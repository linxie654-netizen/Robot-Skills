# RobotStudio 教程：从零建站到跑仿真

目标：不用真机，在电脑上把机器人跑起来。

## 关于 RobotStudio 6.08
- 6.08 是 RobotWare 6 时代的版本，对应 IRC5 控制器，本库的 RAPID 例程（MoveJ/MoveL/MoveC/MoveAbsJ、IO、循环、坐标系）都能用。
- Wizard 积木编程、OmniCore 是更新版本的功能，6.08 里没有，不用找。
- 我不能直接连进你电脑上的 RobotStudio 6.08 帮你点鼠标：我是云端的助手，没有 RobotStudio 连接器，RobotStudio 是本地 Windows 软件、不是网页。你按下面步骤操作，卡住了截图发我，我帮你看。

## 1. 装软件
- ABB 官网下载 RobotStudio，装免费版。
- 装完先打开一次，确认能进主界面。

## 2. 建站
1. 新建空工作站。
2. 导入机器人：ABB 库 -> 选型号，没定型号先用 IRB 120 练。
3. 机器人出现在 3D 画面里，拖动 J1-J6 看它怎么动。

## 3. 建虚拟控制器
1. 控制器 -> 添加控制器 -> 从布局创建。
2. 选 RobotWare 版本，默认即可。
3. 等控制器启动，状态变绿。

## 4. 示教第一个点
1. 把机器人拖到一个姿态。
2. 示教 -> 创建目标点，起名 pHome。
3. 再拖两个姿态，创建 pA、pB。
4. 注意姿态：confdata 不对会报“目标不可达”，换个腕部姿态再试。

## 5. 写第一段 RAPID
1. RAPID 页 -> 展开 MainModule -> 打开 main。
2. 把本库 `rapid/01_move_basics.mod` 里的 MoveJ/MoveL 逻辑抄进去，点位换成你刚示教的 pHome/pA/pB。
3. 同步到控制器。

## 6. 跑仿真
1. 仿真 -> 播放。
2. 看轨迹有没有撞工作台、速度是不是太快。
3. 有问题先改速度（v1000 改 v500）、改区域（fine 改 z50），再跑。

## 7. 常用操作
- 坐标系切换：世界 / 工具 / 工件， jog 时先确认当前坐标系。
- 工具标定：换夹爪必须重标 TCP，否则点位全偏。
- 工件标定：换工件位置只改 wobj，不用重示教每个点。
- 碰撞检查：仿真 -> 碰撞检测打开，跑一遍再上真机。

## 8. Python 联动
1. 按 `vendor/abb_motion_program_exec/` 里的说明，把 RAPID 端装到虚拟控制器。
2. 跑本库 `python/01_move_joints.py`，先只打印 RAPID，不执行。
3. 打印的 RAPID 对了，再取消执行那两行注释，真正发指令。
4. 真机 IP 换掉 `http://127.0.0.1:80`，用户名密码按控制器配置改。
