# 学习进度表：30 课 + 11 个例程 + 7 个项目 + 进阶三课

怎么用：每学完一项，在“学了没”打勾；跑通了，在“跑通没”打勾，写上日期。下次接着学，先看这张表，从断点接着走，不从头重讲。

## “跑通”的标准（全表通用）

- 程序在 RobotStudio 虚拟控制器里跑完一遍、没报错、轨迹对、碰撞检查过。
- 再换一个条件（点位、速度、工件位置）跑一遍，照样通。
- 说“跑通了”要拿出三样证据：报错截图或“无报错”、轨迹对不对、碰撞检查结果。缺一样就不算跑通。
- 看懂了、背下来了、编辑器不报错，都不算跑通。

“学了没”打勾的条件：这一课讲完了，用户能说清这是什么、怎么做。

## 五、进度怎么记

- 用户说“学会了”就记一笔：只记他亲口说的和跑通的证据，不记“我觉得他会了”。
- 每次记进度都写日期：哪天学的、哪天跑通的。
- 断点那课先问一句“上次这课在仿真里跑到哪一步”，从那一步接着跑，跑完往下走。
- 一课的“算会”标准在 `docs/beginner-roadmap.md` 每课末尾那句“算会：……”里，照那句验，不另编标准。
