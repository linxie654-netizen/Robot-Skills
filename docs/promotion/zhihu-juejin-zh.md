# Robot-Skills：让 AI 更会写 ABB 机器人 RAPID 代码的技能包

Robot-Skills 是一个开源技能包，唯一技能 Robot-RAPID，让 AI 更会写 ABB 的 RAPID 代码，学 RobotStudio 仿真。给正在学 ABB 机器人的人用，中文大白话。装一条命令：`npx skills add linxie654-netizen/Robot-Skills`，要 Node.js 22.20 以上。有 7 个实战项目（搬运、码垛、分拣、焊接、上下料、输送带跟踪、三机器人联动，每个含完整代码、搭建步骤、IO 配置、仿真方法、故障分析、安全检查），8 种教法（零基础、实战、代码生成、代码解释、截图分析、错误排查、考试练习、学习进度管理），30 课大白话教学，10 个教学例程，3 课进阶（EGM、多任务、外轴），5 项检查（代码、文档、依赖、安装测试、安全检查）。MIT 开源。

安装命令：

```
npx skills add linxie654-netizen/Robot-Skills
```
