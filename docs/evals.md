# 同一提示，有技能 vs 没技能（RAPID 版 evals）

这 4 个例子是同一提示、有技能 vs 没技能的对照写法，用来说明回答的区别。下面还有一次实数对照（两份程序逐行数出来的）。写法学 arpitg1304/robotics-agent-skills 的 evals（同一提示有技能 vs 没技能对照）和 alchaincyf/nuwa-skill 的盲测思路，只学对照的形式，不夸大结论。下面每例的“没技能时通常缺哪几步”是按本库 `docs/comparison.md` 2.0 一节的写法归纳的。

对照方法：同一句用户原话，先写没技能时助手通常会给什么、缺哪几步，再写有技能时按 `skills/robot-rapid/SKILL.md` 该做到哪几步。每例的“算会”标准见 `docs/beginner-roadmap.md` 对应一课。

## 例 1：写一段搬运程序

同一提示：“帮我写一段 RAPID，从 A 点取箱子放到 B 点。”

- 没技能时通常给的：两句 MoveJ / MoveL，加几个点位就交差。
- 没技能时通常缺的：没问 tooldata 和 wobjdata 有没有标定；没分靠近工件用 v200 + fine、空跑用 v1000 + z50；没写等传感器信号（WaitDI）；没写报错处理；没说要在虚拟控制器里跑一遍、查碰撞。
- 有技能时该做到的：按 SKILL.md 分流表，先读 `references/rapid-patterns.md`，抄 `rapid/02_pick_place.mod` 改；给完整能跑的代码，每段讲清作用；写清 tooldata、wobjdata、速度区域、IO 等待；走 5 步验证闭环，跑通要拿三样证据（报错截图或“无报错”、轨迹、碰撞检查结果，见 `references/simulation-checklist.md`）。

## 例 2：报“目标不可达”

同一提示：“程序报目标不可达，怎么办？”

- 没技能时通常给的：让用户改坐标数值，多试几次。
- 没技能时通常缺的：没先对 `references/troubleshooting.md` 的表；没查手腕姿态（confdata）和工件坐标系；一次改好几处，跑不通不知道回退哪处。
- 有技能时该做到的：先对报错表，再查手腕姿态和工件坐标系，别乱改点位；一次只改一处，改完仿真跑一遍；跑通了换个点位再验一遍。

## 例 3：等传感器有料再取

同一提示：“传感器有料的时候才取，没料就跳过，怎么写？”

- 没技能时通常给的：直接写 MoveL 去取，不等信号。
- 没技能时通常缺的：没写 WaitDI / WaitUntil；没加超时（一直等不到就卡死）；没写没料跳过的分支。
- 有技能时该做到的：按 `rapid/03_io_signals.mod` 写 SetDO、WaitDI、WaitUntil；等信号加超时；没料跳过；对应路线图 L10，算会标准是“有料才做、没料跳过，跑通 `rapid/03` 和 `rapid/10`”。

## 例 4：说“写好了，可以跑了吗”

同一提示：“程序写好了，能跑了吗？”

- 没技能时通常给的：直接说“可以”，或只看编辑器不报错就说没问题。
- 没技能时通常缺的：没按 `references/simulation-checklist.md` 逐项打勾；没要三样证据；没提醒先在仿真里验证；没说编辑器不报错不等于控制器认了，要过 Check Program。
- 有技能时该做到的：先问三样证据齐了没有（报错截图或“无报错”、轨迹、碰撞检查结果），缺一样就不算跑通；清单打完勾才说可以在仿真里跑。

## 实测对照（2026-11-22，同一提示的两份程序，逐行数出来的）

同一提示：“帮我写一段 RAPID，从 A 点取箱子放到 B 点。”两份程序都在 `docs/evals/` 里，数字是 `grep` + `wc -l` 数出来的，不是估的。

|  | 没技能 `no_skill_pick_place.mod` | 有技能 `with_skill_pick_place.mod` |
|---|---|---|
| 总行数 | 15 | 43 |
| 运动指令 | 2 | 9（含回零 MoveAbsJ） |
| IO 指令（SetDO / WaitDI / WaitTime） | 2 | 7 |
| 等信号带超时（MaxTime） | 0 | 1（等料 5 秒不到就跳过） |
| ERROR 处理段 | 0 | 1（出错松爪、回零） |
| fine / 转弯区 z50、z100 | 2 / 0 | 3 / 8 |
| 速度分档 | 只有 v1000 | v200 靠近工件、v500 抬起、v1000 空跑 |

这是一次对照，不是基准测试，不算给技能打分。能说明的是：有技能的版本多做了等料、超时跳过、报错处理、速度分档、回零这几步，没技能的版本两句运动指令就交差了。

## 怎么用这份文件

- 给新手看“有技能多做了哪几步”，不是给技能打分。
