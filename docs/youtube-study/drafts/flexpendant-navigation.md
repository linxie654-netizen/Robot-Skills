## 目标

先认菜单再动手：知道主菜单里有什么、快捷菜单怎么进、操作模式怎么切、使能按钮和速度怎么配合，点动和示教之前不迷路。

## 认识示教器

1. **主菜单（Main menu）**：示教器的总入口，程序、点动、I/O、系统信息都在这里进。先花几分钟把主菜单翻一遍，知道每个入口是干什么的，再动手。
2. **快捷菜单（Quick access menu）**：常用功能放这里，不用一层层翻主菜单。点动、速度、坐标系切换这些天天用的，放快捷菜单里。
3. **使能按钮（Enabling device）**：握在手里的三档开关。松开机器人就停，半按才允许手动运行，全按到底也会停。保命的操作习惯：手一松就停，别一直攥着。
4. **摇杆（Joystick）**：点动用的，推哪个方向机器人往哪个方向走；配合坐标系选择和速度档用。
5. **操作模式**：手动模式才能点动和示教；自动模式跑程序。切模式之前先确认人在单元外、程序没问题，别在手动模式里直接跑自动。
6. **速度档**：小／中／大三档。点动和示教用小档，熟悉了再加；自动跑之前先手动低速走一遍轨迹。

## 容易错的地方

- 没认菜单就直接上手，找不到功能在哪，乱按。
- 使能按钮一直攥着不放，养成坏习惯；或者全按到底，机器人停了还以为出故障。
- 速度档开太大点动，机器人一下冲出去。
- 手动模式和自动模式没分清，人在单元里就切自动。
