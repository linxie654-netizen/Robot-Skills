## 目标

在示教器上把工具的 TCP 标出来，标完验证通过再用。TCP 不准，后面所有点都偏。

## 步骤

1. **准备**：工具装好、拧紧；找一个固定参考点（尖点），比如工作台上的尖顶；确认机器人手动模式、速度小档。
2. **四点法**：用四个不同的姿态，把工具尖端碰到同一个参考点，每碰一次记一个点。四个姿态要尽量散开，别都从一个方向来，姿态越分散算得越准。
3. **算 TCP**：四个点记完，控制器算出 TCP 的位置；保存工具数据（tooldata）。
4. **验证**：标完必须验证，不能标完直接用。换几个姿态再碰一次参考点，看 TCP 是不是还对得上参考点；或者点动 TCP 沿直线走，看轨迹直不直。误差大了就重标。
5. **工件坐标系**：TCP 标完再定义工件坐标系（三点法，见草稿 `workobject-three-point.md`）；点位挂到工件坐标系下，别挂世界坐标系，换工位只改工件不改程序。

## 容易错的地方

- 四个姿态太接近，算出来的 TCP 不准。
- 标完不验证，直接拿去跑程序，点位全偏。
- 工具没拧紧就标，标完工具一动就全错。
- 点位挂到世界坐标系下，工件一挪全得重教。
