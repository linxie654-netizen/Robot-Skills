## 1. 为什么要用多个工件

- 同一段程序（比如取放），换个工位、换个托盘、换条线，不用重示教所有点。
- 做法：点位挂在工件坐标系下，不挂在世界坐标系下；工件一挪，整组点跟着走。
- Domer 的讲法：工件的好处不在“多”，在“程序不用改”——位置变了只改工件，不改程序。

## 2. 典型用法

- 一台机器人对两个托盘：两个工件（wobjA、wobjB），同一套取放点位挂不同的工件各跑一遍。
- 传送带 + 两个码垛托盘：3 个工件（Patino Part 3 就是这么做的：传送带一个、大小托盘各一个）。
- 零件换型：同一种零件换个夹具位置，只重定工件，程序原样跑。

## 3. 每个工件怎么定

- 三点法（见草稿 `workobject-three-point.md`）：原点、X 方向、Y 方向三个点。
- 每个工件单独定，别共用一个原点凑合。
- 定完先测：点动到工件上的已知点，看 TCP 读数跟工件坐标对不对得上（R4 里也有 Test Work Object 这一步）。

## 4. 程序里怎么写

- 运动指令挂工件：`MoveL pPick, v200, fine, tGripper \WObj:=wobjA;`
- 换工位就换 `\WObj`，点位名可以复用。
- 容易错：忘了写 `\WObj`，点位就默认挂 wobj0，工件挪了点位不动，机器人走到错的地方。
