# 叠码垛仿真：从零做到能跑（文字版）

程序在 `rapid/11_palletizing.mod`，这篇是全部要做的事，一个字一个字写出来，照着做就能跑。

## 1. 这个仿真做出来是什么样

- 一条传送带不停送箱子过来，机器人一个一个取下来，码到旁边的托盘上。
- 托盘 2 列 × 2 行 × 3 层，一共 12 箱。奇数层正常摆，偶数层转 90 度交错着码，码出来才稳。
- 托盘码满了，机器人回安全点，示教器上显示“托盘已满，共码了 12 箱”，等你换个空托盘、给个信号，它接着码下一托，不停机。

## 2. 方案定好了（先看明白再动手）

| 东西 | 定成什么样 | 为什么这么定 |
| --- | --- | --- |
| 机器人 | IRB 120，放在 300 mm 高的台座上 | 跟你练手的站一致；IRB 120 臂展只有 580 mm，箱子、托盘都得小，不然够不着 |
| 箱子 | 120 × 80 × 60 mm，一种尺寸 | 小箱子才进得了 IRB 120 的工作范围；想码大箱就换 IRB 460（码垛专用，臂展 2.4 米），程序不用改，只改参数和点位 |
| 托盘 | 320 × 320 mm，顶面高 300 mm（和机器人台座齐平） | 托盘和机器人台座一边高，机器人不用够上够下 |
| 供料 | 传送带，皮带顶面高 400 mm，取料点在机器人左前方 | 传送带比托盘高一截，取放不打架 |
| 夹爪 | 数字输出控制，`doGrip` 1=夹紧、0=松开 | 真空吸盘和机械夹爪在程序里是一样的，都是一个输出；仿真里用哪个，看第 5 节 |
| 信号 | `diBoxReady`（取料点有箱）、`doGrip`（夹爪）、`diNewPallet`（新托盘就位） | 3 个信号就够跑完整流程 |
| 码法 | 参数化：列数、行数、层数、箱子长宽高、间隙都在程序开头 `CONST` 里，改数字就改码法 | 不用改程序逻辑 |

## 3. 建站：一步一步

1. **新建工作站**：RobotStudio 里建空站，导 IRB 120，建虚拟控制器（系统名随便起，比如 `Palletizing`），建系统时打开 motion events 选项。
2. **垫台座**：Modeling 里画一个 300 mm 高的台座（Box 就行），把机器人放到台座上。机器人底座坐标系要同步更新，不然点位全偏。
3. **摆传送带**：Home → Import Library → Equipment，选一条传送带，放到机器人左前方，皮带顶面调到 400 mm 高。取料点定在皮带末端。
4. **摆托盘**：Modeling 里画一个 320 × 320 mm 的托盘（Box），顶面调到 300 mm 高，放到机器人右前方，离机器人近一点，别摆到臂展外面去。
5. **摆箱子**：画一个 120 × 80 × 60 mm 的箱子（Box），先放 1 个在传送带取料点、1 个在托盘一角当参考。箱子本地原点用 Set Local Origin + Snap End 移到箱子顶部，不然开了物理箱子会穿透皮带。
6. **装夹爪**：导夹爪模型（或者先用简单方块代替），Modeling → Create Tool 生成工具，TCP 量自己的夹爪再填——程序里写的是法兰下 120 mm，是个例子数，别照抄。
7. **建 2 个工件坐标系**：传送带一个（`wobjConv`，原点在取料点）、托盘一个（`wobjPallet`，原点在托盘顶面一角）。点位挂工件坐标系下，托盘挪位置只改工件坐标系，程序不用动。建法见草稿 `workobject-three-point.md`（三点法）。
8. **教点**：按程序里的 4 个点位教——`pPick`（取料点，TCP 在箱顶）、`pPalletBase`（托盘一角第一箱）、`pPalletBaseR`（转 90 度的那个，偶数层用）、`pHome`（安全点）。点动方法见 H1/H2。**程序里的点位数值全是教学值，教的时候以你实际摆的位置为准。**
9. **配信号**：Controller → Configuration Editor → I/O，新建 `diBoxReady`（数字输入）、`doGrip`（数字输出）、`diNewPallet`（数字输入），名字要和程序里的一字不差。
10. **同步程序**：把 `rapid/11_palletizing.mod` 加载到控制器（或者右键同步），编译通过，没红字再跑。

## 4. 信号怎么接（仿真里）

| 信号 | 谁给它 | 什么时候变 |
| --- | --- | --- |
| `diBoxReady` | 传送带末端的 Line Sensor（见第 5 节） | 箱子到取料点变 1，机器人取走后变 0 |
| `doGrip` | 机器人程序 `SetDO` | 取箱时变 1，放箱时变 0 |
| `diNewPallet` | 你手动给（I/O Simulator 里点一下） | 托盘码满、换好空托盘后点一下，机器人接着码 |

先跑通可以只接 `diBoxReady` 和 `doGrip` 两个，`diNewPallet` 每次手动点。熟了再把供料、换托盘都做成自动的。

## 5. Smart 组件（两种做法，先简后繁）

**简版（先跑通这个）**：不用传送带物理，不用传感器。箱子手动摆在取料点，`diBoxReady` 在 I/O Simulator 里手动点 1，机器人取走一箱，你再摆一箱、再点 1。先把取放、码垛逻辑跑通。

**完整版（照着 Patino 的做法）**：
- **传送带**：照草稿 `conveyor-physics.md` 做——皮带加 Physics Fixed + Surface Velocity，Source 自动造箱，Line Sensor 检测到箱子就停皮带，`diBoxReady` 接传感器的输出。
- **真空夹爪**：照草稿 `vacuum-gripper-smart-component.md` 做——TCP 处放 Line Sensor，`doGrip` 为 1 吸住、为 0 放开（放的逻辑要过一个 LogicGate NOT，不然吸住不放）。
- **托盘**：加物理属性、设成刚性，箱子才不会掉穿托盘。
- **保存初始状态**：摆好之后保存一个 “Simulation Start” 初始状态，每次改完一键复位。

## 6. 程序讲一遍（`rapid/11_palletizing.mod`）

- **开头 `CONST`**：码垛规格全在这里——2 列、2 行、3 层，箱子 120×80×60，间隙 10 mm。想码 3 列、4 层，改这几个数字就行。
- **`main`**：先回安全点，然后 `WHILE TRUE` 一托一托循环码。`FOR nLayer` 一层一层、`FOR nCol` / `FOR nRow` 一箱一箱。码满 12 箱回安全点，`TPWrite` 报数，`WaitDI diNewPallet` 等你换托盘，换好接着码。
- **`PickBox`**：等 `diBoxReady` 变 1（箱子到了）→ 到取料点上方 → 直线下降 → `doGrip` 置 1 夹紧 → 等 0.3 秒夹牢 → 抬起。
- **`PlaceBox`**：算位置——`dx`、`dy` 是这一箱在第几列第几行，`dz` 是第几层往上抬多高；奇数层用 `pPalletBase`，偶数层用转 90 度的 `pPalletBaseR`，长宽互换。位置是 `Offs()` 当场算出来的，所以不用教 12 个点，只教 2 个基准点。下降放箱 → `doGrip` 置 0 松爪 → 等 0.3 秒放稳 → 抬起。
- **为什么只教 2 个点**：12 个箱子的位置全是基准点加偏移算出来的，托盘挪地方只改 `wobjPallet` 一个坐标系，12 个点跟着走。这就是工件坐标系的用处。

## 7. 跑仿真

1. Simulation → Simulation Setup，把 `main` 加进主序列。
2. 点 Play。看三件事：机器人取不取得到箱子、放的位置对不对（别叠歪、别悬空）、层与层之间转没转 90 度。
3. 跑完一托（12 箱），示教器显示“托盘已满”，I/O Simulator 里点一下 `diNewPallet`，看它接不接着码下一托。
4. 跑完点 Reset，回到 “Simulation Start” 初始状态，再跑一遍确认每次都一样。

## 8. 常见问题

| 现象 | 先查什么 |
| --- | --- |
| 目标点够不着，报不可达 | 托盘、传送带摆太远了，往机器人跟前挪 50 mm 再跑；先查手腕姿态和工件坐标系（见 `references/troubleshooting.md`） |
| 箱子全叠到同一个点上 | `PlaceBox` 里 `dx`、`dy`、`dz` 算没算对，`Offs()` 是不是写在 `Move` 指令里（别先算出来存变量再用） |
| 偶数层没转 90 度 | `pPalletBaseR` 的姿态对不对，仿真里看一眼朝向，不对就重示教 |
| 夹爪吸住不放 | 放的逻辑要取反，`doGrip` 为 0 才放；Smart 组件里检查 LogicGate NOT 接没接 |
| 箱子穿透皮带/托盘 | 箱子本地原点没移到顶部；托盘没加物理、没设刚性 |
| 机器人取走箱子，传送带还不停 | Line Sensor 的输出没连到 `diBoxReady`，或者传感器高度不对（小箱、大箱分不清） |
| 程序一跑就停 | `main` 外面没加 `WHILE TRUE`，一托码完程序就结束了 |

## 9. 进阶（跑通了再玩）

- **换大机器人**：IRB 460（码垛专用），箱子、托盘按比例放大，程序只改开头 `CONST` 和 4 个点位。
- **两种箱子分拣**：传送带送大小两种箱子，两个传感器判断，小箱放小托盘、大箱放大托盘，做法见草稿 `pick-place-offsets-sorting.md`。
- **掉箱检测**：取箱后查一下吸没吸住（比如真空压力信号），没吸住就报警停机，别空手去放。
- **码垛花样**：现在是 2×2 转 90 度交错；想码 3×3、一字排开、井字形，改 `nCols`、`nRows` 和 `PlaceBox` 里的算式就行。
