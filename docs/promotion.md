# 推广文案：Robot-RAPID

🤖 Robot-RAPID：让 AI 教你编 ABB 机器人

按目前核实到的，GitHub 上没有第二个按 Agent Skill（SKILL.md）格式封装的 ABB 机器人编程技能。

里面有什么：
- 30 课大白话教学：安全、示教器、坐标系、运动指令、I/O、焊接、外轴，从零到能跑
- 10 个 RAPID 例程：搬运、循环、圆弧、报错处理，完整能跑，抄下来改改就能用
- 0 到 1 全流程：RobotStudio 里一步步建工作站、跑仿真
- Python 联动：Python 算位置、生成 RAPID、发给控制器

一条命令装上：

```
npx skills add linxie654-netizen/Robot-Skills
```

仓库：https://github.com/linxie654-netizen/Robot-Skills

教学版，非 ABB 官方；例程点位是教学值，在仿真里重新示教。
