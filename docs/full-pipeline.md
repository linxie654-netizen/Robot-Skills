# 从 0 到 1 全流程（Skill 版，不用 MCP）

2026-11-20 用户拍板：MCP 那条路太难，改做 Skill。C# 插件工具（建站、加机器人、Smart 组件、点动、建模的 MCP 草稿）全部暂停，不再往下编；全流程改成 Skill：人照着步骤在 RobotStudio 6.08 里点，助手给 RAPID 文件、给检查清单、看截图改错。

顺序：工作站 → 机器人 → 示教器 → 建模 → 组件 → 编程。每段做完先检查再进下一段。

## 1. 建工作站

- RobotStudio → 新建 → 空工作站，起个名字，保存成 `.rsstn`。
- 检查：3D 窗口能看见地面网格，左边的“路径与目标点”里有默认任务。
- 坑：新工作站可能没开 3D 图形窗口，关了重开或换布局视图就行，不用写代码。

## 2. 加机器人

- 先定型号（还没定就先用 IRB 120 练手）。机器人库在 `C:\ProgramData\ABB\DistributionPackages2`，新型号先在 RobotStudio 里下载。
- 导入机器人：从机器人库选型号 → 导入工作站 → 摆到合适位置。
- 建虚拟控制器：**不能用代码从 0 建系统**，这是 Installation Manager / System Builder 的活。在那里面建系统（选 RobotWare 版本、机器人型号、需要的选项），建好后回 RobotStudio，用“从系统创建虚拟控制器”加载；已有系统直接启动就行。
- 检查：控制器状态是运行中，机器人能在 3D 窗口里显示，手动模式能动。

## 3. 示教器（教点、点动）

- 点动：用虚拟示教器（FlexPendant）点动，关节模式改 J1–J6，线性模式沿 X/Y/Z 走，靠近工件时降速。
- 教目标点：把机器人点动到要的位置 → 创建目标点 → 记下名字和坐标 → 加进路径。
- 仿真里想直接改关节角：改关节值就是点动的替代做法，效果一样，只是没有示教器手感。
- 检查：每个目标点机器人都能到达，不报“不可达”；姿态（手腕方向）合理。

## 4. 建模

- 导 CAD：导入零件的 CAD 文件（STEP/IGES 等），摆到工作台正确位置。
- 自己建几何：用建模功能做长方体、圆柱、圆锥等简单形状，当夹具、工件或障碍物。
- 检查：模型位置、尺寸和真实件对得上；仿真时机器人和模型不穿模。

## 5. 组件（Smart 组件）

- 从 Smart 组件库导入现成组件（夹爪、传送带、传感器等），拖进工作站。
- 接线：按组件说明连信号（比如夹爪开/合信号连到机器人 IO），在组件属性里设好参数。
- 检查：仿真运行时组件按信号动作，比如夹爪在抓取点闭合、在放置点张开。

## 6. 编程

- 用库里的 RAPID 例程（`rapid/01_move_basics.mod` 起步），导入工作站的任务里。
- 流程：教点 → 建路径（MoveJ 快速走空行，MoveL 靠近工件）→ 同步到虚拟控制器 → 仿真跑一遍 → 查碰撞 → 没问题再低速手动验证。
- 检查：仿真跑通、无碰撞、无不可达点；上真机前所有点位必须在仿真里重示教，例程里的点位只是教学值。
