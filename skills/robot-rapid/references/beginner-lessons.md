从 YouTube 新手教程的 30 篇学习草稿转化而来。每课讲清“这是什么、怎么做、容易错在哪”，能独立读懂。

**先说清楚三件事：**

- 按步骤做之前，先在仿真里走一遍、查碰撞。
- 术语第一次出现都用人话解释了一遍，后面直接用简称。
- 本文件已进公开仓库。以后边问边调用、边回答边改正。第 15–30 课是 2026-11-20 新追加的。

## 第 1 课：安全开场——上锁挂牌、急停、安全恢复

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 1 段（视频 https://www.youtube.com/watch?v=hGGkzsT8WEU ，时长 4:36:34）
**学法说明：** 本课内容以 Wolf Robotics《ABB BASIC ROBOTIC PROGRAMMING》4 天线下班手册和 ABB 官方 RU011／IN-RB02 课程大纲为准。

### 这是什么

进机器人单元动手之前，先把能量断掉、锁住、挂牌，确认机器人动不了，再开始工作。出了急停，先查原因、走恢复流程，再复位。

上锁挂牌（Lock out / Tag out）就是：断电断气，上锁，挂上写有姓名、日期、原因的牌子。谁挂的牌谁摘，别人不许代摘。

### 怎么做

1. **进单元前先确认安全装置**：围栏、光幕、急停按钮、安全门开关都在位，没被短接或拆掉；确认安全链（run chain，就是一串安全开关连成的回路，任何一个断开机器人就停）正常。
2. **上锁挂牌**：开工第一步，不是可选项。断开机器人及周边设备的动力（电、气等），上锁，挂上写有姓名、日期、原因的牌子。
3. **验证零能量**：锁好后试着启动一下，确认确实动不了，再开始工作；别只信开关位置。
4. **急停**：出问题先拍急停。急停按下后机器人立即停，但这只是停住，不是恢复。
5. **安全恢复**：急停后不能直接复位就跑。先查清触发原因、排除故障，确认单元里没人、没东西挡路，再按恢复流程复位，最后手动低速验证一遍再进自动。

### 容易错在哪

- 上锁挂牌当成走过场，锁没上、牌没挂就进单元。
- 急停按下后直接复位、直接跑，没查原因、没走恢复流程。
- 恢复后不验证，直接进自动模式。

### 和库里其他内容的关系

- 新手路线 L14 只有原则（手动低速、查碰撞、急停围栏），这课补的是开工和恢复的完整流程。
- QuickStop 信号和 World Zone（禁区）的做法见第 13 课，那课讲信号和禁区，这课讲人和流程，两课合起来才是完整的安全。

## 第 2 课：认识示教器——主菜单、快捷菜单、操作模式、使能与速度

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 2 段（视频同第 1 课）
**学法说明：** 同第 1 课。

### 这是什么

示教器（FlexPendant）就是挂在机器人旁边、拿在手里的那块带屏幕的操作板，点动、示教、改程序都在它上面做。先认菜单再动手，不然找不到功能在哪。

### 怎么做

1. **主菜单（Main menu）**：示教器的总入口，程序、点动、I/O（输入输出信号）、系统信息都在这里进。先花几分钟把主菜单翻一遍，知道每个入口是干什么的，再动手。
2. **快捷菜单（Quick access menu）**：常用功能放这里，不用一层层翻主菜单。点动、速度、坐标系切换这些天天用的，放快捷菜单里。
3. **使能按钮（Enabling device）**：握在手里的三档开关。松开机器人就停，半按才允许手动运行，全按到底也会停。保命的操作习惯：手一松就停，别一直攥着。
4. **摇杆（Joystick）**：点动用的，推哪个方向机器人往哪个方向走；配合坐标系选择和速度档用。
5. **操作模式**：手动模式才能点动和示教；自动模式跑程序。切模式之前先确认人在单元外、程序没问题，别在手动模式里直接跑自动。
6. **速度档**：小／中／大三档。点动和示教用小档，熟悉了再加；自动跑之前先手动低速走一遍轨迹。

### 容易错在哪

- 没认菜单就直接上手，找不到功能在哪，乱按。
- 使能按钮一直攥着不放，养成坏习惯；或者全按到底，机器人停了还以为出故障。
- 速度档开太大点动，机器人一下冲出去。
- 手动模式和自动模式没分清，人在单元里就切自动。

### 和库里其他内容的关系

- 点动三种模式（轴／线性／重定向）见新手路线 L2 和例程 06，那是“怎么动”；这课是“在哪操作、怎么进”，是点动和示教的前置课。

## 第 3 课：从已有布局创建单机器人系统 + 配 I/O

**来源视频：** cnctrain《Creating Single Robot System in ABB Robotstudio》（文章 https://cnctrain.com/blogs/post/creating-single-robot-system-in-abb-robotstudio ，2024-04-04；视频 https://www.youtube.com/watch?v=TDjzO5AMOmk）

### 这是什么

机器人系统就是一台独立机器人 + 自己的控制器 + 自己的 I/O 系统（输入输出信号的集合），配好、能编程。本课用 IRC5 控制器（ABB 机器人常用的控制器型号）。

I/O 就是信号：输入信号是外面传进来的（比如传感器说“箱子到了”），输出信号是机器人发出去的（比如“夹爪合上”）。配完 I/O，信号才能在程序里用。

### 怎么做

1. **先确认布局里有控制器**：布局里 IRC5 已经加好了才能建系统，没加先加。
2. **建系统**：Home → Robot System，有三种方法：
   - 基于已有布局创建系统（视频演示的就是这种：布局现成，系统跟着布局走，最不容易配错，新手先学这一种）；
   - 创建新系统并加到工作站；
   - 加一个已有的系统到工作站。
3. **配 I/O**：Controller 标签页 → Configuration Editor（配置编辑器，就是改系统参数的地方）。在这里看和改系统参数：Communication（通信）、I/O System（I/O 系统）。
4. **核对信号名**：配出来的信号名，就是程序里 `SetDO`（置输出信号）／`WaitDI`（等输入信号）用的名字。写程序之前先在这里核对名字，写错一个字母程序就找不到信号。

### 容易错在哪

- 布局里没加控制器就建系统：先确认 IRC5 已经在布局里。
- 配完 I/O 不检查信号名：程序里写错一个字母就找不到信号，先在 Configuration Editor 里核对名字再写程序。

### 和库里其他内容的关系

- `docs/full-pipeline.md` 是从头建系统的 0 到 1 全流程；这课补的是“从已有布局建”这条路 + 建完后去 Configuration Editor 配 I/O 这一步。

## 第 4 课：工具坐标系——三种定义方法 + Create Tool 向导

**来源视频：** Aleksandar Haber《ABB Robot Tutorial: Defining Tool Frames and Basic Modeling in ABB RobotStudio》（视频 https://www.youtube.com/watch?v=k0ddlUXXHto）
**学法说明：** 作者文字版只有两行（“讲怎么定义工具坐标系、做基础建模”），细节靠下面两份交叉材料补，不是视频逐字稿：ITAR《Hands-on with ABB Robots》（ardavan.io）讲示教器上三种方法；CMU《10 Steps to Add a Tool》讲 Create Tool 向导步骤。

### 这是什么

先分清两个东西：

- **工具几何**：夹爪、焊枪、吸盘的 3D 模型，导进工作站。
- **工具坐标系（tooldata，工具数据）**：告诉机器人工具的尖端在哪、朝向怎么定、工具多重。没定义工具时机器人默认用 tool0，TCP 在法兰中心、Z 轴沿法兰法线。

**TCP**（工具中心点）就是工具真正干活的那个点，比如夹爪的夹取点、焊枪的枪尖。TCP 不准，后面所有点都偏。**法兰**是机器人手腕末端那个圆盘，工具就装在它上面；工具的 Z 轴从手腕向外指。

### 怎么做

**示教器上定义工具，三种方法按需选：**

| 方法 | 什么时候用 | 怎么做 |
|---|---|---|
| TCP（4 点，默认方向） | 工具沿法兰 Z 轴、绕 Z 转不影响干活（如圆头记号笔） | 固定点，从 4 个不同方向把 TCP 对准它 |
| TCP + Z 方向 | 工具 Z 轴和法兰 Z 轴不一样、但绕 Z 转不重要 | 4 点定 TCP，再加一点定 Z 方向 |
| TCP + Z 和 X 方向 | 接近姿态必须精确，连绕 Z 的转角都要定 | 4 点定 TCP，再加两点定 Z、X 方向 |

要点：每种方法都要从多个方向对准空间中同一个固定点，点得越准，TCP 越准。

**RobotStudio 里建工具（Create Tool 向导，CMU 10 步）：**

1. Modeling → Import Geometry，导工具模型（.stl 等，建模单位先设成 mm）。
2. Modeling → Create Tool，起名字。
3. Use Existing，选刚导进来的几何。
4. 其他设置不填也行，Next。
5. 起 TCP 名（只有一个 TCP 就默认），填每个 TCP 的位置和姿态，加进 TCP 列表，Done。
6. Layout 里把工具拖到机器人上，弹窗点 No（让它自动摆正位置）。
7. 要改：Home → Paths&Targets → tooldata 文件夹，右键工具 → Modify Tooldata。

**TCP 位置怎么量：**

- 量法兰安装面到 TCP 的距离，填进 TCP 的 Z 值。
- Patino 的例子：吸盘底座到 TCP 量出来是 184 mm——**每把工具自己量，别照抄**。
- 重心：工具重心用 Snap Gravity 取；重量填错会影响负载估算。

### 容易错在哪

- 建模单位不是 mm 就导错尺寸：导之前先确认单位。
- 工具 Z 轴方向搞反：Z 轴从手腕向外指，不是向里。
- 只有一个 TCP 也留默认名，别手改出两个 TCP 互相混。

### 和库里其他内容的关系

- `rapid/05_coordinates.mod` 讲 tooldata 概念；这课补的是“具体怎么点”。
- 示教器上标 TCP 的流程见第 5 课，两课合起来就齐了。

## 第 5 课：示教器四点法标 TCP + 验证

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 4 段（视频同第 1 课）
**学法说明：** 同第 1 课。

### 这是什么

在示教器上把工具的 TCP（工具中心点，就是工具尖端那个点）标出来，标完验证通过再用。TCP 不准，后面所有点都偏。

**四点法**就是：用四个不同的姿态，把工具尖端碰到同一个固定参考点，每碰一次记一个点，控制器拿这四个点算出 TCP 的位置。

### 怎么做

1. **准备**：工具装好、拧紧；找一个固定参考点（尖点），比如工作台上的尖顶；确认机器人手动模式、速度小档。
2. **四点法**：用四个不同的姿态，把工具尖端碰到同一个参考点，每碰一次记一个点。四个姿态要尽量散开，别都从一个方向来，姿态越分散算得越准。
3. **算 TCP**：四个点记完，控制器算出 TCP 的位置；保存工具数据（tooldata）。
4. **验证**：标完必须验证，不能标完直接用。换几个姿态再碰一次参考点，看 TCP 是不是还对得上参考点；或者点动 TCP 沿直线走，看轨迹直不直。误差大了就重标。
5. **工件坐标系**：TCP 标完再定义工件坐标系（三点法，见第 6 课）；点位挂到工件坐标系下，别挂世界坐标系，换工位只改工件不改程序。

### 容易错在哪

- 四个姿态太接近，算出来的 TCP 不准。
- 标完不验证，直接拿去跑程序，点位全偏。
- 工具没拧紧就标，标完工具一动就全错。
- 点位挂到世界坐标系下，工件一挪全得重教。

### 和库里其他内容的关系

- 第 4 课讲 RobotStudio 里定义工具的三种方法；这课是示教器上标 TCP 的流程，两课合起来就齐了。
- 例程 05（坐标系）和新手路线 L9 只有概念，这课是能照着做的步骤。

算会：四个姿态尽量散开、碰到同一点，标完验证误差在接受范围。
## 第 6 课：三点法定义工件坐标系

**来源视频：** Aleksandar Haber《How to Correctly Define and Create Workobject Frames and Coordinate Systems》（视频 https://www.youtube.com/watch?v=5fdcGGy9IzI ；文字版 https://aleksandarhaber.com/21779-2/）

### 这是什么

**工件坐标系（wobjdata，工件数据）**是用户自己定的坐标系，通常跟工件的几何对齐。好处：工件一挪位置，只改工件坐标系就行，不用重示教每个点。新手常犯的错就是工件一动就全重示教。

**三点法**就是用三个点定一个坐标系：第 1 个点是原点，第 2 个点定 X 轴方向，第 3 个点定 Y 轴方向，Z 轴按右手定则出来（右手定则：右手四指从 X 轴弯向 Y 轴，拇指指的就是 Z 轴方向）。

### 怎么做

1. **建个盒子练手**：在 RobotStudio 里建模一个盒子（Box），调好尺寸。这一步是练手，也是后面定坐标系的参照物。
2. **开三点法**：建工件坐标系时选三点法（Three-point method）。
3. **取三个点**，按顺序：
   - 第 1 个点：原点（工件坐标系的零点，一般取工件一角）；
   - 第 2 个点：X 轴方向上的点；
   - 第 3 个点：Y 轴方向上的点。
   三个点定了，坐标系就定了。
4. **检查**：看坐标系方向对不对：X、Y 沿着工件边，Z 垂直于工件面。不对就重取，别将就。
5. **用起来**：目标点都挂到这个工件坐标系下写，程序里用 `wobjdata` 引用它。

### 容易错在哪

- 三个点的顺序别搞反（原点、X、Y），反了坐标系就歪了。
- 点别取在工件本身会动的地方，取在固定、可复现的位置。
- 工具 TCP 没标定就定工件坐标系，点位全偏——先标工具（第 4、5 课），再定工件。

### 和库里其他内容的关系

- `rapid/05_coordinates.mod` 讲 tooldata、wobjdata 的概念；这课是三点法的操作步骤，补进去新手路线 L9 就完整了。
- 第 11 课建了 3 个工件坐标系（传送带 + 大小托盘），是三点法的实战应用，两课可以互相印证。

## 第 7 课：多个工件坐标系——一个程序，多处复用

**来源视频：** Mr. Domer《ABB Tutorial - Multiple Work Objects》（30 分钟）

### 这是什么

同一段程序（比如取放），换个工位、换个托盘、换条线，不用重示教所有点。做法：点位挂在工件坐标系下，不挂在世界坐标系下；工件一挪，整组点跟着走。

Domer 的讲法：工件的好处不在“多”，在“程序不用改”——位置变了只改工件，不改程序。

### 怎么做

1. **想清楚复用场景**，典型用法：
   - 一台机器人对两个托盘：两个工件（wobjA、wobjB），同一套取放点位挂不同的工件各跑一遍；
   - 传送带 + 两个码垛托盘：3 个工件（第 11 课就是这么做的：传送带一个、大小托盘各一个）；
   - 零件换型：同一种零件换个夹具位置，只重定工件，程序原样跑。
2. **每个工件单独定**：三点法（见第 6 课）：原点、X 方向、Y 方向三个点。每个工件单独定，别共用一个原点凑合。
3. **定完先测**：点动到工件上的已知点，看 TCP 读数跟工件坐标对不对得上。
4. **程序里挂工件**：运动指令挂工件，换工位就换 `\WObj`，点位名可以复用：

```rapid
MoveL pPick, v200, fine, tGripper \WObj:=wobjA;
```

### 容易错在哪

- 忘了写 `\WObj`，点位就默认挂 wobj0（世界坐标系），工件挪了点位不动，机器人走到错的地方。

### 和库里其他内容的关系

- `rapid/05_coordinates.mod`：wobjdata 概念。
- 第 11 课：3 个工件的实战例子。
- 这课补的是“为什么用多个工件”这个讲法，库里原来只讲了 wobjdata 是什么。

算会：同一套取放点位挂两个工件各跑一遍，位置都对。
## 第 8 课：沿路径走——从记点到 RAPID 程序

**来源视频：** Aleksandar Haber《How to Easy Program ABB Robots to Follow a Path by Using RAPID Programming Language》（视频 https://www.youtube.com/watch?v=zZXk-TW2iCE）
**学法说明：** 流程按 Haber 视频讲的顺序，每一步用 CMU Future CNC 官方教程、ITAR《RobotStudio Handbook》、卡尔加里大学 YuMi 指南、plcprogramming.io RAPID 教程交叉核对过。

### 这是什么

让机器人沿着一条你定好的路径走：先点动记下路径上的点，再把点连成路径，最后同步成 RAPID 程序跑起来。

**robtarget**（目标点）就是空间里的一个点，带位置和姿态；**路径（Path）**就是一串按顺序排好的目标点；**同步到控制器（Synchronize to VC）**就是把工作站里的路径变成控制器里的 RAPID 程序。

### 怎么做（7 步）

1. **导模型**：Home → Import Geometry，导工件或末端执行器的几何模型（STEP / IGES 等），摆到机器人够得着的位置。
2. **装末端执行器**：Modeling 里把工具模型挂到机器人法兰上，定义 tooldata（TCP）。TCP 没标定就先标——见第 4 课，TCP 不准，后面所有点都偏。
3. **点动记点**：Jog Joint（轴点动）或 Jog Linear（直线点动）把机器人点到要走的位置，Home → Teach Target 记下 robtarget；也可以 Home → Target → Create Target 按数值直接建点。点要挂到工件坐标系下（见第 6 课），别挂到世界坐标系。
4. **建路径**：Home → Path → Empty path 建空路径，把目标点按顺序拖进路径；每一段选运动类型——空中大跨度用 MoveJ，贴工件走直线用 MoveL；沿模型边走可用 Auto path 自动沿边生成目标点。
   - **MoveJ**：关节运动，机器人各关节自己找最快的路，适合空中赶路。
   - **MoveL**：直线运动，TCP 沿直线走，适合贴工件干活（焊接、点胶、装配插入）。
5. **同步到控制器**：右键 T_ROB1 → Synchronize to VC，路径就变成控制器里的 RAPID 程序（一个 Path 过程 + robtarget 声明）。
6. **写 / 读 RAPID**：同步生成的程序长这样（点位是教学值，在仿真里重新示教）：

```rapid
MODULE Module1
    CONST robtarget pStart:=[[500,0,600],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];
    CONST robtarget p10:=[[500,200,300],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];
    PROC main()
        Path_10;
    ENDPROC
    PROC Path_10()
        MoveJ pStart, v1000, z50, tool0\WObj:=wobj0;
        MoveL p10, v500, fine, tool0\WObj:=wobj0;
    ENDPROC
ENDMODULE
```

`MoveJ 目标, 速度, zone, 工具`：速度 v1000 是空中快移，v500 是贴工件慢走；**zone**（转角区）是拐弯时允许多大偏差：z50 是空中过渡点可以拐弯，fine / z1 是贴工件必须走到位。工具和工件用 `\WObj:=` 指明，别漏。

7. **跑仿真**：Simulation → Simulation Setup，把 Path_10 加进主序列，点 Play；或者先不跑程序，右键路径 → Move Along Path，只验证轨迹走得对不对。

### 容易错在哪

- **Move Along Path 报错**：先加 `ConfL Off` 和 `ConfJ Off`（右键路径 → Insert Action Instruction → Instruction Templates 里选），再不行用 Auto Configuration 给所有 Move 指令重算构型。
- **轨迹拐弯 / 够不着**：点太少机器人会抄近路，中间加过渡点（Approach 点）；点在可达范围外就挪工件或机器人位置，别硬改点位数值。
- **MoveJ / MoveL 用反**：贴工件（焊接、点胶、装配插入）必须 MoveL，空中赶路用 MoveJ；用反了轨迹是歪的。
- **zone 用错**：贴工件的点用 fine 或 z1，空中过渡点才用 z50；全用 fine 跑得慢，全用 z50 贴工件会撞。
- **忘了同步**：只在工作站里建了路径、没 Synchronize to VC，控制器里就没有程序，仿真跑的是旧程序。

## 第 9 课：真空夹爪 Smart 组件——信号一来就吸，信号一撤就放

**来源视频：** Maurilio Patino 码垛教程 Part 1（视频 https://youtu.be/y0FjnO8AysQ ，文字版全文已读）

### 这是什么

做一个能吸住箱子、松开箱子的真空夹爪，信号一来就吸，信号一撤就放。

**Smart 组件**就是 RobotStudio 里带逻辑的小零件：里面可以挂传感器、挂逻辑、挂信号，拼好了能直接复用。**Line Sensor**（线传感器）就是一条检测线，东西碰到这条线它就亮。**Attacher / Detacher**（吸住器／松开器）是 Smart 组件里的两个动作：Attacher 是把碰到的东西粘到夹爪上，Detacher 是松开。

### 怎么做

1. **导夹爪 CAD**：建空工作站，Modeling → Import Geometry，选 `.SAT` 格式的夹爪文件（GrabCAD 上能找例子）。
2. **摆正工具**：先把工具转到露出底座，用 Place Tool → One Point + Snap Center，把工具放到世界坐标系原点，再转到正确朝向。
3. **定 TCP**：Frame → Create Frame（参考系选世界坐标系）；量出工具底座到 TCP 的距离（Patino 的例子是 184 mm，**用自己的夹爪要自己量**），Set Position 把工具坐标系移到 TCP。
4. **生成工具文件**：Modeling → Create Tool，起名，选 Existing Component；重心用 Snap Gravity 取；TCP 起名、选刚建的工具坐标系。
5. **（可选）存成库**：点工具 → Save as Library，存成 `.rslib`，以后直接复用。
6. **建 Smart 组件**：Modeling → Smart Component，起名如 `SC_VentosaTool`；把自定义工具拖进去做子组件，工具属性用 Set as Role 设为 Role。
7. **加传感器**：在 TCP 处放一个 Line Sensor，定好起点和终点的小圆柱，就是传感器的检测线。
8. **接逻辑**：Design 窗口里新建一个数字输入 DI（如 `DI_Attach`），接线逻辑是——
   - 吸：传感器 SensorOut 为真 → Attacher 执行；
   - 放：DI_Attach 为假 → Detacher 执行（注意：放的逻辑要过一个 LogicGate NOT，就是取反）；
   - Attacher/Detacher 的 Child 都设成 `LineSensor.SensedPart`（也就是传感器碰到的箱子），Parent 设成夹爪工具。
9. **存成库**：Smart 组件 → Save as Library，存成 `.rslib`。

### 容易错在哪

- TCP 距离要自己量，别抄 184 mm，那是 Patino 那个夹爪的数。
- 放的逻辑要取反（DI 为假才放），直接接会吸住不放。
- Attacher 的 Parent 必须是夹爪工具，不然箱子吸到别的地方去。

### 和库里其他内容的关系

- 库里 `rapid/02_pick_place.mod` 的搬运是写死的取放，这个是 Smart 组件版的吸放，信号驱动。
- 库里 `references/smart-components.md` 讲通用搭法，这个是真空夹爪的完整实例，补进去后新手能直接照做。

## 第 10 课：传送带物理仿真——箱子自己掉下来、自己被送走

**来源视频：** Maurilio Patino 码垛教程 Part 2（视频同第 9 课，文字版全文已读）

### 这是什么

做一条会动的传送带：箱子从 Source 里出来、掉到皮带上、被皮带送到头、传感器一碰到箱子皮带就停。

**物理仿真**就是让东西按真实物理走：箱子会受重力往下掉，皮带会带着箱子走。**Source**（发生器）是 Smart 组件里造东西的部件，信号一来就造一个箱子出来。**PhysicsControl**（物理控制）是管皮带启停的部件。**Logic Gate**（逻辑门）是把几个信号按“与／或／非”拼起来的小逻辑块。

### 怎么做

1. **导传送带**：新工作站，Home → Import Library → Equipment，选传送带（Patino 用 950×4000），Set Position 放到中间。
2. **做皮带**：Modeling → Solid → Box，画一个当皮带，起名 Belt，放到传送带顶上。
3. **做箱子**：再画两个 Box，小箱 200×200×100（橙色）、大箱 200×200×200（绿色），放到传送带一头；大箱先隐藏。
4. **移箱子本地原点**：每个箱子用 Set Local Origin + Snap End，把本地坐标系移到箱子顶部。不移的话，开了物理后箱子会穿透皮带（Patino 原话的教训）。
5. **皮带加物理**：Physics → Behavior → Fixed；再用 Surface Velocity，打开速度、方向沿 +X。
6. **建 Smart 组件**：新建 Smart Component，起名如 `SC_Conveyor`，把箱子和传送带都拖进去。再挂这些子组件：
   - 两个 Source：一个造小箱、一个造大箱（开 Transient，箱子到头就删；开 dynamic transition，箱子带物理、会受重力掉下来）；
   - 一个 PhysicsControl：管皮带启停；
   - 两个 Line Sensor：下传感器 X 偏移 −60 mm、Y +50 mm（到小箱中部高度）；上传感器 X 同样 −60 mm、Y +150 mm（只碰大箱）；
   - 一个 Logic Gate：连信号管皮带启停。
7. **接 I/O**：Design 窗口里建数字输入（造小箱、造大箱）和数字输出（上传感器、下传感器）。
8. **接线**：Source 由输入信号触发；传感器输出一亮，皮带经 PhysicsControl 停下。
9. **测试**：先把箱子隐藏，保存仿真初始状态，起名 “Simulation Start”；打开 I/O Simulator，点按钮出箱，点 Play 跑，看箱子掉下来、皮带送、传感器一碰就停；停下后 Reset 回初始状态。
10. **保存工作站**：验证没问题再保存整个站。

### 容易错在哪

- 箱子本地原点不移到顶部，箱子会穿透皮带。
- 上传感器高度要够（+150 mm），不然小箱也会触发它，分拣就乱了。
- 测试前先保存 “Simulation Start” 初始状态，不然每次改完都要重摆。

### 和库里其他内容的关系

- 库里没有传送带物理仿真的内容，`references/smart-components.md` 没讲 Physics，这是新的。学完后那篇可以加一节“物理仿真”。

## 第 11 课：取放 + 叠放偏移 + 传感器分拣

**来源视频：** Maurilio Patino 码垛教程 Part 3（视频同第 9 课，文字版全文已读）

### 这是什么

传送带送来大小两种箱子，机器人按传感器判断：小箱放小托盘、大箱放大托盘，叠起来放，一层一层往上码。

**Offs**（偏移）就是在原来点的基础上加个差值，比如往上抬一个箱子高度，这样不用每个位置都重教点。**motion events**（运动事件）是建系统时开的一个选项，开了后面有些功能才能用。

### 怎么做

1. **摆场景**：导机器人底座放传送带对面；导机器人，控制器起名 “Pick and Place”，建系统时打开 motion events 选项；把机器人放到台座上，调高一点、转个方向；更新任务坐标系，让机器人底座坐标系同步。
2. **加组件**：把前面做好的传送带 Smart 组件和夹爪 Smart 组件拖进来；控制器模型放传送带旁边；两边各放一个托盘，开 workspace volume 可视化确认位置摆对了。
3. **托盘加物理**：两个托盘都加物理属性、设成刚性，箱子才不会掉穿托盘。
4. **放参考箱**：大小托盘上各放一个参考箱对轨迹（大箱那个要设成传感器检测不到，不然干扰）。
5. **建 3 个工件坐标系**：传送带一个（取的轨迹相对它）、小托盘一个、大托盘一个（各绑托盘一角）。三点法定工件见第 6 课。
6. **主程序加循环**：同步配置到控制器，主程序加 `while true` 循环，不然仿真自己停了。
7. **教轨迹**：Home 点；取大箱轨迹（取点起名如 Target Large Box，调好工具朝向）；过渡点（取放之间抬高走，防撞）；小箱轨迹照样做；放大小托盘的轨迹各一套。
8. **同步 + 接信号**：所有指令同步到 RAPID；加数字输入（传感器状态）、数字输出（造箱、真空吸放）。
9. **写程序**：Pick and Place 大箱、Pick and Place 小箱两个程序；再写 Create Box 程序，FOR 循环先造 3 个小箱、再造 3 个大箱，中间加延时模拟间隔。
10. **主逻辑**：开头结尾都回 Home；IF 判断：只有下传感器亮 → 走小箱轨迹；两个传感器都亮 → 走大箱轨迹。
11. **叠放**：路径上加偏移（Offs），每放一层往上抬一个箱子高度，不然箱子叠到同一个点。
12. **收尾**：加 WaitTime 让动作顺滑；再同步一次；把控制器和 Smart 组件的信号连上；跑起来验：箱子自动造、机器人按传感器走、取放都对；最后 Reset、保存。

### 容易错在哪

- 参考箱不设成“传感器检测不到”，分拣逻辑会被它干扰。
- 叠放不加偏移，箱子全叠到同一个点上。
- 建系统时 motion events 没开，后面有些功能用不了，要重建系统。

### 和库里其他内容的关系

- `rapid/02_pick_place.mod`：固定取放；这课是“按传感器分拣 + 叠放”的升级版。
- `rapid/04_loops_conditions.mod`：FOR 循环造箱、IF 判断分拣，都是现成模式的组合。
- `rapid/05_coordinates.mod`：一个场景 3 个工件坐标系，是 wobjdata 的实战例子。

## 第 12 课：PLC 发程序号 + Pounce 点 + 故障处理

**来源视频：** Ryan Bliss《Learn to Code ABB Robots to Perform Pick and Place Tasks using Rapid Programming》（19 分钟）
**配套文字材料：** control.com 同主题文字教程《ABB Robot Example Programming Tutorial》（机器人编程系列第 2 篇，2022-03-01，2024-01-08 更新；是同主题文字教程，不是视频逐字稿）

### 这是什么

PLC（可编程逻辑控制器，就是工厂里管整条线的大脑）发一个程序号过来，机器人按号执行对应的程序。机器人先回个收到确认，PLC 对上号才让机器人动手。

**组信号**就是把多个离散信号拼成一个整数：比如 `giCommand`（组输入）收程序号，`goCmdEcho`（组输出）把收到的号原样发回去当回执，`diExe`（数字输入）是执行标志，PLC 置 1 才表示“可以动手了”。

**Pounce 点**是离工装足够远、离干活区足够近的中间点，先到它再进活区，省时间。**Offs()** 是偏移函数，在原来点的基础上加个差值。**No Step 模块**是只做计算、不含运动的模块，示教器上不能单步进里面，代码必须先测好再用。

### 怎么做

**1. 视频的完整流程（章节表）：**

定义工件 → 新建工件 → 三点法 → 原点 → 点动 → 改点位 → 再改点位 → 测工件 → 建 Palette B（托盘）→ 定义点 → 工具对象 → 定义点 → 安全点 → 程序编辑器 → 代码走读 → 应用代码 → 调试。

要点：工件、点位、工具、安全点全部先在示教里定好，最后才进程序编辑器写代码、走读、应用、调试。顺序别反。

**2. PLC 发程序号，机器人按号执行：**

- PLC 通过现场总线（Ethernet/IP、PROFINET、EtherCAT，就是工厂里设备之间传信号的工业网线协议）发一个程序号。
- 机器人用组信号收：`giCommand` 收号；回执用 `SetGo goCmdEcho, nCmd` 把收到的号原样发回去，PLC 对上号才把执行标志 `diExe` 置 1。
- 主循环等执行标志：

```rapid
WHILE diExe = 0 DO
  nCmd := giCommand;
  SetGo goCmdEcho, nCmd;
ENDWHILE
```

也可以用 GOTO 写法：`LoopStart:` … `IF NOT(diExe) GOTO LoopStart;`。

**3. 按号分发（TEST/CASE）：**

```rapid
TEST nCmd
CASE 1:
  FuncFirst();
CASE 2:
  FuncSecond();
DEFAULT:
  TPWrite "Invalid Program" \Num:=diExe;
ENDTEST
```

非法程序号要报出来，别静默跳过。库里 `rapid/08_test_case_functions.mod` 有 TEST/CASE 基础，这里补的是“号从 PLC 来”这一层。

**4. Pounce 点 + Offs 接近：**

- Pounce 点：离工装足够远、离干活区足够近的中间点，先到它再进活区，省时间；示教时确认到 Pounce 点和 Home 点的路上没有任何物理阻挡。
- 从 Pounce 点用 `Offs()` 偏移到最终点：先高速到接近点，最后一段用慢速直线（`fine`）下到取件点，停稳再合夹爪，再原路退回 Pounce 点。
- 文字教程的取件片段：先 `CheckGripper\Empty` 查夹爪是空的 → 开夹爪 → 按零件类型 `GetPosition(\Pick)` 取点 → `MoveL Offs(..., -20, 0, 120)` 接近 → `MoveL Offs(..., -20, 0, -5)` 下探 → `MoveL pPallet_Pick, v500, fine` 到位 → `Gripper\Close`。

**5. 故障处理别省：**

- 每次关键动作后查故障位（`dnFltPend1` / `dnFltPend2`），有故障就 `FaultMsg` → `SetCmdDone` → `RETURN`，别继续往下走。
- 取件失败要能恢复：先确认故障、打开夹爪、抬起来退回接近点和 Home 点，再报错。
- 干循环（没料试跑）要单独留开关（`bDryCycle`），别把无料报警和真故障混在一起。

**6. No Step 模块：**

- 只做计算、不含运动的模块可以设成 No Step：示教器上不能单步进里面，代码必须先测好再用。
- 典型放这里的：`FUNC GetPosition(\switch Pick, \switch Place)`——按零件类型（`TEST nPartType`，CASE 1/2/3）返回不同的取件点，非法类型置故障位、发 `TPWrite "Wrong Part type"`。

**7. World Zone 告诉 PLC 机器人在哪（挂 PowerOn 事件）：**

```rapid
PROC WorldZones()
  WZSphDef\Inside, shp wzHome, pHome.trans, 50;
  WZDOSet\Stat, wzHome\Inside, shp wzHome, doAtHome, 1;
  WZBoxDef\Outside, shp wzDial, poswzDialLow, poswzDialHigh;
  WZDOSet\Stat, wzClearDial\Inside, shp wzClearDial, doClearDial, 1;
ENDPROC
```

- 每个 Zone 要两个数据：`wzstationary`（允许的工作范围声明）+ `shapedata`（范围形状大小）。
- 三种形状：球、盒、圆柱；进 Zone 置输出为真，出范围可停机或反转信号。
- 好处：PLC 不用中断程序流就知道机器人在哪，还能用来恢复到已知安全点。
- 详细做法见第 13 课。

**8. 模块分工（文字教程的习惯）：**

- 主模块：PROC + 全局变量；tooldata、夹爪数据放这里；点位不放这里。
- 运动模块：所有运动 PROC；开头先回 Home/维修点、确认夹爪状态。
- 各模块职责分开，别把点位、逻辑、运动全塞一个模块。

### 容易错在哪

- 非法程序号静默跳过：DEFAULT 里一定要报出来，别什么都不干。
- Pounce 点和 Home 点的路上没确认有没有物理阻挡，示教时先确认。
- 关键动作后不查故障位，有故障还继续往下走。
- 干循环（没料试跑）和真故障混在一起：干循环单独留开关。
- No Step 模块里的代码没测好就用：示教器上不能单步进里面，出错不好查。

### 和库里其他内容的关系

- `rapid/02_pick_place.mod`：固定取放；这课补的是 PLC 调度、Pounce 点、故障处理、No Step 这些实战写法。

## 第 13 课：安全——QuickStop + World Zone 禁区

**来源视频：** Maurilio Patino 码垛教程 Part 4（视频同第 9 课，文字版全文已读）；ABB 官方《RobotStudio® Tutorial – Visualize World Zones》（视频 https://www.youtube.com/watch?v=E0bhSQN46Os）
**学法说明：** 本课的 World Zone 写法以 Patino Part 4 为主。

### 这是什么

单元里有人进来机器人要停；机器人不准进的区域，软件上也要拦住，真撞上围栏之前就停机。

**QuickStop**（快速停机信号）就是一个让机器人立刻停下的信号，比正常停快。**World Zone**（禁区）就是在软件里划一块区域，机器人一进这块区域就报警停机，相当于看不见的围栏。**PowerOn 事件**就是控制器一上电就自动跑的程序，把禁区定义挂在这里，重启控制器禁区就生效。**ISO 10218:2011** 是工业机器人安全标准，围栏、光幕、急停这些东西为什么要有，都是它规定的。

### 怎么做

1. **讲标准**：先看 ISO 10218:2011，知道围栏、光幕、急停这些东西为什么要有。
2. **摆安全件**：围栏围住单元；导急停按钮（.SAT）、状态指示塔、Omron 光幕，放到位：急停按钮放墙上、复制一个放站里；光幕放单元入口（叉车进出的口子），两边都装好。
3. **建急停信号**：新建信号 `StopRobotEmergency`（数字输入）+ 一个恢复信号；建用户信号清单，把两个信号加进去。
4. **接系统输入**：System Inputs 里把启动连到 Run 按钮，新建一个 QuickStop 信号；应用后重启控制器。
5. **演练光幕急停**：先关掉自动序列和过渡选项（不然急停时箱子会消失）；跑仿真、造一个小箱；触发急停信号模拟有人进单元，机器人停住；人“出去”后手动恢复。
6. **建 World Zone（禁区）**：先编一条故意撞围栏的轨迹做测试（点如 Point1、Point2）；定义一个四面体禁区，尺寸 1 m × 4 m × 2 m，红色半透明，放单元后部；用底座坐标系量点来定禁区范围。
7. **写 RAPID**：声明一个静止障碍物变量，写 `MyPowerOn` 程序定义禁区，量好的点当输入；把 `MyPowerOn` 挂到机器人的 PowerOn 事件上，重启控制器。
8. **验证**：再跑那条撞围栏的轨迹，TCP 一进禁区就报警、机器人没撞上就停了；最后机器人回初始位置，保存仿真。

### 容易错在哪

- 演练前不关自动序列，急停一触发箱子就消失了，现象看不出来。
- QuickStop 信号建完要重启控制器，不然不生效。
- World Zone 的点要用底座坐标系量，别用错坐标系，禁区会偏。

### 和库里其他内容的关系

- 新手路线 L14 只有安全文字（手动低速、查碰撞、急停围栏），没有 QuickStop 和 World Zone 的做法；这课补的是能照着做的步骤。
- World Zone 的 RAPID 写法（PowerOn 事件 + 禁区定义）是新东西，库里原来没有。
- 可视化做法见第 14 课。

算会：禁区建好，进禁区就停；QuickStop 触发后恢复顺序对。
## 第 14 课：World Zone 可视化——三种做法，任选一种

**来源视频：** ABB 官方《RobotStudio® Tutorial – Visualize World Zones》（视频 https://www.youtube.com/watch?v=E0bhSQN46Os）
**学法说明：** WorldZones Add-in 的做法来自 ABB 社区帖 + GitHub parasuramsarathi/ABB-WorldZones，是社区材料，不是官方教程原文。

### 这是什么

RAPID 里的 World Zone 定义指令（`WZBoxDef` / `WZCylDef` / `WZSphDef`，分别是定义盒形／圆柱形／球形禁区的指令）直接在工作站里画出来：半透明形状。这样不用跑程序就能看见禁区在哪。

### 怎么做：三种可视化做法，任选一种

1. **工作站里直接显示**：定义好的 Zone 在 3D 图里画成半透明形状。
2. **WorldZones Add-in**：Add-ins → Install Packages，装 `WorldZones-2.0.rspak`，重启 RobotStudio；Utilities 下有 Visualize Zones 和 Robot Position Viewer。来源：ABB 社区帖 + GitHub parasuramsarathi/ABB-WorldZones。
3. **手工画**：Modeling 里建一个盒子当 Zone，透明度约 60%，再在 Simulation 里建碰撞集，机器人碰到 Zone 就报警（社区常用土办法）。

### 容易错在哪

## 第 15 课：认识机器人系统 + 操作模式三档

**来源视频：** 《ABB ROBOT PROGRAMMING PART_1》（5 分 37 秒）
**学法说明：** 标题和时长在多次搜索结果里一致；章节只有“Introduction”（介绍）、“Operating mode”（操作模式）两条。内容以搜索到的章节名加 ABB 官方操作手册的对应讲法交叉核对。

### 这是什么

一套 ABB 机器人分四件：机器人本体（手臂）、控制器（柜子，大脑）、示教器 FlexPendant（手里的操作屏）、电脑上的 RobotStudio（离线编程序、仿真）。程序可以在示教器上写，也可以在 RobotStudio 里写好再传给控制器。

**操作模式**就是机器人现在处在什么工作状态，一共三档：手动低速、手动全速、自动。刚上手只用手动低速和自动这两档，手动全速先别碰。

### 怎么做

1. **认识示教器**：示教器上有触摸屏、摇杆、使能按钮（握着才动，松开就停）、急停按钮。先认这几个件，再碰菜单。
2. **手动模式**：人在机器人旁边，用摇杆点动、示教点位、改程序。手动模式下机器人跑得慢，使能按钮必须一直握着，松手就停。
3. **自动模式**：人离开机器人工作范围，关好围栏门，程序从头跑。自动模式下示教器不点动，机器人按程序全速跑。
4. **切模式**：在示教器状态栏点 QuickSet（快捷设置），进 Mode（模式）一栏选；如果模式被锁了，先点 Unlock 解锁，有的还要输 4 位 PIN 码。切到自动模式会弹确认框，点确认才生效；切模式后电机会先断电再上电，这是正常的，别慌。
5. **切模式之前确认三件事**：人在工作范围外面、围栏门关好、程序已经在仿真里跑通过。手动模式里别直接切自动跑程序。

### 容易错在哪

- 手动模式和自动模式没分清，人在机器人旁边就切自动。
- 切到自动模式发现机器人不动：先看是不是切模式后电机断电了，等它重新上电；再看是不是确认框没点。
- 模式锁住了硬掰：先点 Unlock 解锁，输 PIN 码，不知道 PIN 码就问管设备的人，别自己猜。
- 手动全速当手动低速用：全速档速度很快，新手别碰。

### 和库里其他内容的关系

- 新手路线 L1（系统组成）和 L14（手动低速验证、再切自动）只有概念，这课是能照着做的步骤。
- 第 2 课讲了主菜单、快捷菜单、操作模式、使能与速度，和这课重叠；这课更专，只讲“系统组成＋操作模式怎么切”，两课合起来看不冲突。
- 第 1 课的上锁挂牌和安全操作，和这课切模式前的确认互相照应。

## 第 16 课：示教器最小闭环——建工件、教点、写程序、跑起来

**来源视频：** 《ABB ROBOT PROGRAMMING PART_2》（11 分 44 秒）
**学法说明：** 标题和时长在多次搜索结果里一致；章节名在多个搜索结果里交叉出现过：“Intro”、“Overview”、“Main menu”、“Quick access menu”，以及一串流程章节：“Define Work Objects”、“New Work Object”、“Three Point Method”、“Origin”、“Jogging”、“Modify Position”、“Test Work Object”、“Define Points”、“Tool Object”、“Defining Point”、“Safety Point”、“Program Editor”、“Code Walkthrough”、“Apply Code”、“Debug”。这串章节是按流程排的，不一定是视频里的原顺序。

### 这是什么

在示教器上走完一遍最小闭环：建工件 → 定工具 → 教点 → 写程序 → 跑起来调通。跑通一次，以后每个程序都是这套流程。

**工件**就是告诉机器人“东西放在哪”，程序里的点都挂在工件上，工件一挪，点跟着走，不用重教。**安全点**是机器人平时待的高处、不碰任何东西的位置，进出都先经过它。

### 怎么做

1. **认菜单**：点示教器主菜单（ABB 菜单），找到程序编辑器（Program Editor）、点动（Jogging）、工件（Work Object）、工具（Tool）这几个入口；常用的点动、速度、坐标系切换放快捷菜单（Quick access menu）里，不用每次翻主菜单。
2. **新建工件**：进工件管理，新建一个工件（New Work Object）。
3. **三点法定工件**：用三点法标工件——教三个点：原点（Origin）、X 方向上一点、Y 方向上一点。三个点要拉开距离，别挤在一起；标完点“测试工件”（Test Work Object），看工件坐标系对不对。
4. **定工具**：选好工具（Tool Object），工具尖端（TCP）要标过，没标过的工具先标 TCP（四点法，见第 5 课），再拿来用。
5. **点动到位**：切手动模式，握住使能按钮，用摇杆把机器人点动到要教的位置。先走关节点动到大概位置，再换成直线点动微调。
6. **教点**：位置对了就记一个点（Defining Point）。先教一个安全点，再教工作点。
7. **进程序编辑器写程序**：进 Program Editor，新建模块（Module）和主程序（PROC main）。程序骨架是：先去安全点，再去工作点做动作，最后回安全点。移动用 MoveJ（关节走，快，路径不直，适合空跑）和 MoveL（直线走，路径直，适合靠近工件）。
8. **点位改了就改程序里的点**：点位不准不用重写程序，在程序编辑器里选中那一行点位，点“修改位置”（Modify Position），机器人当前位置就覆盖进去。改完再测一遍。
9. **应用代码**：改完点“应用”（Apply Code），代码才真正生效。没点应用，跑的还是旧代码。
10. **调试跑起来**：先手动低速单步跑（一步一步走，看每一步对不对），没问题再整段跑；跑通了再切自动模式整段跑。哪步不对就停下来，回到第 8 步改点位。

### 容易错在哪

- 点位挂到世界坐标系下：工件一挪全得重教。点位要挂到工件坐标系下。
- 三点法的三个点挤在一起：算出来的工件坐标系不准，点要拉开。
- 工具没标 TCP 就教点：教出来的点全偏。
- 没有安全点：程序一开头就从当前位置直插工作点，容易撞东西。
- 改了点位没点应用：跑的还是旧代码，白调。
- 没单步验证就直接自动跑：先低速单步，再整段，最后才自动。

### 和库里其他内容的关系

- 第 2 课：主菜单、快捷菜单、操作模式已有，这课第 1 步和它重叠，这课重点是后面的建工件、教点、写程序全流程。
- 第 6 课：三点法定工件的完整步骤已有，这课第 2、3 步是它的缩略版，细节以那课为准。
- 第 4、5 课：定义工具和示教器四点法标 TCP 已有，这课第 4 步只讲“要用标过的工具”，不重复步骤。
- 例程 01：MoveJ／MoveL 的写法已有，这课第 7 步是示教器上怎么把这些指令攒成程序。

## 第 17 课：程序结构——任务、程序、模块、例程、数据

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 5 段（视频 https://www.youtube.com/watch?v=hGGkzsT8WEU ，时长 4:36:34）
**学法说明：** 本课内容以 Wolf Robotics《ABB BASIC ROBOTIC PROGRAMMING》4 天线下班手册和 ABB 官方 RU011／IN-RB02／R102 课程大纲为准。

### 这是什么

RAPID 程序是几层套几层：一个任务里跑一个程序，一个程序由模块组成，模块里是例程和数据。结构清楚了，写程序才知道东西该放哪，改程序才知道去哪找。

- **任务（Task）**：控制器里跑程序的单位，一台机器人一般就一个运动任务 T_ROB1。任务和程序是两回事：任务是“谁在跑”，程序是“跑什么”。
- **程序（Program）**：任务里当前装着的整套代码，由一个或多个模块组成；程序指针 PP 指向当前要执行的那一行。
- **模块（Module）**：分两种。程序模块跟着程序走，换程序就换掉；系统模块一直留在控制器里，换程序也不丢，放的是共用的数据和工具定义。
- **例程（Routine）**：模块里真正干活的一段，分三种。PROC 是过程，只管做事不返回值，比如 `PROC main()`、`PROC Pick()`；FUNC 是函数，算完返回一个值，比如算个距离、判个条件；TRAP 是中断例程，出了中断事件才跑（比如急停信号一来就跑），平时不跑。
- **数据（Data）**：分三种。CONST 是常量，写死不变，比如速度、层数；VAR 是变量，程序跑起来会改，比如计数器；PERS 是持久变量，程序停了、重启了值还在，比如产量计数。

### 怎么做

1. **入口 main**：程序从 `PROC main()` 开始跑。main 里别堆满动作，main 只做调度：调 Pick、调 Place、调 Home，动作全放子程序里。这样主程序一眼就能看懂。
2. **写程序的顺序**：先定模块分工（主程序一个模块，取放、焊接各一个模块），再写 main 的调用顺序，最后才填每个子程序里的动作。顺序反了，写到后面全是补丁。
3. **数据放对地方**：共用的数据（工具、工件）放系统模块里，只属于这个产品的放程序模块里。数据还能分“只在自己模块里用”和“哪里都能用”。

### 容易错在哪

- main 里堆几百行动作，出了问题不知道去哪找。
- 数据该用 PERS 的用了 VAR，重启后计数归零；该用 CONST 的用了 VAR，跑着跑着被人改了。
- 系统模块和程序模块分不清，换个程序，共用的工具数据跟着丢了。
- PROC 和 FUNC 混用：要返回值的写成了 PROC，调用的地方拿不到结果。
- TRAP 当普通子程序调，中断逻辑写错，出了事不触发。

### 和库里其他内容的关系

- 新手路线 L3、L5、L11 有结构的概念，例程 01–10 每个文件都是一个 MODULE + PROC main 的活例子；这课把层级链补全，例程里的结构就知道为什么这么分了。
- 例程 08 是 FUNC 的实战，例程 09 里有 ERROR 和 TRAP 的影子，学这课时对照着看。
- 流程控制 IF／FOR／WHILE／TEST 的写法见例程 04 和 08。

## 第 18 课：创建、修改、保存、加载程序——示教器上的日常操作

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 6 段（视频同第 17 课）
**学法说明：** 同第 17 课；示教器菜单的具体叫法以你手柄版本界面为准。

### 这是什么

在示教器上新建程序、改程序、改点位、保存、加载，改完的程序丢不了、换产品能调出来。改程序是日常活，比写新程序更常用。

**ModPos**（改点位）就是：把机器人点动到正确位置，选中那条运动指令，点一下，点位就改成当前位置，不用删了重教。

### 怎么做

1. **新建程序**：示教器进程序编辑器（Program Editor），新建一个程序模块，起个一看就懂的名字（比如产品名 + 工序，别叫 Test1、New2）。程序从 `PROC main()` 开始，先写空架子：main 里只留调用，再慢慢填子程序。
2. **示教点位**：点动机器人到要去的位置，在程序编辑器里新建一条运动指令，点位就记下来了（robtarget）。点位记完马上检查：工具、工件、速度、转弯区这四项对不对，别等整段写完才查。
3. **改点位（ModPos）**：点位不准不用删了重教。把机器人点动到正确位置，选中那条运动指令，点 ModPos，点位就改成当前位置。改完看一眼坐标变没变，确认改的是这条指令、不是旁边那条。
4. **改指令**：选中一行指令可以改参数（速度、转弯区、工具、工件），也可以删行、插行。一段好用的动作复制到别处用，复制完记得改点位名，别两处共用同一个点位名，改错一个全错。
5. **保存程序**：改完马上保存。示教器程序编辑器里保存程序（Save Program），存到控制器硬盘；重要版本再另存一份到 U 盘。保存分两层：存程序（整个程序）和存模块（只存某一个模块），只改了一个模块就存模块，别每次都全存。
6. **加载程序**：换产品时加载别的程序。加载前先确认当前程序已保存，不然改过没存的东西直接丢了。加载分加载程序和加载模块两种，加载模块是给程序加一个现成的功能模块，比如把写好的焊接模块加进来。
7. **删程序**：示教器上删程序只删内存里的程序，不删硬盘上的文件；硬盘上的文件要去文件管理器（FlexPendant Explorer）里删。删之前确认硬盘上有备份。
8. **RobotStudio 里的做法**：电脑上改 RAPID 更方便，改完同步到虚拟控制器（Synchronize to VC）。离线改、在线只改点位，分工别乱。

### 容易错在哪

- 改完程序不保存，直接关机或切程序，改的全丢了。
- ModPos 改错行：机器人停在 A 点，选中的却是 B 点的指令，B 点被改成 A 点的位置。
- 复制粘贴后忘了改点位名，两处指令共用一个点，改一个等于改两个。
- 加载新程序前没保存旧程序，旧程序的修改直接没了。
- 程序模块和系统模块存混了：该进系统模块的共用数据存进了程序模块，换程序就丢。

- 第 16 课（第一段程序、示教点、同步到 RAPID）、`docs/full-pipeline.md`（RobotStudio 建站到仿真）是这课的上游，这课补的是示教器上日常改程序、存程序的操作。
- 点位怎么教、路径怎么建，见第 8 课；点位挂工件还是挂世界，见第 6、7 课。
- 备份整机和恢复系统是另一回事，见第 22 课；这课只讲单个程序的保存和加载。

## 第 19 课：运动指令——MoveJ、MoveL、MoveC、MoveAbsJ，速度和转弯区

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 7 段（视频同第 17 课）
**学法说明：** 同第 17 课。

### 这是什么

四个运动指令分清、会选：空跑用 MoveJ、贴着工件走直线用 MoveL、走圆弧用 MoveC、回零位用 MoveAbsJ；速度和转弯区配对用，靠近工件慢下来、停稳，空跑快起来、拐弯不停。

- **MoveJ（关节运动）**：六个关节一起转，各走最短的路，TCP 走的轨迹是弯的。优点是快、姿态变化大也不怕；用在空跑、换姿态、大范围移动。
- **MoveL（直线运动）**：TCP 沿直线走到目标点，姿态也按直线插补。优点是轨迹直、可预测；用在靠近工件、贴着工件走、焊接、涂胶。缺点是遇到奇异点或够不着会报错，这时别硬改直线，改回 MoveJ 绕过去。
- **MoveC（圆弧运动）**：要两个点：先给一个圆弧中间点，再给圆弧终点，三个点定一个圆弧。用来走圆、倒圆角。
- **MoveAbsJ（绝对关节运动）**：直接给六个关节的角度（jointtarget），不管 TCP 在哪。用来回零位、回安全姿态，位置绝对准。
- **速度（speeddata）**：数字是 TCP 速度 mm/s，v5 到 vmax。常用档：靠近工件 v200，空跑 v1000，精细动作 v50–v100。
- **转弯区（zonedata）**：fine 是精确定位，到点停稳再走下一段；z50／z100 是圆角，到点附近拐弯不停，速度越快、圆角越大。靠近工件、抓放、焊接起弧收弧用 fine，空跑过渡点用 z50／z100。
- **点位数据（robtarget）**：一个点四样东西：位置（x,y,z）、姿态（四元数）、关节姿态（confdata，腕部怎么翻）、外轴位置。姿态不对会报“目标不可达”，换腕部姿态再试，别只改位置。

### 怎么做

1. **MoveJ 写法**：`MoveJ pHome, v1000, z50, tool0;`
2. **MoveC 写法**：`MoveC pMid, pEnd, v500, z10, tool0;` 中间点别跟起终点共线，共线了算不出圆弧。
3. **MoveAbsJ 写法**：目标是关节角度，不是 robtarget。
4. **速度和转弯区配对**：速度别只看数字，还要看转弯区配不配。
5. **示教顺序**：先 MoveJ 到工件附近的安全点，再 MoveL 慢速接近，最后 fine 停稳干活。干完反过来：MoveL 抬起来，MoveJ 回去。

### 容易错在哪

- 全程 MoveL，姿态变化大的段报奇异点或不可达。
- 全程 MoveJ，贴着工件的段轨迹弯了，撞工件或焊偏。
- 靠近工件还用 v1000 + z100，冲过头、撞夹具。
- 该 fine 的地方用了 z50，机器人没停稳就走了，抓放位置偏。
- MoveC 中间点和起终点共线，圆弧算不出来。
- confdata 不对报目标不可达，只改位置不改姿态，越改越偏。

### 和库里其他内容的关系

- 已有：新手路线 L6、L7、例程 01／06／07。这课是 R1 段 7 的版本，结论跟库里一致，没发现说法不一样的地方。
- 示教点、建路径、同步到控制器，见第 8 课；点位挂哪个工件，见第 7 课。
- 外轴运动 MoveExtJ 见第 25 课。

## 第 20 课：运行与调试程序——PP to Main、单步、手动／自动、生产窗口

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 8 段（视频同第 17 课）
**学法说明：** 同第 17 课；示教器菜单的具体叫法以你手柄版本界面为准。

### 这是什么

程序敢跑、会调：先手动单步走一遍，再自动跑；跑偏了知道停在哪、从哪重跑；操作员日常生产用生产窗口，不用进程序编辑器。

- **程序指针 PP**：下一行执行哪句。**运动指针 MP**：机器人正在往哪个点走。正常跑的时候两个指针挨着；单步、暂停、改程序后两个指针会分开，分开时别直接按开始，先把 PP 移到要重跑的那一行。
- **生产窗口（Production Window）**：操作员日常用的界面：开始、停止、看当前程序和状态。操作员不用进程序编辑器改代码，生产窗口就够了。

### 怎么做

1. **PP to Main（程序指针回主程序开头）**：跑程序之前先把程序指针 PP 移回 main 开头。PP 不在开头，程序就从中间跑，动作全乱。每次正式跑之前都先 PP to Main，养成习惯。
2. **手动模式单步跑**：手动模式 + 使能按钮按住，一步一步执行。单步时看三样：机器人往哪走、速度对不对、有没有要撞的东西。单步跑通了再整段跑，整段跑通了再想自动。
3. **从指定指令开始跑**：某一段改过、只想重跑这一段时，把 PP 移到那一段的开头再开始，不用从头跑。但要确认前面的准备动作（比如夹爪状态、工件位置）已经对了，不然从中间跑条件不对。
4. **自动模式**：人出单元、关安全门、确认程序单步跑通过，再切自动。自动模式下使能按钮不用按，机器人按程序自己跑。切自动之前先确认：工件在位、夹具没松、程序是最新的。
5. **停机和复位**：暂停是停住、还能接着跑；停止是停住、PP 可能要重设；程序复位是 PP 回开头。停机后先看事件日志（Event Log）报了什么，再决定是接着跑还是复位重跑。
6. **跟操作员说话（TPWrite / TPReadFK）**：程序里用 `TPWrite` 在示教器上显示一句话（比如“放料完成，换托盘”），用 `TPReadFK` 让操作员按功能键回答（比如“换好了，继续”）。提示写清楚，操作员才知道下一步干什么。

### 容易错在哪

- 不 PP to Main 就按开始，程序从上次停的地方接着跑，动作顺序全乱。
- 单步没跑通就切自动，撞了才停。
- PP 和 MP 分开时直接开始，机器人突然往一个没想到的点走。
- 从中间重跑，忘了前面的准备动作没做（夹爪还夹着上一个工件）。
- 人还在单元里就切自动。
- 停机后不看事件日志就复位重跑，同一个错反复报。

### 和库里其他内容的关系

- 第 12 课（仿真跑通、查碰撞）、第 1 课是这课的上游原则，这课补的是 PP、单步、生产窗口这些具体操作。
- 例程 09 讲了程序里怎么接错误，跑起来报了错先看那篇；`references/troubleshooting.md` 是排错清单，跑不起来时对照着查。
- RobotStudio 里仿真跑程序的流程见 `docs/full-pipeline.md`；这课讲的是示教器上跑，两个地方的操作别混了。

## 第 21 课：IO 信号编程与模拟——SetDO、WaitDI、客户设备接线

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 9 段（视频同第 17 课）
**学法说明：** 同第 17 课。

### 这是什么

信号会用、会等、会模拟：输出信号让设备动，输入信号等设备回话，没设备的时候用模拟信号先把程序跑通；客户设备（PLC、焊机、夹具）接进来，名字对上、时序对上。

- **信号分四种**：数字输入 DI（传感器、按钮发来的 0／1）、数字输出 DO（机器人发出去的 0／1，比如夹爪合、气阀开）、模拟输入 AI（连续量，比如温度、压力）、模拟输出 AO（连续量输出，比如焊机电流给定）。组信号 GI／GO 是把几个数字信号拼成一个数，PLC 发程序号就用组信号。
- **客户设备**：PLC、焊机、传送带这些，接法是机器人和设备互相给信号——机器人说“我取完了”（DO），设备说“我送到位了”（DI）。

### 怎么做

1. **输出指令**：`SetDO doGripper, 1;` 把夹爪信号置 1（合爪），`Reset doGripper;` 置 0（松爪）。`SetDO` 是写死 1 或 0；`Set` 和 `Reset` 是同一回事的不同写法。模拟量用 `SetAO`，给一个数。
2. **等输入指令**：`WaitDI diPartReady, 1;` 等到有料信号变 1 才往下走，没等到就一直等。`WaitUntil` 是等一个条件成立，比如等两个信号同时满足。等信号一定要加超时和处理：一直等不到就报错、提示操作员，别让机器人傻等一夜。
3. **信号在哪配**：信号名是控制器里配出来的（Configuration Editor 里看和改，见第 3 课），程序里用的名字必须跟配置里的名字一模一样，差一个字母就报错。接线之前先在纸上画好信号表：信号名、干什么用、接哪个设备、是输入还是输出。
4. **模拟信号**：没接设备也能调程序。示教器进 Inputs and Outputs 界面，把信号设成模拟（Simulate），手动拨 0／1，看程序走不走分支。模拟是调试手段，记得取消模拟，不然程序等的是假信号。
5. **客户设备编程**：时序要先对好：谁先动、谁等谁、超时多久算故障。第 12 课的 PLC 程序号调度就是标准做法：PLC 发程序号（giCommand），机器人回执（goCmdEcho），再等执行标志（diExe）。
6. **安全信号别混用**：急停、安全门、QuickStop 这些安全信号走安全链，不走普通 IO。普通 IO 程序能改，安全信号不能拿普通指令随便置位。安全的做法见第 1、13 课。

### 容易错在哪

- 信号名写错一个字母，程序编译不过，还以为是逻辑错了。
- WaitDI 不加超时，设备一故障机器人傻等，产线停了没人知道。
- 模拟信号忘了取消，跑起来等的是假信号，动作全乱。
- 输入输出方向搞反：该等的信号写成了输出，该发的写成了输入。
- 安全信号拿普通 IO 指令去置位，安全链被绕过。
- 时序没对好：机器人还没取完，设备就开始送下一个工件，撞在一起。

### 和库里其他内容的关系

- 已有：新手路线 L10、例程 03／10、第 12 课（PLC 程序号调度 + Pounce 点 + 夹爪故障处理）、第 3 课（建完系统配 I/O）。这课是 R1 段 9 的版本，结论跟库里一致，没发现说法不一样的地方。
- 传感器分支分拣（IF 判断大小箱）见第 11 课；真空夹爪的 DI 控制 Attach／Detach 见第 9 课。
- World Zone 挂 PowerOn 事件、用 WZDOSet 告诉 PLC 机器人在哪，见第 13 课；那是 IO 和安全的结合点。

## 第 22 课：备份与恢复、控制器重启、转数计数器更新

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 10 段（视频同第 17 课）
**学法说明：** 同第 17 课；示教器菜单的具体叫法以你手柄版本界面为准。

### 这是什么

改程序、换电池、修机器人之前先备份，出事能恢复；知道什么时候要重启控制器、什么时候要更新转数计数器，更新时别把标定搞丢。

- **备份（Backup）**：存的是整机：程序、系统参数、标定数据、配置。
- **保存程序**：只存单个程序。只改了一个程序，保存程序就够了；要动系统、换硬件、修机器人，必须整机备份。
- **转数计数器（Revolution Counter）**：每个关节记自己转了多少圈，控制器靠它知道关节在哪。换电机、换电池（SMB 电池）、断电太久，计数器会丢，机器人就不知道自己在哪了，表现是点位全偏、报需要更新转数计数器。

### 怎么做

1. **备份**：示教器进 Backup and Restore，点备份，选存到哪（控制器硬盘 hd0a 或 U 盘）。备份之前先确认程序已保存，没保存的修改备份不进去。
2. **什么时候备份**：改程序之前、换工具或工件标定之后、修机器人之前、换电池之前，都先备份。好习惯是每周固定备一份，重要的改动当天就备。备份文件名写日期和改了什么，别全叫 Backup。
3. **恢复**：出事了（程序丢了、参数乱了）才恢复。恢复会把整机状态盖回去，恢复之后新改的东西就没了，所以恢复之前先把现在的程序另存一份。恢复完重启控制器，再手动低速验证一遍。
4. **控制器重启**：示教器菜单里有 Restart。重启分几种：普通重启（热启动，程序和数据都在）、重启后恢复出厂设置之类的大动作别乱点。重启之前先保存程序、确认人在单元外。重启方式选错会丢东西。
5. **更新转数计数器**：示教器进 Calibration 菜单，选更新转数计数器。做法是把每个关节手动点动到标定刻度（关节上的同步标记对齐），再点更新确认。六个关节一个一个来，别跳过。更新完手动低速跑一遍程序验证点位。
6. **转数计数器和标定的区别**：更新转数计数器只是告诉控制器“关节现在在这个刻度”，标定数据（calibration）还在；但如果标定本身丢了或换了机械部件，光更新转数计数器不够，得重新做精标定。分不清的时候先查事件日志、看手册，别硬跑。

### 容易错在哪

- 改程序之前不备份，改坏了回不去。
- 备份了但不知道备到哪了，恢复时找不到文件。
- 恢复之前不另存当前程序，恢复完新改的全没了。
- 重启方式选错，丢了程序或数据。
- 转数计数器丢了还硬跑程序，点位全偏、撞工件。
- 更新转数计数器时关节没对准刻度就点确认，更新完还是偏的。
- 备份和保存程序混为一谈：只保存了程序就去换电池，系统参数没备。

### 和库里其他内容的关系

- 库里没有备份、恢复、重启、转数计数器的内容，这课是新补的缺口。
- 第 18 课讲单个程序的保存和加载，这课讲整机备份和恢复，两课别混了。
- TCP 标定和工件标定见第 5、6 课；转数计数器更新是标定的前置条件，计数器不对，标定也白标。

## 第 23 课：负载辨识 LoadIdentify、时钟计时算节拍

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 11 段（视频同第 17 课）
**学法说明：** 同第 17 课。

### 这是什么

换了工具、换了工件，负载数据要重新辨识，机器人才能算准力、走得稳；用时钟指令量出一个循环要多久，节拍超了知道慢在哪。

- **负载数据**：工具多重、重心在哪、抓的工件多重。控制器要知道这些才算得准加速度和力。负载数据不对，机器人走起来抖、停不准，严重的报过载。
- **时钟指令**：程序里量时间的指令。`ClkReset` 清零、`ClkStart` 开始计时、`ClkStop` 停、`ClkRead` 读出来是多少秒。

### 怎么做

1. **为什么要辨识负载**：换工具、换夹爪、换工件，第一件事就是核对负载数据。
2. **手动填负载数据**：工具数据（tooldata）里有质量、重心、惯量三项。知道厂家给的数就直接填；不知道就别瞎填，走下一步自动辨识。
3. **LoadIdentify 服务例程**：ABB 操作手册里的标准做法。进程序编辑器，运行服务例程 LoadIdentify。条件是：手动模式下有激活的程序，要辨识的工具和负载已经在点动界面里定义好、激活了。
4. **辨识前热身**：先跑一段热身程序，让所有轴都动起来，机器人热了再辨识，精度才好。冷机直接辨识，数据不准。
5. **选辨识对象**：工具负载（tool load）还是工件负载（payload），两个分开辨识。辨识工件负载时，工具要已经标定好；工件 TCP 不动（固定 TCP）的，还要确认工件坐标系已经标定好。
6. **辨识动作**：选辨识方法（质量已知还是未知）、选姿态角度（手册说最好 +90 或 −90 度）。可以先慢速试跑一遍，确认机器人不会撞到东西，再正式辨识。辨识时机器人会自己慢慢动几个姿态、算出负载数据。
7. **确认结果**：辨识完把算出来的质量、重心写进工具数据或负载数据，保存。换工具后跑一遍程序验证：走起来稳不稳、停得准不准。
8. **时钟计时**：`ClkReset` 清零、`ClkStart` 开始计时、`ClkStop` 停、`ClkRead` 读出来是多少秒。量一个完整循环（取料到放料）要多久，节拍超了就一段一段量，看慢在哪一段。
9. **节拍怎么算**：一个循环的总时间就是节拍。量完跟生产要求比：超了就优化——空跑提速、转弯区放大、等信号的时间缩短；别一上来就全段提速，先找到最慢的那一段。

### 容易错在哪

- 换了工具不改负载数据，机器人越走越抖，还以为是程序问题。
- 负载数据瞎填一个数，重心位置是猜的，辨识结果全错。
- 冷机直接辨识，数据不准还不知道。
- 辨识工件负载时工具还没标定，辨识出来的数是错的。
- 辨识时周围有人或有东西挡路，机器人辨识动作撞上去。
- 计时只量总时间，不分段量，慢在哪一段不知道。
- 负载数据改了不保存，重启后又回到旧数据。

### 和库里其他内容的关系

- 库里没有负载辨识和时钟计时的内容，这课是新补的缺口；第 9 课里那句 Snap Gravity 取重心是同一回事的手工做法，这课是自动辨识的标准流程。

- Offs 偏移编程见第 11 课；这课的 ClkRead 是 R102 列的最常用功能之一。

## 第 24 课：基础焊接指令——ArcLStart、ArcL、ArcLEnd，焊缝数据怎么配

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 12 段（视频同第 17 课）
**学法说明：** 同第 17 课。

### 这是什么

会写一段最基础的焊缝程序：空跑到起弧点、起弧、沿直线焊过去、收弧、空跑回来；知道 seamdata、welddata、weavedata 各管什么，焊缝参数去哪改。

- **GMAW 焊接**：熔化极气体保护焊，Wolf 基础班的先修要求写明 GMAW 焊接经验优先——就是说，焊本身的活要先会一点，这课只教机器人怎么走焊缝。
- **seamdata（焊缝数据）**：管起弧和收弧的条件，比如起弧前送气多久、起弧电流多大、收弧怎么收。不同焊缝、不同板厚，seamdata 不一样，先抄手册或师傅给的数，别自己猜。
- **welddata（焊接数据）**：管焊接过程中的条件，比如送丝速度、焊接电压、焊接速度。welddata 是焊缝质量的关键，改一个数焊缝就变样，改之前记下原来的数。
- **weavedata（摆动数据）**：焊缝要摆动（左右摆着焊，焊缝宽一点）才用，设摆动宽度、频率。不摆动的焊缝不用设。

### 怎么做

1. **先确认设备**：焊枪装好、焊丝送丝正常、焊机通电、保护气开了、工件夹紧了、接地接好了。焊接是真动火，安全流程走第 1 课那套：上锁挂牌、确认安全装置、人在单元外再起弧。
2. **焊枪 TCP 要标定**：焊丝尖端就是 TCP，标定方法跟第 5 课的四点法一样。焊枪 TCP 不准，焊缝全偏。焊丝伸出长度变了，TCP 也要重标。
3. **起弧指令 ArcLStart**：焊缝第一段用 `ArcLStart`，不是 MoveL。起弧点要先 MoveJ 空跑到焊缝起点上方，再 MoveL 慢速落到起弧点，最后 `ArcLStart` 起弧。ArcLStart 后面跟两个数据：seamdata（起弧条件）和 welddata（焊接条件）。
4. **中间焊段 ArcL**：焊缝中间的直线段用 `ArcL`，跟 MoveL 一样走直线，但是一边走一边焊。长焊缝分几段 ArcL，每段一个点，点与点之间别跨太大。
5. **收弧指令 ArcLEnd**：焊缝最后一段用 `ArcLEnd`，收弧、停丝、停气。收弧点别直接抬枪，先收弧、等一会儿，再 MoveL 抬起来，不然焊缝尾巴留个坑。
6. **圆弧焊缝 ArcC**：焊缝是圆弧用 `ArcCStart` 起弧、`ArcC` 焊、`ArcCEnd` 收弧，跟 MoveC 一样要中间点。圆弧焊缝的中间点别跟起终点共线。
7. **摆动数据 weavedata**：焊缝要摆动才用，设摆动宽度、频率。不摆动的焊缝不用设。
8. **RobotStudio 里的做法**：ArcWelding PowerPac 里有模板（Arc Default 模板就是 ArcLStart、ArcL、ArcLEnd 这一套），模板里 seamdata、welddata、weavedata、trackdata 都配好了，照模板建焊缝比手写快。离线编好焊缝程序，仿真里先跑一遍看轨迹。

### 容易错在哪

- 焊枪 TCP 没标定，焊缝全偏。
- 起弧用了 MoveL 而不是 ArcLStart，焊机没起弧，空走了一段。
- 收弧直接抬枪，焊缝尾巴留坑。
- welddata 乱改一个数不记原值，焊缝坏了回不去。
- 焊丝伸出长度变了不重标 TCP，焊缝越焊越偏。
- 人在单元里就起弧，或者保护气没开就起弧。
- 长焊缝一段 ArcL 走到底，中间没分段，焊缝质量不均匀。

### 和库里其他内容的关系

- 库里没有焊接内容，这课是新补的缺口；新手路线 L1–L15 里也没有焊接课，焊接是 Wolf 基础班和 RU011 焊接方向的专项内容。
- 运动指令的基础（MoveJ 空跑、MoveL 直线、MoveC 圆弧）见第 19 课，焊接指令就是在这三个指令前面加了起弧、焊接、收弧。
- TCP 标定见第 5 课；点位挂工件、焊缝点位怎么教，见第 6、8 课。
- 进阶焊接（寻位、跟踪、多道焊、焊错恢复）是 Wolf《ABB 高级编程班》的内容，RU011 只讲基础焊接动作，这课只讲基础，进阶的没写。

## 第 25 课：外轴编程与标定——变位机、导轨怎么编

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 13 段（视频同第 17 课）
**学法说明：** Wolf《ABB 基础编程班》手册列的 5 个教学点里没有外轴，外轴是 RU011 Day 4 的内容，这课是按 RU011 大纲补的，不是按视频原文写的。

### 这是什么

知道外轴是什么、什么时候用：工件太大焊一面不够，变位机翻个面再焊；机器人够不着，导轨带着机器人走一段。会写最基础的外轴动作、会标定外轴。

**外轴**就是机器人本体六个轴之外的轴，常见两种：变位机（翻转工件的转台）、导轨（带着机器人走的轨道）。外轴有自己的电机和标定，控制器把它当第七个轴（或更多轴）管。

### 怎么做

1. **什么时候用外轴**：工件大、焊缝在背面，机器人手够不着，变位机把工件翻过来；工件长、机器人行程不够，导轨带着机器人走。搬运小工件用不上外轴，别为了用而用。
2. **外轴运动指令 MoveExtJ**：让外轴自己转到指定角度，比如变位机转 90 度。写法是给外轴目标角度，不是给 robtarget。外轴动作和机器人动作要分开写，别写在同一句里。
3. **机器人和外轴一起动**：焊缝要变位机边转、机器人边焊，叫协调运动。协调运动要先配好，程序里写的是焊缝轨迹，变位机跟着转。协调运动配错了，焊枪和工件各走各的，焊缝全偏。
4. **标定外轴**：跟 TCP 标定一个道理：外轴的零点、方向要标出来。RU011 Day 4 把外轴标定单列，就是因为不标定，外轴转的角度和程序里的角度对不上。标定方法按 ABB 操作手册走，标完验证一遍再用。
5. **点位里的外轴值**：robtarget 里除了位置、姿态、关节姿态，还有一项外轴位置（extjoint）。点位教好后，检查外轴值对不对：变位机在 0 度教的点，变位机转到 90 度再跑，点位就错了。
6. **安全**：外轴动起来力气大、范围大，变位机翻工件时人在单元外。外轴和机器人的联动区域要划禁区，见第 13 课的做法。

### 容易错在哪

- 外轴没标定就编程序，转的角度和程序里的角度对不上。
- 协调运动没配好，焊枪和工件各走各的。
- 点位教的时候外轴在 0 度，跑的时候外轴在 90 度，点位全错。
- 外轴动作和机器人动作写在同一句，控制器不知道先动谁。
- 变位机翻工件时人在单元里，或者禁区没划。

### 和库里其他内容的关系

- 库里没有外轴内容，这课是新补的缺口；这课的依据是 RU011 大纲，不是 R1 视频原文。
- 运动指令的基础见第 19 课，MoveExtJ 是那张指令表里的第五个指令。
- 焊接里用外轴最多，见第 24 课；变位机翻面焊是焊接班的典型场景。
- 基础班（Wolf 5 个教学点）不讲外轴，学完第 24 课先会焊，再学这课；不着急，先知道有这么个东西就行。

## 第 26 课：作业 2——在旋转立方体上定义工件坐标系

**来源视频：** Aleksandar Haber《ABB Robot Studio Tutorial: Definition of Work-object Frames in ABB Robot Studio》（视频 https://www.youtube.com/watch?v=igJmGmmN7xo）
**作业原文：** https://aleksandarhaber.com/homework-assignment-2-2/ （已读原文，7 项任务，截止 2022 年 3 月 14 日）
**学法说明：** YouTube 播放页只返回标题和一句话简介。下面步骤按作业原文第 1、5 项要求 + 第 6 课三点法 + RobotStudio 常规操作拼出来。

### 这是什么

按作业要求，在旋转立方体上定一个工件坐标系：原点在立方体顶面的一角，Z 轴垂直于顶面，X、Y 轴沿着顶面的两条边。定好后，后面画字母的所有点都挂在这个工件坐标系下。

关键差别：第 6 课练手用的是平放的盒子，X、Y 沿着桌面，Z 朝上；这课的立方体是转过的，顶面是斜的，Z 轴必须跟着顶面斜，不能再用世界 Z。

### 怎么做

1. **先建旋转立方体（作业第 1 项，前置步骤）**：Modeling 选项卡 → Solid → Box，建一个立方体，尺寸自己定（作业图里没给数字，图上看着多大就建多大）。选中立方体 → Set Position，把它转一转：绕 X、Y 轴各转一点角度，让它看起来和作业图里一样斜。作业原文只说“转到看起来和图里差不多就行”，没给具体角度，别到处找标准答案，没有。
2. **摆位置**：立方体放到机器人够得着的地方，别摆在机器人手臂伸不到的角落，也别和机器人底座重叠。
3. **开三点法**：建工件坐标系时选三点法（Three-point method）。三个点的顺序是原点、X 方向点、Y 方向点（见第 6 课）。
4. **取三个点（关键）**：都在立方体的顶面上取——
   - 第 1 个点：原点，取顶面的一个角。
   - 第 2 个点：X 轴方向上的点，沿着从原点出发的一条顶面边取。
   - 第 3 个点：Y 轴方向上的点，沿着从原点出发的另一条顶面边取。
   - 三个点定了，坐标系就定了，Z 轴按右手定则出来，应该正好垂直于顶面。
5. **检查方向**：看坐标系箭头对不对：X、Y 沿着顶面的边，Z 垂直顶面往外指。Z 轴如果竖直朝上（和世界 Z 重合），说明点取错了——顶面是斜的，Z 轴也得是斜的。不对就重取，别将就。
6. **定安全点（作业第 6 项）**：离立方体远远的教一个 robtarget 当安全点，后面程序从安全点出发。点要挂到这个工件坐标系下，别挂世界坐标系。
7. **用起来**：后面画字母的目标点全挂到这个工件坐标系下写，程序里用 `wobjdata` 引用它（见第 27 课）。

### 容易错在哪

- Z 轴按世界 Z 定：顶面是斜的，Z 必须垂直顶面；按世界 Z 定，画出来的字母全是歪的。
- 三个点的顺序搞反（原点、X、Y），坐标系就歪了。
- 原点取错角：原点必须是作业图里那个角，取成对角，字母位置全跑偏。
- 立方体转完不检查：转完先从几个角度看看，和作业图差太多就重调角度。
- 点挂到世界坐标系下：立方体一挪，全得重教。

### 和库里其他内容的关系

- 第 6 课：三点法的通用做法（平放盒子练手）；这课是三点法在作业里的实战版——坐标系定在斜顶面上，第 6 课没讲过这种情况。
- 例程 05：只有 wobjdata 的概念和一个平放工作台的例子；这课是能照着做的步骤。
- 第 4 课：工具坐标系三种方法 + Create Tool 向导；按那课先把圆锥末端执行器的工具定好，再定这个工件坐标系（工具 TCP 没标定就定工件，点位全偏）。
- 第 27 课：定好这个工件坐标系后，写程序画字母，接着用。

## 第 27 课：作业 2——圆锥末端执行器 + 写程序画字母

**来源视频：** Aleksandar Haber 作业 2 第 4 个视频（视频 https://www.youtube.com/watch?v=ng_R2LRGL8o）
**作业原文：** https://aleksandarhaber.com/homework-assignment-2-2/ （已读原文，7 项任务）
**学法说明：** 这课的内容方向是推测：下面内容按作业页上 4 个视频的顺序推断：前 3 个是 H1（点动）、H3（工具坐标系 + 基础建模）、H5（工件坐标系），剩下的作业任务只有第 6 项安全点和第 7 项写程序画字母；作者站 2022 年 2 月归档里也有一条简介写着“讲怎么写一段让末端执行器动的简单代码”（疑似 H6 的简介）。所以这课按“作业第 2–4、6、7 项”写：建圆锥末端执行器、装到法兰上、定义工具、定安全点、写程序画字母。圆锥和工具的具体操作按第 4 课 + RobotStudio 常规操作拼。

### 这是什么

做完作业剩下的部分：建一个圆锥当末端执行器（就当一支笔），装到机器人法兰上，TCP 定在圆锥尖端；从安全点出发，让笔尖在立方体顶面的工件坐标系 X-Y 平面里画出自己名字的前两个字母，跑仿真验证。

### 怎么做

1. **建圆锥（作业第 2 项）**：Modeling 选项卡 → Solid → Cone，建一个圆锥。底面直径和高度作业图里没给数字，按图上比例自己定；尖端朝下，指向工件——笔尖就是干活的那头。
2. **装到法兰上（作业第 3 项）**：Modeling → Create Tool，起个名字（比如 tCone），选 Use Existing，选刚建的圆锥几何。Layout 里把工具拖到机器人上，弹窗点 No（让它自动摆正位置）。装完检查：圆锥底面贴着法兰，尖端朝外，别装反。
3. **定义工具坐标系（作业第 4 项）**：TCP 定在圆锥尖端。Home → Paths&Targets → tooldata 文件夹，右键工具 → Modify Tooldata，TCP 的位置填法兰安装面到尖端的距离（沿工具 Z 轴量，工具 Z 轴从手腕向外指）。只有一个 TCP 就留默认名，别手改出两个 TCP 互相混。详细三种方法见第 4 课。
4. **定工件坐标系（作业第 5 项）**：按第 26 课，在旋转立方体顶面用三点法定工件坐标系。顺序别反：先标工具，再定工件——工具 TCP 没标定就定工件，点位全偏。
5. **定安全点（作业第 6 项）**：离立方体远远的教一个 robtarget（比如 pSafe），程序从它出发，画完也回它。点挂到工件坐标系下，别挂世界坐标系。
6. **教画字母的点**：在工件坐标系的 X-Y 平面里（也就是立方体顶面上），按字母笔画教一串点。点动用 Jog Linear 沿工件坐标系走，Home → Teach Target 记点；也可以 Home → Target → Create Target 按数值直接建点。每个字母的笔画起笔处要抬笔（Z 抬起来走），落笔再画，别拖着笔尖走，笔画之间会多一条线。
7. **写程序**：结构照下面来（点位是教学值，在仿真里重新示教）：

```rapid
MODULE Module1
    PROC main()
        MoveJ pSafe, v500, z50, tCone\WObj:=wobjCube;
        ! 下面画第一个字母：落笔走直线，笔画之间抬笔
        MoveJ pLetter1Start, v500, fine, tCone\WObj:=wobjCube;
        MoveL pLetter1P2, v100, fine, tCone\WObj:=wobjCube;
        MoveL pLetter1P3, v100, fine, tCone\WObj:=wobjCube;
        ! 画第二个字母，同理
        MoveJ pSafe, v500, z50, tCone\WObj:=wobjCube;
    ENDPROC
ENDMODULE
```

   要点：空中赶路用 MoveJ，贴顶面画线用 MoveL；画线速度放慢（比如 v100），zone 用 fine（必须走到位）；工具和工件用 `\WObj:=` 指明，别漏。
8. **同步 + 跑仿真**：右键 T_ROB1 → Synchronize to VC，再 Simulation → Simulation Setup，把主程序加进序列，点 Play。先看笔尖轨迹对不对、字母画没画出来，再看有没有撞立方体。

### 容易错在哪

- 圆锥装反：尖端朝里、底面朝外，TCP 全错。
- TCP 位置量错：量的是法兰安装面到尖端的距离，不是圆锥高度随便填一个数；工具 Z 轴方向搞反，TCP 会跑到机器人手臂里面去。
- 工具没定就定工件：顺序反了，工件坐标系是拿这个工具的 TCP 去点的，TCP 不准，工件也跟着偏。
- 笔画之间不抬笔：字母之间多一条连线。

## 第 29 课：TCP 的方向——Z 轴和 X 轴朝哪、朝错了会怎样

**来源视频：** ABB《Setting up Tool TCP》（视频 https://www.youtube.com/watch?v=vsSfa-enwgw ；描述原文：“Learn how to set up the origin of a tool coordinate system, the Tool Center Point, for SWIFTI™, the CRB 1100 and CRB 1300 robot systems.”；频道据第三方课程页标注为 ABB Robotics）
**引用上下文：** Maurilio Patino《ABB RobotStudio - Industrial Palletizing Robot - Sorting and Pick&Place Tutorial》B.2.1 节（“LearnMore about Tool Center Point (TCP) orientations”处挂了这个视频）；方向的三种定法见 ITAR《Hands-on with ABB Robots》（ardavan.io，交叉材料，非视频原文）
**学法说明：** 视频本身讲的是 TCP 原点怎么设，方向的细拆主要靠 Patino 笔记引用它的上下文＋ITAR＋ABB 社区帖子交叉补。

### 这是什么

搞清 TCP 不只是一个点，还是一个朝向。位置标对了、方向标错了，机器人照样干不好活：吸盘吸不牢、夹爪夹偏、焊枪角度歪。学完能做到：建工具时把方向一次定对，方向错了能看出来、知道改哪。

**先分清：位置和方向是两回事**

- **位置**：TCP 在哪，比如吸盘底面中心、焊丝头。就是一个点。
- **方向**：TCP 那三个轴朝哪。Z 轴是工具干活的方向，X 轴是工具的“正面”朝哪，Y 轴不用你定，Z 和 X 定了机器人自己算出来（右手定则）。
- 四点法只能算出**位置**，算不出方向。四点法定完，方向默认跟法兰一样。工具要是弯的、斜装的，光做四点法方向就是错的。
- 打个比方：位置是你手指尖碰到哪，方向是你手指朝哪戳。碰到地方对了、手指是横着戳的，按钮还是按不下去。

**默认方向是什么样**

- 没定义工具时机器人用 tool0：TCP 在法兰中心，Z 轴沿法兰法线向外指（从手腕向外，不是向里）。
- 社区说法：tool0 的 X 轴朝下（照做时以 RobotStudio 里实际显示的坐标轴为准）。
- 例程 05 里的夹爪 `tGripper`，tframe 转角写的是 `[1, 0, 0, 0]`，意思就是“方向跟 tool0 一样，没转过”。这个四元数就是方向，位置是前面的 `[0, 0, 120]`，两者分开看。

**Z 轴和 X 轴各管什么**

- **Z 轴＝工具干活的方向**。吸盘：Z 轴要垂直于箱子表面，吸盘才能整面贴上去；焊枪：Z 轴沿着焊丝；点胶：Z 轴沿着针头。Z 轴歪了，工具就是斜着碰工件的。
- **X 轴＝工具绕 Z 轴转了多少，也就是“正面”朝哪**。两指夹爪：X 轴决定夹爪张开的方向对着箱子的哪条边；长方形盒子：X 轴决定机器人从长边夹还是短边夹。
- **什么时候方向无所谓，什么时候有所谓**：
  - 圆头记号笔：绕 Z 转不转都一样，只留默认方向就行。
  - 吸盘：Z 轴必须对，但绕 Z 转多少无所谓（圆吸盘转了还是圆的）。
  - 两指夹爪、长方形工具：Z 和 X 都必须对，转错了就夹到边上。

### 怎么做（在 RobotStudio 里把方向定对，按 Patino B.2.1 的流程，重点在方向）

1. **导模型**：空工作站，导进工具 CAD（.SAT 等）。
2. **先把工具转到干活的朝向，再建坐标系**：这是最关键的一步，顺序不能反。点工具，选 Rotate，把工具转一转，让它摆成干活时的样子——底座露出来、工作端朝向它真正干活的方向。Patino 的目标就是先对齐朝向，再建 Frame。
3. **把底座中心放到世界原点**：用 Place Tool → One Point，选 Snap Center，点工具底座的中心点，Apply，工具就落到世界坐标系原点了。这一步定的是位置基准，不动朝向。
4. **建 Frame**：Frame → Create Frame，参考坐标系选 World，点 Create。这时 Frame 的三个轴就是你第 2 步摆出来的朝向——**方向就是在这一步定下来的**，后面再转模型也没用。
5. **把 Frame 移到 TCP 点上，只平移、别旋转**：量底座到 TCP 的距离（Patino 的吸盘例子量出来是 184 mm，每把工具自己量，别照抄），用 Set Position 填新位置，Apply。只改位置，朝向保持第 4 步的样子。
6. **生成工具**：Modeling → Create Tool，选刚建的 Frame 当 TCP。生成完在 3D 视图里看一眼坐标轴：Z 轴是不是从工作端向外指，X 轴是不是对着工具的正面。
7. **检查方向**：把工具装到机器人上，点动坐标系切到 Tool，沿 Z 轴点动——TCP 应该沿着工具干活的方向直着走；再用 Reorient 转手腕——TCP 点应该原地不动、只有工具绕着它转。两个都对，方向才算对。

### 容易错在哪

- **先建 Frame、后转模型**：Frame 建完朝向就定死了，后面再怎么转模型，TCP 方向都不会跟着变。顺序错了就删了 Frame 重建。
- **四点法标完就以为全对了**：四点法只管位置，工具是斜装的、弯的，必须再用 TCP+Z 或 TCP+Z 和 X 的方法定方向（见第 4 课）。
- **Z 轴指反了**：Z 轴从手腕向外指，指向工件；指成向里的，点动和接近方向全反。
- **把位置和方向混在一起改**：TCP 位置偏了改平移，方向歪了改转角；在 tooldata 里改错地方，越改越乱。先分清是点偏了还是朝向歪了。
- **照抄别人的 184 mm**：那是 Patino 的吸盘自己的尺寸，你的工具自己量。

### 方向错了会怎样（怎么看出来）

- 吸盘落下去只有一边沾上，另一边翘起来，吸不住或者吸上就掉。
- 夹爪夹到箱子棱上，不是夹到面上；或者每次夹的位置都偏同一个方向。
- 沿 Tool 坐标点动 Z 轴，TCP 不沿工具干活方向走，而是斜着走。
- Reorient 转手腕时，TCP 点在空中画圈，不原地不动。
- 教出来的点看着都对，一跑起来所有点的姿态都歪同一个角度——这是工具方向错，不是单个点教错了，别一个一个重教点，改工具方向。

### 和库里其他内容的关系

- 第 4 课：**已有**，RobotStudio 里定义工具的三种方法（TCP 四点 / TCP+Z / TCP+Z 和 X）+ Create Tool 向导步骤；这课不重复那张表，只讲那张表背后的“为什么”——方向是什么、错了长什么样。
- 第 5 课：**已有**，示教器四点法标 TCP 的完整流程＋验证；这课补它的缺口——四点法只定位置，方向要另定。两课关系：先用四点法定位置，再按需用 TCP+Z / TCP+Z 和 X 定方向，最后都用“固定点＋转手腕验证”。
- 例程 05 和新手路线 L9：**已有概念，没有步骤**。05 只写了 tooldata 概念和 `[1, 0, 0, 0]` 这个默认方向；L9 只有一句话“工具 TCP 要标定”。这课是方向部分的步骤和检查法。
- Patino 笔记 B.2.1：**已有流程，这课是它的方向解读**。Patino 原文只写了操作（转模型、放原点、建 Frame、移 184 mm），没讲为什么顺序是先转后建、方向错了会怎样，这课补的就是这部分。
- **说法不一样**：没有直接冲突。注意两点：一是 tool0 的 X 轴朝下是社区说法；二是 Patino 原文的目标朝向只给了图、文字没写清是哪个轴朝哪，照做时以图和 RobotStudio 里的坐标轴显示为准。

### 新手怎么按顺序看

结合库里 15 课新手路线（L1–L15），建议分三步，别按 P2 到 P6 的编号顺序硬看：

1. **先看英语短课，建立整图（P6 → P5）**：P6 的 EP1–EP6 一口气看完，知道坐标系、运动类型、工具、工件是怎么回事；再看 P5 的第 1、3、8、9、10 条，动手装好、建站、建工件、加点跑起来。这一步对应库里 L1–L4、L6、L9。
2. **再啃西语大课，补 RAPID 和实操（P3 → P2 前半 → P4 前半）**：P3 按顺序看，RAPID 从数据、流程、循环、运动、IO 一路学下来，对应库里 L5–L11 和例程 01–08；然后看 P2 第 1–18 条（建站到 IO）和 P4 的 Lab 1–9（轨迹、示教器、偏移），边看边在 RobotStudio 里照做。西语听不懂就开自动翻译字幕，重点看画面操作。
3. **最后按需挑进阶（P2 后半、P4 后半）**：要做码垛看 P2 第 31、34 条和 P4 第 15–18、24 条（对应库里 11 号例程和 Patino 码垛草稿）；要玩双机器人、导轨、变位机看 P4 第 17、19–22 条；要接 PLC 和做示教器界面看 P2 第 19、29 条。看完一步就在 RobotStudio 里跑通一步再往下走，别只看视频攒进度。

### 容易错在哪

- 按 P2 到 P6 的编号顺序硬看：西语大课在前，英语短课在后，顺序反了，先看英语短课建整图。
- 只看视频攒进度：看完一步就在 RobotStudio 里跑通一步再往下走，别只看不练。

- 西语听不懂就卡住：开自动翻译字幕，重点看画面操作。
