# 术语表 — Robot-RAPID

一个词一句话，以后回答用词一致。术语以 ABB RAPID 手册的叫法为准。

- **tooldata**：工具数据，工具中心点（TCP）位置 + 负载（质量、重心、惯量）。
- **wobjdata**：工件数据，工件坐标系的位置和朝向，程序里的点都挂在它上面。
- **robtarget**：直角坐标目标点，位置（x、y、z）+ 姿态（四元数）+ 外轴值 + 机器人姿态。
- **jointtarget**：关节目标点，六个关节角 + 外轴值，直接定姿态。
- **TCP**：工具中心点，工具上干活的那个点，标定就是算出它在哪。
- **fine**：精确定位，机器人到点停稳了再走下一步。
- **z50 / z100**：转弯区，数字越大拐弯越圆、越不停；z50 是常用的过渡值。
- **MoveJ**：关节插补，快，空走、换姿态用它。
- **MoveL**：直线插补，贴着工件走直线用它。
- **MoveC**：圆弧插补，走圆弧要给中间点和终点。
- **MoveAbsJ**：按六个关节角直接到位，回零、定姿态用它。
- **SetDO / WaitDI**：写数字输出信号 / 等数字输入信号变到指定值。
- **WaitUntil**：等一个条件成立再往下走。
- **PERS**：长久变量，程序停了、控制器重启了值还在。
- **VAR**：普通变量，只在程序跑的时候有效。
- **PROC**：例程，一段程序；`PROC main()` 是主程序入口。
- **MODULE**：模块，装例程和数据的容器。
- **Smart Component**：Smart 组件，RobotStudio 里带逻辑的组件（信号一来就动作）。
- **虚拟控制器**：RobotStudio 里仿真用的控制器，不接实体机器人。
- **Check Program**：RobotStudio 的程序检查，控制器认不认以它为准。
- **示教器**：FlexPendant，拿在手里点动、教点、改程序的那个屏。
- **I/O**：输入输出信号，机器人和外部设备（夹爪、传感器、PLC）说话的线。
