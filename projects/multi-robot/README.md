# 三机器人联动项目：一个控制器三台机器人，同步抬一件长工件

工厂里用在哪：长梁、车门框、大板件这种一台机器人抬不动或会变形的工件，要多台机器人一起抬、一起搬；还有焊接线上一台翻工件、几台同时焊。学会以后能写 MultiMove 程序：三台机器人各跑各的任务，在碰头点等齐，然后同步运动，同时起步、同时到点。

代码三份，各载入一个运动任务：`multi_robot.mod`（T_ROB1）、`multi_robot_t2.mod`（T_ROB2）、`multi_robot_t3.mod`（T_ROB3）。指令写法按 ABB《Application manual - MultiMove》（3HAC089689-001）第 6 章“Programming”：

| 指令 / 数据 | 解决什么问题 |
| --- | --- |
| `PERS tasks all_tasks{3}` | 参与同步的任务名单，三个任务里一模一样 |
| `VAR syncident sync1` … | 同步点的名字，三个任务里同名才对得上 |
| `WaitSyncTask sync1, all_tasks` | 碰头：先到的等后到的，全到齐再往下走（半协调） |
| `SyncMoveOn sync2, all_tasks` | 开始同步运动 |
| `MoveL pLift \ID:=10, …` | 同步段里每句运动都带 `\ID`，三台相同 ID 的那句同时起步、同时到点 |
| `SyncMoveOff sync3` | 结束同步，三台恢复各走各的 |

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，摆三台 IRB 120，左、中、右一字排开，间隔 400 mm（教学值）。
2. 从布局创建系统，三台机器人放进同一个系统；选项里勾 MultiMove Coordinated（604-1）——修改选项时在 Options 选项卡的 Motion Coordination 里选。系统会自动建 T_ROB1、T_ROB2、T_ROB3 三个运动任务。
3. 摆工件：三台机器人前方摆一根长梁，三台各负责一段。
4. 装夹爪：每台一个，TCP 在夹爪尖端，法兰下 120 mm（教学值）。
5. 标定：每台标自己的工具；各建一个 `wobjPart`，原点在本机器人负责的那段工件顶面。
6. 示教：每台在自己的 `wobjPart` 里示教 pAbove、pGrip、pLift、pCarry、pPut、pHome。三台的 pLift → pCarry → pPut 位移方向和距离要一样，工件才不会被扯歪。
7. 配 IO：按第 ② 节。
8. 三个 .mod 分别加载进三个任务，三个任务 PP 都移至 main，一起启动。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diPartReady | 数字输入 | 工件到位，1 = 到位（只由 T_ROB1 看） |
| doGrip1 | 数字输出 | 机器人 1 夹爪，1 = 夹紧 |
| doGrip2 | 数字输出 | 机器人 2 夹爪，1 = 夹紧 |
| doGrip3 | 数字输出 | 机器人 3 夹爪，1 = 夹紧 |

## ③ 仿真方法

1. 三个任务一起启动，T_ROB2、T_ROB3 很快停在 `WaitSyncTask sync1`；手动把 `diPartReady` 置 1，T_ROB1 也到了，三台一起往下走。
2. 三台各自下到抓取点合爪，然后在 `SyncMoveOn` 处等齐。
3. 看同步段：ID 10、20、30 三句，三台同时起步、同时到点——这就是同步成功。
4. 把 T_ROB3 的 pCarry 故意改远一点，再跑：三台照样同时到点，T_ROB3 自动走得快一些。
5. `SyncMoveOff` 之后三台各自松爪回原位，最后在 `sync4` 碰头，开始下一件。
6. 打开三台的 TCP 轨迹跟踪，看三条搬运轨迹是不是平行。

## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| 三台一直卡在 `WaitSyncTask` | 有一个任务没启动，或任务名单里的名字和控制器里的任务名对不上 | 看三个任务是不是都在运行；对任务名大小写 |
| `SyncMoveOn` 报错 | 三个任务里 syncident 名字不一样，或任务名单不一样 | 三个文件里同步标识、任务名单必须一模一样 |
| 同步段报 ID 不匹配 | 三个任务同步段里运动指令条数或 `\ID` 对不上 | 每个 ID 在三个任务里各出现一次，条数一样 |
| 运动指令带 `\ID` 报错 | 这句在同步段外面（不同步时不许带 `\ID`） | 只在 SyncMoveOn 和 SyncMoveOff 之间写 `\ID` |
| 没有 SyncMoveOn 这条指令 | 系统里没装 MultiMove 选项 | 修改系统选项，加 MultiMove Coordinated |

## ⑤ 安全检查

跑之前逐条过：

- [ ] 三台的工具 TCP 各自标过。
- [ ] 三台的点位全部按自己工作站重新示教。
- [ ] 三个文件里 syncident、任务名单、`\ID` 一一对上，确认后再启动。
- [ ] 同步段三台位移方向、距离一致，确认不会互相拉扯工件。
- [ ] 开碰撞检查，确认三台机器人之间、和工件之间不碰撞。
- [ ] 先把速度调低跑一遍，确认同步正常再提速。

## ⑥ 怎么学这个项目

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4、L6–L7、L9、L11（程序结构）。
2. 读 `docs/advanced-topics.md` 第 2 课：两台机器人碰头、同步的最小例程。
3. 读本项目三个文件：先对比三份的同步标识和任务名单（一模一样），再看各自的点位和夹爪信号（各不相同）。
4. 动手：按第 ① 节搭站，按第 ③ 节逐条看现象。
