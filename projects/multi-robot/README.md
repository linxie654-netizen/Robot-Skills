# 三机器人联动项目：三台机器人一个控制器，配合搬一件大工件

状态：这是骨架：思路照 `docs/advanced-topics.md` 第 2 课（多任务）写，需要 623-1 Multitasking 选项，要全程一起动，还需要 MultiMove 选项；同步和协调动作的写法按手册补齐，补完在仿真里跑。

三个任务：T_ROB1、T_ROB2、T_ROB3，各带一台机器人。同步靠 `WaitSyncTask` 碰头，协调动作靠 `SyncMoveOn / SyncMoveOff` 包起来，协调动作里每句 Move 都带 `\ID`，三台机器人相同 `\ID` 的动作是一对。

代码在 `multi_robot.mod` 里：一个文件写了三个任务的 PROC，各任务的模块里只留自己那一份，main 里只调自己机器人的 PROC，别把三台的都调了。

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，摆三台机器人（教学设定：三台都够得着同一件大工件，分别抬左端、中间、右端），启动虚拟控制器。
2. 确认选项：控制器里要有 623-1 Multitasking 选项，全程一起动还要 MultiMove 选项，加选项的办法按 RobotStudio 的改选项流程走。
3. 建三个任务：T_ROB1、T_ROB2、T_ROB3，各带一台机器人，类型先全用 NORMAL（调试方便，调好了再按 `docs/advanced-topics.md` 第 2 课改后台任务类型）。
4. 摆工件：在三台机器人中间摆一件大工件（教学值），三台机器人各抬一头，工件重量在三台负载加起来以内。
5. 装工具：每台机器人装一个夹爪，TCP 各标各的。
6. 标定：每台机器人标自己的工具 TCP，工件位置三台要对得上——工件一动，三台的点位都要跟着改。
7. 示教点位：每台机器人示教自己的抬起点、搬运目标点、安全点，逐个示教。注意：三台搬运的目标点位移要一样（都往同一个方向挪同样的距离），不然工件会被扯坏。
8. 配 IO：按下面第 ② 节的表配好信号，名字和代码里的一模一样。
9. 把 `multi_robot.mod` 分成三份，各任务的模块里只留自己那一份，同步点和任务名单三份要一模一样。先手动低速跑一遍，再切自动。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diPartReady | 数字输入 | 工件已就位、可以开始搬，1 = 就位 |
| doGrip | 数字输出 | 夹爪，1 = 夹紧，0 = 松开（三台机器人各接各的夹爪，信号名按自己系统分开配） |

一共 2 个信号（按信号名算）。三台机器人的夹爪信号在自己的系统里要分开配（比如每台一个 `doGrip`），这里只写一个名字当例子，名字对不上就按自己系统改。

## ③ 仿真方法

1. 虚拟控制器里三个任务都加载好，先把速度改低（比如全改成 v100），再点运行。
2. 看同步：三台机器人跑到 `WaitSyncTask sync1` 是不是都停下等人齐了再往下走；跑到 `SyncMoveOn sync2` 之后是不是同时起、同时停。
3. 看轨迹：三台机器人抬着工件一起走的路直不直，工件有没有歪、有没有被扯。
4. 看 IO：手动把 `diPartReady` 置 1，看三台动不动；看三台的夹爪是不是都夹紧了再抬。
5. 看碰撞：开碰撞检查，看三台机器人互相之间、机器人和工件、机器人和围栏有没有撞。重点看三台机器人之间的距离，离得太近会撞臂。
6. 都顺了，再把速度一档一档往上加，连续跑三遍。

## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| 三台在同步点一直等，卡死 | 同步点名字对不上、任务名单 `all_tasks` 里的任务名和控制器里建的名字差一个字母、某个任务没启动 | 对三份模块里的 `syncident` 和 `all_tasks`，一模一样才行；看三个任务是不是都启动了 |
| 协调动作各走各的，不一起动 | `SyncMoveOn / SyncMoveOff` 没包住、`\ID` 没配对 | 看协调动作是不是都在 `SyncMoveOn` 和 `SyncMoveOff` 之间；`\ID` 是不是 10 对 10、20 对 20、30 对 30 |
| 工件被扯歪了 | 三台目标点的位移不一样、某台机器人够不着 | 看三台目标点的位移是不是一样大、同一个方向；够不着的那台把工件往跟前挪 |
| 某台机器人报“目标不可达” | 那台机器人离工件太远、腕部姿态不对 | 把那台机器人往工件跟前挪；换姿态重新示教 |
| 三台机器人互相撞臂 | 三台摆得太近、轨迹交叉 | 把三台摆开一点；改轨迹，错开走 |
| 抬起来工件掉了 | 某台夹爪没夹紧、夹爪信号没分开配 | 看三台夹爪是不是都夹紧了；夹爪信号按每台分开配 |

## ⑤ 安全检查

跑之前逐条过，缺一条都不开自动：

- [ ] 三台机器人、工件都在围栏里，围栏门关好，工作站里没有人。
- [ ] 三台机器人之间的距离够，互相不会撞臂。
- [ ] 每台工具 TCP 各标各的，夹爪都装紧了。
- [ ] 点位全是重新示教的，没照抄教学值。
- [ ] 先在仿真里跑一遍、碰撞检查过，确认没问题再开自动。
- [ ] 先手动低速跑一遍，确认三台同步、工件不歪再切自动。
- [ ] 工件重量在三台负载加起来以内，三台夹紧了再抬。
- [ ] 急停按钮能按到，急停后三台都停得住。
- [ ] 同步点名字、任务名单三份模块一模一样，差一个字母都不开自动。

## ⑥ 怎么学这个项目

零基础从这一步开始：

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4：建站、启动虚拟控制器、示教点位。
2. 再学 L6–L7：MoveJ / MoveL、速度和区域。
3. 再学 L10：SetDO / WaitDI，对应 `rapid/03_io_signals.mod`。
4. 先读 `rapid/02_pick_place.mod`：一台机器人取料 → 放料是怎么写的。
5. 再读 `docs/advanced-topics.md` 第 2 课：多任务是什么、`WaitSyncTask` 碰头、`SyncMoveOn / SyncMoveOff` 包协调动作、`\ID` 怎么配对。
6. 再读 `multi_robot.mod`：三台机器人的 PROC 长得差不多，差在哪（点位不同、`\ID` 一样），为什么 main 里只调自己那一份。
7. 最后动手：在 RobotStudio 里按第 ① 节搭一遍，先建两个任务碰一次头（照进阶课的骨架），跑通了再加到三个任务。三个任务跑通了，再试三台一起抬工件。
