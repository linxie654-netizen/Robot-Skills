# 输送带跟踪项目：皮带不停，机器人跟着工件走、边走边取

工厂里用在哪：食品、日化、电子行业的流水线拣选和装箱——皮带一直在走，机器人追上工件抓起来放进托盘或箱子，生产线不用停。学会以后能写一套完整的跟踪取件：激活输送带、等工件进启动窗口、跟着皮带抓取、离开并断开。

代码在 `conveyor_tracking.mod`，指令写法按 ABB《Application manual - Conveyor tracking》（3HAC050991-001）第 6 章“Programming”和第 8 章 RAPID 参考：

| 指令 / 数据 | 解决什么问题 |
| --- | --- |
| `ActUnit CNV1` / `DeactUnit CNV1` | 激活 / 停用输送带机械单元 |
| `wobjdata` 里 `ufprog:=FALSE`、`ufmec:="CNV1"` | 让工件坐标系跟着输送带动，点位示教在工件上，皮带走多远坐标系就跟多远 |
| `WaitWObj wobjCnv1` | 等工件过同步开关、进启动窗口，连上以后才开始跟 |
| `\Inpos:=followTime`（stoppointdata） | 在取件点跟着皮带走一小段，夹爪有时间合上 |
| `DropWObj wobjCnv1` | 断开工件；前一句必须是固定坐标系里的 fine 点（手册写明这是结束跟踪的唯一办法） |
| `ConfL\Off` | 跟踪时关掉线性姿态监控（手册例子同样这样写） |

文件末尾 `PickStopBelt` 是另一种写法：控制器没有 Conveyor Tracking 选项时，用光电开关停带、取件、再开带。

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，选 IRB 120，从布局创建系统，选项里勾 Conveyor Tracking。
2. 建输送带：用 RobotStudio 的 Conveyor Tracking 选项卡创建输送带（手册第 4 章），机械单元名用 CNV1，设好皮带速度、工件模型和同步开关位置。
3. 标定输送带基坐标系（手册 5.8 节），设定启动窗口（5.9 节）。
4. 摆托盘：在机器人另一侧放托盘，建工件坐标系 `wobjPallet`，原点在托盘顶面一角。
5. 装夹爪：TCP 在夹爪尖端，法兰下 120 mm（教学值）。
6. 示教：跟踪段的 `pCnvAbove`、`pCnvPick` 在 `wobjCnv1` 里示教——先单步跑过 `WaitWObj`，工件连上后停住皮带再示教（手册 6.6 节的做法）。
7. 配 IO：按第 ② 节。
8. 加载 `conveyor_tracking.mod`，PP 移至 main，开皮带，运行。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| doGrip | 数字输出 | 夹爪，1 = 夹紧，0 = 松开 |
| diPartReady | 数字输入 | 停带写法用：料到取料区，1 = 到了 |
| diConvStopped | 数字输入 | 停带写法用：皮带已停稳，1 = 停了 |
| doConvRun | 数字输出 | 停带写法用：皮带走 / 停，1 = 走 |

跟踪写法的编码器和同步开关信号由输送带模块（CTM）接，配置在系统参数里，程序里不写。

## ③ 仿真方法

1. 开皮带，工件一个个流过来；程序停在 `WaitWObj`，工件过同步开关、进启动窗口后继续。
2. 看夹爪：下到工件上方后跟着皮带一起平移，抓住工件以后再抬起——这就是跟踪成功。
3. 看 `pLeave`：离开皮带走到固定点，`DropWObj` 之后再也不跟皮带动。
4. 把皮带速度调快一点再跑，夹爪照样追得上；调太快超出机器人能力，会报工件跑出最大距离。
5. 开 TCP 轨迹跟踪，看取件段的轨迹是一条斜线（机器人下降的同时在跟皮带走）。
6. 把 main 里的 `PickOnBelt` 换成 `PickStopBelt`，对比停带写法：皮带要停一下，节拍变慢。

## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| `WaitWObj` 一直不往下走 | 工件没过同步开关、没进启动窗口、输送带没激活 | 看 `ActUnit CNV1` 执行了没有；看启动窗口设置；看工件队列 |
| 抓取点偏在工件旁边 | 跟踪点没在 `wobjCnv1` 里示教、输送带基坐标系标偏了 | 重标输送带基坐标系；按手册 6.6 节重新示教 |
| `DropWObj` 报错 | 前一句不是固定坐标系的 fine 点 | 把 `pLeave` 那句改成不带 `\WObj:=wobjCnv1`、区域用 fine |
| 机器人追不上工件 | 皮带太快、启动窗口太靠后 | 降皮带速度，或把启动窗口往前挪 |
| `ActUnit CNV1` 报找不到单元 | 机械单元名不叫 CNV1，或系统里没装 Conveyor Tracking | 看系统参数里的机械单元名；加选项 |

## ⑤ 安全检查

跑之前逐条过：

- [ ] 工具 TCP 标过。
- [ ] 输送带基坐标系标过，启动窗口设好。
- [ ] 跟踪点位在 `wobjCnv1` 里示教，固定点位在 wobj0 / `wobjPallet` 里示教。
- [ ] 离开皮带那句是固定坐标系的 fine 点，确认后再跑 `DropWObj`。
- [ ] 先低皮带速度跑一遍，确认夹爪追得上、不撞工件，再提速。
- [ ] 开碰撞检查，确认夹爪不撞皮带、托盘。

## ⑥ 怎么学这个项目

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4、L6–L7、L9。
2. 先读 `rapid/02_pick_place.mod`：固定位置取放一个循环怎么写。
3. 读本项目的 `PickStopBelt`：停带取件，最简单的输送带写法。
4. 再读 `PickOnBelt`：多了 `ActUnit`、`WaitWObj`、跟皮带走的 `wobjCnv1`、`DropWObj`。
5. 动手：按第 ① 节搭站，按第 ③ 节逐条看现象。
