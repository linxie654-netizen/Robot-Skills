# 输送带跟踪项目：传送带不停，机器人跟着动的料取件

状态：这是骨架：写的是“传送带停一下再取”的保守版（等料到、皮带停、再取件），不是动态跟踪。需要 Conveyor Tracking 选项，没这个选项跟踪编不过。

先说清楚：`conveyor_tracking.mod` 里写的是“传送带停一下再取”的保守骨架（等料到、皮带停、再取件），**不是动态跟踪**。动态跟踪要靠选项里的跟踪指令和输送带标定，那些指令名、参数名这里不编、不写，用之前先查跟踪手册。先把保守版在仿真里跑起来，再按跟踪手册补动态跟踪的写法。

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，选 IRB 120，启动虚拟控制器。
2. 确认 Conveyor Tracking 选项：控制器里要有这个选项，没有就先加上，加选项的办法按 RobotStudio 的改选项流程走。
3. 摆传送带：在机器人前方摆一条传送带，取料区大概在机器人前方 300 mm 的位置（教学值）。
4. 摆托盘：在机器人另一边放一个托盘，托盘顶面一角当放料原点。
5. 装传感器：在取料区装一个光电传感器（料到了就亮），接 `diPartReady`；再装一个皮带停稳的反馈信号，接 `diConvStopped`。
6. 装工具：装一个夹爪，TCP 标在夹爪尖端，法兰下 120 mm。
7. 标定：先标工具 TCP，再建两个工件坐标系——`wobjConv` 原点在传送带取料点，`wobjPallet` 原点在托盘顶面一角。动态跟踪还要标输送带，标定方法按跟踪手册走。
8. 配 IO：按下面第 ② 节的表配好信号，名字和代码里的一模一样。
9. 把 `conveyor_tracking.mod` 加载进控制器，先手动低速跑一遍保守版。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diPartReady | 数字输入 | 料到了取料区，1 = 到了 |
| diConvStopped | 数字输入 | 皮带已停稳，1 = 停了，0 = 在走 |
| doGrip | 数字输出 | 夹爪，1 = 夹紧，0 = 松开 |
| doConvRun | 数字输出 | 皮带走 / 停，1 = 走，0 = 停 |

一共 4 个信号。动态跟踪还要不要别的信号（比如编码器反馈），查跟踪手册。

## ③ 仿真方法

1. 虚拟控制器里加载 `conveyor_tracking.mod`，先把速度改低，再点运行。
2. 看 IO：手动把 `diPartReady` 置 1，看皮带停不停（`doConvRun` 变 0）；把 `diConvStopped` 置 1，看机器人取不取件；取完看皮带走不走（`doConvRun` 变回 1）。
3. 看轨迹：机器人从取料点到托盘走的路直不直，够不够得着。
4. 看碰撞：开碰撞检查，看机器人、夹爪、工件有没有撞传送带、托盘。
5. 看节拍：数一数一件料从到取料区到被取走要多久，皮带停稳要多久，`WaitTime 0.3` 是教学值。
6. 保守版跑顺了，再按跟踪手册学动态跟踪：先在仿真里搭一条会动的传送带，对照着写跟踪指令，再跑动态取件。

## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| 程序卡在 `WaitDI diPartReady` 不动 | 料没到取料区、传感器没亮、信号名配错 | 手动置 1 试试；看传感器位置；对信号名 |
| 程序卡在 `WaitDI diConvStopped` 不动 | 皮带没停稳、停稳信号没回 | 看皮带停没停；停稳信号接没接 |
| 料取起来了，但位置偏了 | 皮带没停稳就动手、料停下时滑了 | 把 `WaitTime 0.3` 改长一点，等皮带彻底停稳再取 |
| 皮带一直停着不走 | 取完没发开皮带、开皮带信号发的方式不对 | 看 `doConvRun` 变回 1 没有；看皮带控制接线 |
| 机器人报“目标不可达” | 取料点超出工作范围 | 把传送带往机器人跟前挪；重新示教取料点 |
| 动态跟踪跑起来跟不上料 | 跟踪指令、输送带标定、皮带速度没配对 | 先回保守版；跟踪的写法和标定按跟踪手册重新对一遍 |

## ⑤ 安全检查

跑之前逐条过，缺一条都不开自动：

- [ ] 机器人、传送带、托盘都在围栏里，围栏门关好，工作站里没有人。
- [ ] 工具 TCP 标过，夹爪装紧了。
- [ ] 点位全是重新示教的，没照抄教学值。
- [ ] 先在仿真里跑一遍、碰撞检查过，确认没问题再开自动。
- [ ] 先手动低速跑一遍保守版，确认皮带停稳再取件。
- [ ] 皮带还在动的时候，机器人绝不伸手进取料区。
- [ ] 动态跟踪的指令、标定按跟踪手册对过，确认没问题再在仿真里试。
- [ ] 急停按钮能按到，急停后机器人、皮带都停得住。

## ⑥ 怎么学这个项目

零基础从这一步开始：

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4：建站、启动虚拟控制器、示教点位。
2. 再学 L6–L7：MoveJ / MoveL、速度和区域。
3. 再学 L10：SetDO / WaitDI，对应 `rapid/03_io_signals.mod`。
4. 先读 `rapid/02_pick_place.mod`：取料 → 放料一个循环是怎么写的。
5. 再读 `conveyor_tracking.mod`：`PickOnBelt` 里为什么要先停皮带、等停稳信号再动手，取完为什么要再开皮带。
6. 最后动手：在 RobotStudio 里按第 ① 节搭一遍，先跑保守版（停带取件）。跑顺了，再按跟踪手册学动态跟踪：搭一条会动的传送带，对照着写跟踪指令，低速试跑动态取件。
