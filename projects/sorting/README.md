# 分拣项目：传送带来料 → 按类型分到 3 个箱子

状态：点位是教学值。机器人是 IRB 120，场景是传送带来料，机器人按类型分到 A、B、C 三个箱子，认不出来的进废品箱。

分法（教学设定）：两个光电信号拼出类型——`diTypeA`=1 是 A 类，`diTypeB`=1 是 B 类，两个都是 0 是 C 类，两个都是 1 算认不出来，进废品箱。

代码在 `sorting.mod` 里：`ReadType` 读类型，`PickPart` 取料，`PlaceByType` 用 TEST 分四路放料。

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，选 IRB 120，启动虚拟控制器。
2. 摆传送带：在机器人左手边放一条传送带，取料点大概在机器人前方 300 mm 的位置（教学值）。
3. 摆四个箱子：在机器人右手边摆 A、B、C 三个箱子加一个废品箱，位置按代码里的 `pBinA / pBinB / pBinC / pBinReject` 来（教学值，够不着就往跟前挪）。
4. 装传感器：在取料点前装两个光电传感器（或一个能出两种信号的识别装置），分别接 `diTypeA` 和 `diTypeB`。
5. 装工具：装一个夹爪，TCP 标在夹爪尖端，法兰下 120 mm。
6. 标定：先标工具 TCP，再建两个工件坐标系——`wobjConv` 原点在传送带取料点，`wobjBin` 原点在分拣区一角。
7. 示教点位：取料点、四个箱子的放料点、安全点，逐个示教。
8. 配 IO：按下面第 ② 节的表配好信号，名字和代码里的一模一样。
9. 把 `sorting.mod` 加载进控制器，先手动低速跑一遍，每种类型各跑一件。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diPartReady | 数字输入 | 取料点有料，1 = 有料 |
| diTypeA | 数字输入 | 类型信号 A，1 = 亮 |
| diTypeB | 数字输入 | 类型信号 B，1 = 亮 |
| doGrip | 数字输出 | 夹爪，1 = 夹紧，0 = 松开 |

一共 4 个信号。类型是 `diTypeA` 和 `diTypeB` 两个信号拼出来的，见上面分法。

## ③ 仿真方法

1. 虚拟控制器里加载 `sorting.mod`，先把速度改低，再点运行。
2. 看 IO：手动把 `diPartReady` 置 1，再分别置 `diTypeA / diTypeB`，看机器人把料放进哪个箱子——A 类进 A 箱，B 类进 B 箱，两个都是 0 进 C 箱，两个都是 1 进废品箱。
3. 看轨迹：机器人从取料点到四个箱子走的路，有没有绕远、有没有走到工作范围边缘。
4. 看碰撞：开碰撞检查，看机器人、夹爪、工件有没有撞传送带、箱子边。重点看最远那个箱子。
5. 看计数：每种类型各跑几件，看 `nCountA / nCountB / nCountC / nCountReject` 数得对不对。
6. 都顺了，再把速度一档一档往上加，连续跑十件。

## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| 程序卡在 `WaitDI diPartReady` 不动 | 料没到取料点、传感器没亮、信号名配错 | 手动置 1 试试；看传感器位置；对信号名 |
| 所有料都进同一个箱子 | `diTypeA / diTypeB` 信号没接对、传感器位置不对 | 仿真里手动置两个信号，看分箱变不变；看传感器装在哪 |
| 料老进废品箱 | 两个类型信号同时亮、传感器抖动 | 看料经过时两个信号是不是同时亮；读类型前加了 0.2 秒等信号稳住，抖得厉害就再加长 |
| 机器人报“目标不可达” | 某个箱子超出工作范围 | 把那个箱子往机器人跟前挪；重新示教放料点 |
| 放料撞箱子边 | 放料点示教偏了、箱子摆歪了 | 重新示教放料点；箱子摆正再跑 |
| 取料时料被带偏了 | 夹爪没夹紧、料在皮带上放歪了 | 看夹爪夹没夹到；把 `WaitTime 0.3` 改长一点试试 |

## ⑤ 安全检查

跑之前逐条过，缺一条都不开自动：

- [ ] 机器人、传送带、四个箱子都在围栏里，围栏门关好，工作站里没有人。
- [ ] 工具 TCP 标过，夹爪装紧了。
- [ ] 点位全是重新示教的，没照抄教学值。
- [ ] 先在仿真里跑通、碰撞检查过，每种类型各跑一件确认分箱对了。
- [ ] 先手动低速跑一遍，确认轨迹没问题再切自动。
- [ ] 传感器装牢了，不会被工件撞掉。
- [ ] 废品箱够大，认不出来的料不会掉地上。

## ⑥ 怎么学这个项目

零基础从这一步开始：

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4：建站、启动虚拟控制器、示教点位。
2. 再学 L6–L7：MoveJ / MoveL、速度和区域。
3. 再学 L8：IF 判断和 TEST / CASE 分路，对应 `rapid/04_loops_conditions.mod` 和 `rapid/08_test_case_functions.mod`。
4. 再学 L10：SetDO / WaitDI，对应 `rapid/03_io_signals.mod`。
5. 先读 `rapid/02_pick_place.mod`：取料 → 搬运 → 放料一个循环是怎么写的。
6. 再读 `sorting.mod`：`ReadType` 怎么用两个信号拼出类型，`PlaceByType` 的 TEST 四路是怎么分的。
7. 最后动手：在 RobotStudio 里按第 ① 节搭一遍，四种类型各跑一件，确认分箱全对。跑通了，把分法改成自己的（比如按颜色、按大小），重新跑一遍。
