# 焊接项目：直焊缝 + 圆弧焊缝，ArcLStart / ArcL / ArcCEnd 弧焊

工厂里用在哪：钢结构件、汽车支架、机架的 MIG/MAG 弧焊工作站。学会以后能自己写一条完整焊缝：飞行起弧、直线段焊、圆弧段焊、到点收弧（填弧坑、回烧、后送气），焊枪摆动，引弧失败自动重试。

代码在 `welding.mod`，指令写法按 ABB《Application manual - Arc and Arc Sensor》（3HAC050988-001）第 8 章 RAPID 参考：

| 指令 / 数据 | 解决什么问题 |
| --- | --- |
| `ArcLStart` | 飞行起弧：走向起焊点的路上提前送气，到点起弧，省节拍 |
| `ArcL` | 沿直线焊，焊速按 welddata 走，不按指令里的 v100 |
| `ArcCEnd` | 沿圆弧焊到终点并收弧（ArcC 多一个圆弧中间点） |
| `seamdata` | 起弧、收弧阶段：送气时间、引弧参数、填弧坑、回烧、后送气 |
| `welddata` | 焊接阶段：焊速、电压、送丝速度 |
| `weavedata` | 焊枪摆动：之字摆的周期长、摆宽（不摆就去掉 `\Weave`） |
| `AW_IGNI_ERR` / `AW_WELD_ERR` | 引弧失败、焊接中断弧的错误号，ERROR 里重试 |

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，选 IRB 120，从布局创建系统。
2. 加弧焊选项：创建系统（或“修改选项”）时，在应用选项里勾 RobotWare Arc，焊机类型选 650-8 Simulated Welder（虚拟焊机，仿真里就能出弧过程）。
3. 摆工件：在机器人前方摆一块平板，焊缝先直走 200 mm，再接一段半圆（教学值，按自己工件改）。
4. 装焊枪：给机器人装焊枪，TCP 标在焊丝尖端，工具 Z 轴和焊枪平行（手册要求）。
5. 标定：先标工具 `tTorch`，再建工件坐标系 `wobjPart`，原点在焊缝起点。
6. 示教点位：接近点、起焊点、直缝中点、圆弧起点、圆弧中间点、收弧点、离开点、安全点。
7. 焊接数据：`seam1`、`weld1`、`weave1` 已写好教学值；也可以在 RobotStudio 程序数据窗口里新建，系统按焊机配置填默认值。
8. 配 IO：按第 ② 节配 `diPartReady`。
9. 把 `welding.mod` 加载进 T_ROB1，PP 移至 main，运行。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diPartReady | 数字输入 | 工件已夹紧就位，1 = 就位 |

送气、起弧、送丝这些焊机信号由 RobotWare Arc 按焊机配置自己管（Arc Equipment 系统参数），程序里不写 SetDO。

## ③ 仿真方法

1. 先单步跑（单步只走轨迹、不起弧），看焊枪沿焊缝走的路线和角度。
2. 手动把 `diPartReady` 置 1，连续运行，看示教器上的弧焊状态：起弧、焊接、收弧依次出现。
3. 打开 TCP 轨迹跟踪，看直线段和圆弧段有没有走偏，摆动是不是之字形。
4. 开碰撞检查，重点看起焊点和收弧点，焊枪离夹具多远。
5. 改 `weld1` 的焊速（比如 10 改 15），再跑一遍，看焊缝那段走得更快——证明焊速由 welddata 控制。
6. 去掉 `\Weave:=weave1` 再跑，对比有摆和没摆的轨迹。

## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| `ArcLStart` 下面有红线，提示 Identifier not found | 系统里没加 RobotWare Arc 选项 | 修改系统选项，加 Arc 和 Simulated Welder，重启控制器 |
| `seamdata` 类型找不到 | 同上 | 同上 |
| 程序卡在 `WaitDI diPartReady` | 工件信号没给 | 在 I/O 窗口手动置 1 |
| 报 AW_IGNI_ERR 引弧失败 | 焊机没准备好、送气或焊枪监控信号没就绪 | 看事件日志；程序会自动重试 2 次，再失败停下 |
| 焊缝中途报目标不可达 | 焊缝超出工作范围、腕部姿态不对 | 工件往机器人跟前挪，或换姿态重新示教 |
| 焊到某个点报错停下 | 同一条焊缝里出现两个坐标相同的点 | 删掉重复点 |

## ⑤ 安全检查

跑之前逐条过：

- [ ] 工具 TCP 标过，Z 轴和焊枪平行。
- [ ] 点位全部按自己工作站重新示教。
- [ ] 先单步跑一遍轨迹，确认焊枪不撞工件、夹具。
- [ ] 开碰撞检查跑一遍，确认没有碰撞报警再连续运行。
- [ ] 焊接段速度用 welddata 里的焊速，确认数值合理（教学值 10 mm/s）。
- [ ] 起弧点、收弧点是 fine 点，中间点是过渡点。
- [ ] ERROR 里重试次数有上限，确认不会无限重试。

## ⑥ 怎么学这个项目

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4：建站、启动虚拟控制器、示教点位。
2. 再学 L6–L7：MoveJ / MoveL / MoveC、速度和区域——弧焊指令的参数和 MoveL / MoveC 一个样，只多了 seam、weld、weave。
3. 再学 L9：工具 TCP 和工件坐标系。
4. 再学 L13：ERROR 处理、RETRY、RAISE，对应 `rapid/09_error_handling.mod`。
5. 读 `welding.mod`：先看三份焊接数据各管哪个阶段，再看 `WeldSeam` 里起弧 → 焊接 → 收弧三段。
6. 动手：按第 ① 节搭站，按第 ③ 节逐条看现象。
