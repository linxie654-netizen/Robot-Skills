# 焊接项目：沿一条直焊缝走焊枪

状态：这是骨架：只写了“干跑 + 开关焊输出”（MoveL + SetDO），弧焊专用的起弧 / 收弧指令名这里不编、不写，用之前先查弧焊手册。需要弧焊选项（比如 ArcWare），没这个选项焊枪指令编不过。点位、焊速、焊枪角度全是教学值。

代码在 `welding.mod` 里只写了“干跑 + 开关焊输出”的骨架（MoveL + SetDO），弧焊专用的起弧 / 收弧指令名这里不编、不写，用之前先查弧焊手册。开焊之前，先在仿真里干跑轨迹（焊输出关掉）。

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，选 IRB 120，启动虚拟控制器。
2. 确认弧焊选项：控制器里要有弧焊选项（比如 ArcWare），没有就先加上，加选项的办法按 RobotStudio 的改选项流程走。
3. 摆工件：在机器人前方摆一个工件，焊缝从 X=0 走到 X=200（教学值，按自己工件改），工件夹紧在夹具上。
4. 装焊枪：给机器人装焊枪，TCP 标在焊丝尖端，焊枪角度按自己焊枪标定后再改。
5. 标定：先标工具 TCP，再建工件坐标系 `wobjPart`，原点在焊缝起点那一端。
6. 示教点位：起焊点、焊缝中点、收焊点、抬枪点、安全点，逐个示教。焊枪角度不对，焊缝会偏，先在仿真里看。
7. 配 IO：按下面第 ② 节的表配好信号，名字和代码里的一模一样。
8. 把 `welding.mod` 加载进控制器，先干跑轨迹（焊输出关掉），确认轨迹没问题再开焊。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diPartReady | 数字输入 | 工件已夹紧就位，1 = 就位 |
| doWeldOn | 数字输出 | 焊接输出，1 = 起弧焊接，0 = 停焊 |
| doGasOn | 数字输出 | 保护气，1 = 开气，0 = 关气 |

一共 3 个信号。弧焊参数（电流、电压、送丝速度）不在这个表里——那些要按弧焊手册配。

## ③ 仿真方法

1. 虚拟控制器里加载 `welding.mod`，先把 `doWeldOn` 强制关掉，干跑轨迹。
2. 看轨迹：焊枪沿焊缝从起点走到终点，路线直不直、焊枪角度稳不稳、有没有走到工作范围边缘。
3. 看 IO：手动把 `diPartReady` 置 1，看程序走不走焊缝；看 `doGasOn` 是不是先开、再开 `doWeldOn`，焊完是不是先关焊、再关气。
4. 看碰撞：开碰撞检查，看焊枪、工件、夹具有没有撞。重点看起焊点和收焊点，焊枪最容易撞夹具。
5. 看速度：焊缝那段先用 v100（教学值）跑，跑顺了再按弧焊手册调。
6. 先在仿真里干跑，全顺了，再查弧焊手册，对照着写起弧 / 收弧，低速试焊一条短缝。


## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| 程序卡在 `WaitDI diPartReady` 不动 | 工件没夹紧、夹具信号没接、信号名配错 | 手动置 1 试试；看夹具和信号 |
| 焊枪走到一半报“目标不可达” | 焊缝太长、超出工作范围、腕部姿态不对 | 把工件往机器人跟前挪；焊缝分两段焊；换姿态重新示教 |
| 焊缝走偏了 | `wobjPart` 标偏了、焊枪 TCP 没标准 | 重新标 TCP 和 `wobjPart`；干跑一遍看焊枪尖离焊缝多远 |
| 起弧没弧 / 一焊就断弧 | 弧焊选项没开、弧焊参数没配、起弧写法不对 | 先确认选项开了没有；起弧 / 收弧的写法查弧焊手册，别照抄 |
| 焊完气还一直开 | `doGasOn` 关晚了、程序中途停了 | 看程序是不是走完关气那句；急停后手动关气 |
| 焊枪撞夹具 | 起焊点、收焊点示教偏了 | 重新示教起焊点和收焊点；干跑时开碰撞检查 |

## ⑤ 安全检查

跑之前逐条过，缺一条都不开自动：

- [ ] 机器人、工件、夹具都在围栏里，围栏门关好，工作站里没有人。
- [ ] 焊接区域通风好，附近没有易燃的东西，灭火器能拿到。
- [ ] 焊枪、气管、电缆接牢了，不会拖到地上被机器人压到。
- [ ] 工具 TCP 标过，焊枪装紧了。
- [ ] 点位全是重新示教的，没照抄教学值。
- [ ] 先在仿真里干跑轨迹、碰撞检查过，确认没问题再开自动。
- [ ] 先手动低速干跑一遍，确认轨迹没问题再试焊。
- [ ] 弧焊选项开了，起弧 / 收弧写法按弧焊手册对过，确认没问题再开自动。
- [ ] 焊接时戴好防护，眼睛别直视电弧。

## ⑥ 怎么学这个项目

零基础从这一步开始：

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4：建站、启动虚拟控制器、示教点位。
2. 再学 L6–L7：MoveJ / MoveL、速度和区域——焊接那段要用直线 MoveL，速度先用 v100。
3. 再学 L9：工具 TCP 和工件坐标系怎么标，工件一动只改 wobj。
4. 再学 L10：SetDO / WaitDI，对应 `rapid/03_io_signals.mod`。
5. 再读 `welding.mod`：`WeldOneSeam` 里开气、开焊、沿缝走、关焊、关气的顺序为什么是这个顺序。
6. 最后动手：在 RobotStudio 里按第 ① 节搭一遍，先在仿真里干跑轨迹，再查弧焊手册，对照着写起弧 / 收弧，低速试焊一条短缝。
