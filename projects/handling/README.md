# 搬运项目：传送带来料 → 机器人搬到托盘

状态：点位是教学值。机器人是 IRB 120，场景是传送带来一件、机器人搬一件到托盘，一托盘 6 件（教学值），满了等换托盘。

代码在 `handling.mod` 里，主程序只调子程序：`PickPart` 取料、`PlacePart` 放料。

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，选 IRB 120，启动虚拟控制器。
2. 摆传送带：在机器人左手边放一条传送带，取料点大概在机器人前方 300 mm、高 400 mm 的位置（教学值，够不着就往跟前挪）。
3. 摆托盘：在机器人右手边放一个托盘，托盘顶面一角当放料原点。
4. 装工具：给机器人装一个平口夹爪，TCP 标在夹爪尖端，法兰下 120 mm（教学值，量自己的再改）。
5. 标定：先标工具 TCP，再建两个工件坐标系——`wobjConv` 原点在传送带取料点，`wobjPallet` 原点在托盘顶面一角。工件一动只改 wobj，不重示教每个点。
6. 示教点位：Jog 到取料上方、取料点、放料上方、放料点、安全点，逐个示教，覆盖 `handling.mod` 里的点位。
7. 配 IO：按下面第 ② 节的表配好信号，名字和代码里的一模一样。
8. 把 `handling.mod` 加载进控制器，先手动低速跑一遍，再切自动。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diPartReady | 数字输入 | 取料点有料，1 = 有料 |
| diPalletReady | 数字输入 | 托盘已就位，1 = 就位，0 = 托盘拿走了 |
| doGrip | 数字输出 | 夹爪，1 = 夹紧，0 = 松开 |

一共 3 个信号。信号名要和控制器里的配置对上，差一个字母程序就等不到信号。

## ③ 仿真方法

1. 虚拟控制器里加载 `handling.mod`，先把速度改低（比如全改成 v100），再点运行。
2. 看轨迹：机器人从取料点到放料点走的路直不直、有没有绕远、有没有走到工作范围边缘。
3. 看 IO：仿真里手动把 `diPartReady` 置 1，看机器人动不动；把 `diPalletReady` 置 0，看机器人停不等料；夹爪 `doGrip` 在取料时变 1、放料时变 0。
4. 看碰撞：开碰撞检查，看机器人、夹爪、工件有没有撞传送带、托盘、围栏。撞了就挪托盘 / 传送带，或者改点位。
5. 看计数：搬满 6 件，看示教器报不报“托盘搬满”，换托盘信号来没来，计数清不清零。
6. 都顺了，再把速度一档一档往上加，重新跑一遍。


## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| 程序卡在 `WaitDI diPartReady` 不动 | 传感器没亮、信号名配错、料没到取料点 | 仿真里手动置 1 试试；对信号名；看传感器位置 |
| 程序卡在 `WaitDI diPalletReady` 不动 | 托盘没放好、托盘到位信号没接 | 手动置 1 试试；看托盘位置和传感器 |
| 夹爪合了，料没夹起来 | 夹爪行程不够、料放歪了、合爪时间太短 | 看夹爪夹没夹到料；把 `WaitTime 0.3` 改长一点试试 |
| 机器人报“目标不可达” | 点位超出工作范围、腕部姿态不对 | 把托盘 / 传送带往机器人跟前挪；换个姿态重新示教 |
| 放料撞托盘边 | 放料点示教偏了、托盘放歪了 | 重新示教放料点；托盘摆正再跑 |
| 满托后不报数、一直搬 | `nPalletMax` 和实际托盘容量对不上 | 数一数一托盘到底放几件，改 `nPalletMax` |

## ⑤ 安全检查

跑之前逐条过，缺一条都不开自动：

- [ ] 机器人、传送带、托盘都在围栏里，围栏门关好。
- [ ] 工作站里没有人，急停按钮能按到。
- [ ] 工具 TCP 标过，夹爪装紧了，螺丝没松。
- [ ] 点位全是重新示教的，没照抄教学值。
- [ ] 在仿真里跑过一遍、碰撞检查过，确认没问题再开自动。
- [ ] 先手动低速跑一遍，确认轨迹没问题再切自动。
- [ ] 夹爪气压 / 电源正常，夹紧力够夹住工件、不会掉。
- [ ] 托盘放稳了，不会一碰就倒。

## ⑥ 怎么学这个项目

零基础从这一步开始：

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4：认识 IRB 120、建站、启动虚拟控制器、示教一个点。
2. 再学 L6–L7：MoveJ / MoveL 怎么用、靠近工件用 v200 + fine、空跑用 v1000 + z50。
3. 再学 L10：SetDO / WaitDI 怎么用，对应 `rapid/03_io_signals.mod`。
4. 然后读 `rapid/02_pick_place.mod`：取料 → 搬运 → 放料，一个循环是怎么写的。
5. 再读 `handling.mod`：主程序只调子程序，`PickPart` 和 `PlacePart` 各干什么，`nCount` 怎么计数的。
6. 最后动手：在 RobotStudio 里按第 ① 节搭一遍，示教自己的点位，低速跑通一次。跑通了，再把一托盘 6 件改成自己托盘的件数。
