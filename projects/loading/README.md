# 上下料项目：给机床上毛坯 → 等加工完 → 取出成品

状态：点位是教学值。机器人是 IRB 120，场景是传送带来毛坯，机器人放进机床，机床加工，机器人取出成品放到成品托盘。

最要紧的一条：门没开好、机床没停稳，机器人绝不伸手进去。

代码在 `loading.mod` 里：`PickBlank` 取毛坯、`LoadMachine` 上料、`UnloadMachine` 取成品、`PlaceFinished` 放成品。

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，选 IRB 120，启动虚拟控制器。
2. 摆传送带：在机器人左手边放一条传送带，取料点大概在机器人前方 300 mm 的位置（教学值）。
3. 摆机床：在机器人右手边摆一台机床（仿真里用一个带门的机床模型），夹具中心当上料原点。
4. 摆成品托盘：在机器人另一边放一个成品托盘，托盘顶面一角当放料原点。
5. 装工具：装一个夹爪，TCP 标在夹爪尖端，法兰下 120 mm。
6. 标定：先标工具 TCP，再建三个工件坐标系——`wobjConv` 原点在传送带取料点，`wobjMachine` 原点在机床夹具中心，`wobjOut` 原点在成品托盘一角。
7. 示教点位：取料点、上料点、成品放料点、安全点，逐个示教。上料点要伸进机床里，示教时慢慢 Jog，别撞夹具。
8. 配 IO：按下面第 ② 节的表配好信号，名字和代码里的一模一样。
9. 把 `loading.mod` 加载进控制器，先手动低速跑一遍：上料 → 发加工启动 → 等加工完 → 取成品 → 放成品。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diPartReady | 数字输入 | 取料点有毛坯，1 = 有料 |
| diMachineReady | 数字输入 | 机床空闲、可以上料，1 = 空闲 |
| diCycleDone | 数字输入 | 机床加工完成，1 = 加工完 |
| diDoorOpen | 数字输入 | 机床门已开好，1 = 门开了，0 = 门关了 |
| doGrip | 数字输出 | 夹爪，1 = 夹紧，0 = 松开 |
| doDoorOpen | 数字输出 | 开门请求，1 = 开门，0 = 关门 |
| doCycleStart | 数字输出 | 加工启动，1 = 启动（发 0.5 秒脉冲） |

一共 7 个信号。门的开 / 关、加工启动的脉冲写法按机床说明书对。

## ③ 仿真方法

1. 虚拟控制器里加载 `loading.mod`，先把速度改低，再点运行。
2. 看 IO：手动把 `diPartReady`、`diMachineReady` 置 1，看机器人上不上料；把 `diCycleDone` 置 1，看机器人取不取成品；开门时手动把 `diDoorOpen` 置 1，看机器人进不进机床。
3. 看轨迹：机器人进机床的路直不直，有没有擦到门框、夹具。进机床那段用 v100 慢速。
4. 看碰撞：开碰撞检查，看机器人、夹爪、工件有没有撞机床门、夹具、传送带。重点看伸进机床里那一段。
5. 看顺序：上料 → 关门 → 发加工启动 → 等加工完 → 开门 → 取成品，这个顺序错一步都可能撞机床。
6. 都顺了，再把速度一档一档往上加，连续跑三件。


## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| 程序卡在 `WaitDI diMachineReady` 不动 | 机床没空闲、信号名配错 | 手动置 1 试试；看机床状态；对信号名 |
| 程序卡在 `WaitDI diDoorOpen` 不动 | 门没开、开门信号发的方式不对、门开好信号没回 | 看门动没动；门的开 / 关是发脉冲还是保持信号，按机床说明书对 |
| 机器人伸进机床撞夹具 | 上料点示教偏了、夹具位置变了 | 重新示教上料点；慢慢 Jog 进去核对 |
| 加工启动发了，机床不动 | `doCycleStart` 脉冲太短、机床没收到 | 把 `WaitTime 0.5` 改长一点试试；看机床说明书要多长的脉冲 |
| 取成品时毛坯还在里面 | 上一轮上料没放好、夹具没夹紧 | 看夹具夹没夹住；上料点重新示教 |
| 成品放歪了 | 成品托盘原点 `wobjOut` 标偏了 | 重新标 `wobjOut`；重新示教放料点 |

## ⑤ 安全检查

跑之前逐条过，缺一条都不开自动：

- [ ] 机器人、传送带、机床、成品托盘都在围栏里，围栏门关好，工作站里没有人。
- [ ] 机床门联锁正常：门开着机床不加工，机器人进机床时门开好、机床停稳。
- [ ] 工具 TCP 标过，夹爪装紧了。
- [ ] 点位全是重新示教的，没照抄教学值。
- [ ] 先在仿真里跑通、碰撞检查过，重点看伸进机床里那一段。
- [ ] 先手动低速跑一遍，确认上料、取成品的轨迹没问题再切自动。
- [ ] 夹爪夹紧力够，毛坯、成品都不会半路掉进机床里。
- [ ] 急停按钮能按到，急停后机器人、机床都停得住。

## ⑥ 怎么学这个项目

零基础从这一步开始：

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4：建站、启动虚拟控制器、示教点位。
2. 再学 L6–L7：MoveJ / MoveL、速度和区域——进机床那段用 v100 慢速。
3. 再学 L10：SetDO / WaitDI，对应 `rapid/03_io_signals.mod`——这个项目信号最多，先把 7 个信号的来龙去脉画一张图。
4. 先读 `rapid/02_pick_place.mod`：取料 → 放料一个循环是怎么写的。
5. 再读 `loading.mod`：`LoadMachine` 和 `UnloadMachine` 里开门、等门开好、关门、等门关好为什么每一步都要等回信。
6. 最后动手：在 RobotStudio 里按第 ① 节搭一遍，先跑通一轮完整的上料 → 加工 → 取成品。跑通了，再连续跑三件。
