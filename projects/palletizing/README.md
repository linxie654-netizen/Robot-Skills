# 码垛项目：传送带来箱 → 一层一层码到托盘上

状态：点位是教学值。底子是库里 `rapid/11_palletizing.mod`（只复制扩写，原文件留在原地，没动过）。

方案：IRB 120（台座高 300 mm）+ 传送带供料 + 托盘 2 列 × 2 行 × 3 层 = 12 箱。箱子 120 × 80 × 60 mm，奇数层正常摆，偶数层转 90 度交错码放。扩写部分：满托信号 `doPalletFull`、每码完一层报一次数。

代码在 `palletizing.mod` 里：`PickBox` 取箱，`PlaceBox` 算位置放箱，层、列、行三个循环套起来码。

---

## ① 搭建步骤

1. RobotStudio 里新建工作站，选 IRB 120，台座高 300 mm，启动虚拟控制器。
2. 摆传送带：在机器人左手边放一条传送带，取料点大概在机器人前方 300 mm 的位置（教学值，够不着就往跟前挪）。
3. 摆托盘：在机器人右手边放一个托盘，托盘顶面一角当放料原点。
4. 装工具：装一个夹爪（或真空吸盘，都只接 `doGrip` 一个输出），TCP 标在夹爪尖端，法兰下 120 mm。
5. 标定：先标工具 TCP，再建两个工件坐标系——`wobjConv` 原点在传送带取料点，`wobjPallet` 原点在托盘顶面一角。
6. 示教点位：取料点 `pPick`、放料基准点 `pPalletBase`、转 90 度的基准点 `pPalletBaseR`、安全点 `pHome`，逐个示教。
7. 配 IO：按下面第 ② 节的表配好信号，名字和代码里的一模一样。
8. 把 `palletizing.mod` 加载进控制器，先手动低速跑一层，再跑满一托盘。

## ② IO 配置表

| 信号名 | 类型 | 干什么用 |
| --- | --- | --- |
| diBoxReady | 数字输入 | 取料点有箱，1 = 有箱 |
| doGrip | 数字输出 | 夹爪，1 = 夹紧，0 = 松开 |
| diNewPallet | 数字输入 | 新托盘已就位，1 = 就位 |
| doPalletFull | 数字输出 | 托盘满了，1 = 满托，亮灯 / 通知换托盘 |

一共 4 个信号。`doPalletFull` 是扩写新增的，原 `rapid/11_palletizing.mod` 里没有。

## ③ 仿真方法

1. 虚拟控制器里加载 `palletizing.mod`，先把速度改低，再点运行。
2. 看轨迹：机器人从传送带到托盘走的路直不直，够不够得着托盘最远那一箱。
3. 看 IO：手动把 `diBoxReady` 置 1，看机器人取不取箱；码满 12 箱，看 `doPalletFull` 变不变 1、示教器报不报“托盘已满”；把 `diNewPallet` 置 1，看计数清不清零、下一托盘开不开工。
4. 看碰撞：开碰撞检查，看机器人、箱子有没有撞传送带、托盘、已经码好的箱子。重点看第三层：越码越高，越容易撞。
5. 看码法：第一层正常摆，第二层是不是转了 90 度交错码放，箱子之间有没有留 10 mm 间隙、有没有叠歪。
6. 都顺了，再把速度一档一档往上加，跑满两托盘。


## ④ 故障分析

| 现象 | 可能原因 | 怎么查 |
| --- | --- | --- |
| 程序卡在 `WaitDI diBoxReady` 不动 | 箱子没到取料点、传感器没亮、信号名配错 | 手动置 1 试试；看传感器位置；对信号名 |
| 箱子码歪了、越码越偏 | 托盘原点 `wobjPallet` 标偏了、箱子尺寸和程序里的 120×80×60 对不上 | 重新标 `wobjPallet`；量箱子实际尺寸，改 `boxL / boxW / boxH` |
| 偶数层没转 90 度 | `pPalletBaseR` 的姿态示教错了 | 仿真里看第二层的朝向，重新示教 `pPalletBaseR` |
| 第三层够不着 | 托盘离机器人太远、台座太矮 | 把托盘往机器人跟前挪；托盘位置改了不用改程序，只改 `wobjPallet` |
| 满托后不换托盘、一直等 | `diNewPallet` 信号没来 | 手动置 1 试试；看换托盘的传感器 / 按钮接没接 |
| 箱子没夹起来就走了 | 夹爪没夹紧、合爪时间太短、箱子放歪了 | 看夹爪夹没夹到；把 `WaitTime 0.3` 改长一点试试 |

## ⑤ 安全检查

跑之前逐条过，缺一条都不开自动：

- [ ] 机器人、传送带、托盘都在围栏里，围栏门关好，工作站里没有人。
- [ ] 工具 TCP 标过，夹爪装紧了。
- [ ] 点位全是重新示教的，没照抄教学值。
- [ ] 先在仿真里跑通、碰撞检查过，重点看第三层。
- [ ] 先手动低速跑一层，确认码法、朝向都没问题再跑满托。
- [ ] 箱子重量在机器人负载内，码三层不会倒。
- [ ] 换托盘时机器人回到安全点 `pHome` 再进人，别在机器人动的时候换托盘。

## ⑥ 怎么学这个项目

零基础从这一步开始：

1. 先学 `docs/beginner-roadmap.md` 的 L1–L4：建站、启动虚拟控制器、示教点位。
2. 再学 L6–L7：MoveJ / MoveL、速度和区域（靠近工件 v200 + fine）。
3. 再学 L8：FOR 循环怎么套三层（层、列、行），对应 `rapid/04_loops_conditions.mod`。
4. 再学 L10：SetDO / WaitDI，对应 `rapid/03_io_signals.mod`。
5. 先读 `rapid/11_palletizing.mod`：码垛规格那几个 CONST 怎么改码法，`PlaceBox` 里奇数层、偶数层的位置是怎么算出来的。
6. 再读 `palletizing.mod` 的扩写部分：`doPalletFull` 什么时候亮、每层报数是干什么用的。
7. 最后动手：在 RobotStudio 里按第 ① 节搭一遍，先跑通一层，再跑满 12 箱一托盘。跑通了，把箱子尺寸改成自己的，重新跑一遍。
