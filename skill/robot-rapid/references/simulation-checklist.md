# 仿真检查清单 — Robot-RAPID

铁规矩：**没仿真过的程序不上真机**。每一项打勾才能往下走。

## 验证前先写清这次看什么（seams）

跑仿真之前，先把这次要看的公开点写下来，没写下来就不跑。每次验证至少写清这四样里这次看哪几样：

- [ ] 轨迹：路径对不对，有没有跑飞、走奇异点
- [ ] IO：夹爪、传感器、等待信号的顺序对不对
- [ ] 速度和区域：靠近工件是不是低速 + fine，空跑是不是合理速度
- [ ] 碰撞：机器人自己、工件、夹具、围栏有没有碰到

写下来的点就是这次验证的缝：只看写下来的点，跑完只对这些点下结论；没写下来的不顺带说“都挺好”。

## 跑通的证据：缺一样不算跑通

说“跑通了”要拿出三样东西，感觉对了不算数：

- [ ] 报错情况：报错截图，或写明“跑完无报错”
- [ ] 轨迹：轨迹对不对，截图或文字写清看了哪段轨迹
- [ ] 碰撞检查：碰撞检查的结果，有没有撞、撞在哪

三样缺一样就不算跑通，回去补。换个条件再验一遍（换个点位、速度、工件位置），三样证据也要重新留一份。

## 建站

- [ ] 工作站新建好了，机器人型号定了（没定先用 IRB 120 练）
- [ ] 虚拟控制器建好了（Installation Manager / System Builder 里建，加载进工作站）
- [ ] 控制器状态是 motoron / AUTO / stopped，任务是 T_ROB1

## 教点

- [ ] 工具 `tooldata` 设好了（中心点 + 负载）
- [ ] 工件 `wobjdata` 设好了
- [ ] 每个目标点都示教过，点位不是抄别人的教学值

## 仿真

- [ ] 程序先在虚拟控制器里完整跑一遍
- [ ] 改完文件要同步到虚拟控制器再跑，保存了不等于传上去了
- [ ] 全程看轨迹：有没有撞机器人自己、有没有撞工件和夹具
- [ ] 速度先用低速跑，确认没问题再提速
- [ ] 信号时序对不对：夹爪、传感器、等待信号都按顺序来
- [ ] 圆弧、奇异点附近重点看，轨迹别跑飞

## 每次改完走一遍闭环（只在仿真里做，不上真机）

- [ ] 一次只改一处，改完仿真跑一遍
- [ ] 看结果：报错、轨迹、碰撞三样都对
- [ ] 跑通了换个条件再验一遍（换个点位、速度、工件位置）

## 上真机之前

- [ ] 仿真里跑通了，碰撞查完了
- [ ] RobotStudio 的 Check Program 过了（编辑器不报错不等于控制器认了）
- [ ] UAS 账号有对应操作的授权，写操作被拒先查四道门再查授权号（见 `references/learned.md`）
- [ ] 真机先手动模式、低速验证一遍
- [ ] 确认速度、区域、工具都对
- [ ] 没把握就停下来问，别硬上

## 仿真跑不通先查什么

1. 报错原话贴出来，对 `references/troubleshooting.md` 的表。
2. 不可达先查手腕姿态和工件坐标系，别乱改点位。
3. 控制器没装程序会报 C0049004，先装 `rapid/01_move_basics.mod`。
4. 改一处，跑一遍，别一次改五处。
