# 仿真检查清单 — Robot-RAPID

铁规矩：**没仿真过的程序不上真机**。每一项打勾才能往下走。

## 建站

- [ ] 工作站新建好了，机器人型号定了（没定先用 IRB 120 练）
- [ ] 虚拟控制器建好了（Installation Manager / System Builder 里建，加载进工作站）
- [ ] 控制器状态是 motoron / AUTO / stopped，任务是 T_ROB1

## 教点

- [ ] 工具 `tooldata` 设好了（中心点 + 负载）
- [ ] 工件 `wobjdata` 设好了
- [ ] 每个目标点都示教过，点位不是抄别人的教学值

## 仿真

- [ ] 程序先在虚拟控制器里完整跑一遍
- [ ] 全程看轨迹：有没有撞机器人自己、有没有撞工件和夹具
- [ ] 速度先用低速跑，确认没问题再提速
- [ ] 信号时序对不对：夹爪、传感器、等待信号都按顺序来
- [ ] 圆弧、奇异点附近重点看，轨迹别跑飞

## 上真机之前

- [ ] 仿真里跑通了，碰撞查完了
- [ ] 真机先手动模式、低速验证一遍
- [ ] 确认速度、区域、工具都对
- [ ] 没把握就停下来问，别硬上

## 仿真跑不通先查什么

1. 报错原话贴出来，对 `references/troubleshooting.md` 的表。
2. 不可达先查手腕姿态和工件坐标系，别乱改点位。
3. 控制器没装程序会报 C0049004，先装 `rapid/01_move_basics.mod`。
4. 改一处，跑一遍，别一次改五处。
