# 新手大白话教学：14 课

从 YouTube 新手教程的 14 篇学习草稿转化而来。每课讲清“这是什么、怎么做、容易错在哪”，能独立读懂。

**先说清楚三件事：**

- 这 14 课是纸面上的理解，**还没在 RobotStudio 里照做跑通过**。按步骤做之前，先在仿真里走一遍、查碰撞，手动低速验证后再上真机。
- 内容只写草稿里有的东西。没核实的地方写了“未核实”，不要当成定论。
- 术语第一次出现都用人话解释了一遍，后面直接用简称。
- 本文件已进公开仓库。以后边问边调用、边回答边改正。

## 第 1 课：安全开场——上锁挂牌、急停、安全恢复

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 1 段（视频 https://www.youtube.com/watch?v=hGGkzsT8WEU ，时长 4:36:34）
**学法说明：** 视频原片没逐帧看过，字幕拿不到；本课内容以 Wolf Robotics《ABB BASIC ROBOTIC PROGRAMMING》4 天线下班手册和 ABB 官方 RU011／IN-RB02 课程大纲为准，视频内章节时间点**未核实**。

### 这是什么

进机器人单元动手之前，先把能量断掉、锁住、挂牌，确认机器人动不了，再开始工作。出了急停，先查原因、走恢复流程，再复位。

上锁挂牌（Lock out / Tag out）就是：断电断气，上锁，挂上写有姓名、日期、原因的牌子。谁挂的牌谁摘，别人不许代摘。

### 怎么做

1. **进单元前先确认安全装置**：围栏、光幕、急停按钮、安全门开关都在位，没被短接或拆掉；确认安全链（run chain，就是一串安全开关连成的回路，任何一个断开机器人就停）正常。
2. **上锁挂牌**：开工第一步，不是可选项。断开机器人及周边设备的动力（电、气等），上锁，挂上写有姓名、日期、原因的牌子。
3. **验证零能量**：锁好后试着启动一下，确认确实动不了，再开始工作；别只信开关位置。
4. **急停**：出问题先拍急停。急停按下后机器人立即停，但这只是停住，不是恢复。
5. **安全恢复**：急停后不能直接复位就跑。先查清触发原因、排除故障，确认单元里没人、没东西挡路，再按恢复流程复位，最后手动低速验证一遍再进自动。

### 容易错在哪

- 上锁挂牌当成走过场，锁没上、牌没挂就进单元。
- 急停按下后直接复位、直接跑，没查原因、没走恢复流程。
- 恢复后不验证，直接进自动模式。

### 和库里其他内容的关系

- 新手路线 L14 只有原则（手动低速、查碰撞、急停围栏），这课补的是开工和恢复的完整流程。
- QuickStop 信号和 World Zone（禁区）的做法见第 13 课，那课讲信号和禁区，这课讲人和流程，两课合起来才是完整的安全。

## 第 2 课：认识示教器——主菜单、快捷菜单、操作模式、使能与速度

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 2 段（视频同第 1 课）
**学法说明：** 同第 1 课，视频内章节时间点**未核实**。

### 这是什么

示教器（FlexPendant）就是挂在机器人旁边、拿在手里的那块带屏幕的操作板，点动、示教、改程序都在它上面做。先认菜单再动手，不然找不到功能在哪。

### 怎么做

1. **主菜单（Main menu）**：示教器的总入口，程序、点动、I/O（输入输出信号）、系统信息都在这里进。先花几分钟把主菜单翻一遍，知道每个入口是干什么的，再动手。
2. **快捷菜单（Quick access menu）**：常用功能放这里，不用一层层翻主菜单。点动、速度、坐标系切换这些天天用的，放快捷菜单里。
3. **使能按钮（Enabling device）**：握在手里的三档开关。松开机器人就停，半按才允许手动运行，全按到底也会停。保命的操作习惯：手一松就停，别一直攥着。
4. **摇杆（Joystick）**：点动用的，推哪个方向机器人往哪个方向走；配合坐标系选择和速度档用。
5. **操作模式**：手动模式才能点动和示教；自动模式跑程序。切模式之前先确认人在单元外、程序没问题，别在手动模式里直接跑自动。
6. **速度档**：小／中／大三档。点动和示教用小档，熟悉了再加；自动跑之前先手动低速走一遍轨迹。

### 容易错在哪

- 没认菜单就直接上手，找不到功能在哪，乱按。
- 使能按钮一直攥着不放，养成坏习惯；或者全按到底，机器人停了还以为出故障。
- 速度档开太大点动，机器人一下冲出去。
- 手动模式和自动模式没分清，人在单元里就切自动。

### 和库里其他内容的关系

- 点动三种模式（轴／线性／重定向）见新手路线 L2 和例程 06，那是“怎么动”；这课是“在哪操作、怎么进”，是点动和示教的前置课。

## 第 3 课：从已有布局创建单机器人系统 + 配 I/O

**来源视频：** cnctrain《Creating Single Robot System in ABB Robotstudio》（文章 https://cnctrain.com/blogs/post/creating-single-robot-system-in-abb-robotstudio ，2024-04-04；视频 https://www.youtube.com/watch?v=TDjzO5AMOmk ；时长**未核实**）

### 这是什么

机器人系统就是一台独立机器人 + 自己的控制器 + 自己的 I/O 系统（输入输出信号的集合），配好、能编程。本课用 IRC5 控制器（ABB 机器人常用的控制器型号）。

I/O 就是信号：输入信号是外面传进来的（比如传感器说“箱子到了”），输出信号是机器人发出去的（比如“夹爪合上”）。配完 I/O，信号才能在程序里用。

### 怎么做

1. **先确认布局里有控制器**：布局里 IRC5 已经加好了才能建系统，没加先加。
2. **建系统**：Home → Robot System，有三种方法：
   - 基于已有布局创建系统（视频演示的就是这种：布局现成，系统跟着布局走，最不容易配错，新手先学这一种）；
   - 创建新系统并加到工作站；
   - 加一个已有的系统到工作站。
3. **配 I/O**：Controller 标签页 → Configuration Editor（配置编辑器，就是改系统参数的地方）。在这里看和改系统参数：Communication（通信）、I/O System（I/O 系统）。
4. **核对信号名**：配出来的信号名，就是程序里 `SetDO`（置输出信号）／`WaitDI`（等输入信号）用的名字。写程序之前先在这里核对名字，写错一个字母程序就找不到信号。

### 容易错在哪

- 布局里没加控制器就建系统：先确认 IRC5 已经在布局里。
- 配完 I/O 不检查信号名：程序里写错一个字母就找不到信号，先在 Configuration Editor 里核对名字再写程序。

### 和库里其他内容的关系

- `docs/full-pipeline.md` 是从头建系统的 0 到 1 全流程；这课补的是“从已有布局建”这条路 + 建完后去 Configuration Editor 配 I/O 这一步。

## 第 4 课：工具坐标系——三种定义方法 + Create Tool 向导

**来源视频：** Aleksandar Haber《ABB Robot Tutorial: Defining Tool Frames and Basic Modeling in ABB RobotStudio》（视频 https://www.youtube.com/watch?v=k0ddlUXXHto ；时长**未核实**）
**学法说明：** 作者文字版只有两行（“讲怎么定义工具坐标系、做基础建模”），细节靠下面两份交叉材料补，不是视频逐字稿：ITAR《Hands-on with ABB Robots》（ardavan.io）讲示教器上三种方法；CMU《10 Steps to Add a Tool》讲 Create Tool 向导步骤。

### 这是什么

先分清两个东西：

- **工具几何**：夹爪、焊枪、吸盘的 3D 模型，导进工作站。
- **工具坐标系（tooldata，工具数据）**：告诉机器人工具的尖端在哪、朝向怎么定、工具多重。没定义工具时机器人默认用 tool0，TCP 在法兰中心、Z 轴沿法兰法线。

**TCP**（工具中心点）就是工具真正干活的那个点，比如夹爪的夹取点、焊枪的枪尖。TCP 不准，后面所有点都偏。**法兰**是机器人手腕末端那个圆盘，工具就装在它上面；工具的 Z 轴从手腕向外指。

### 怎么做

**示教器上定义工具，三种方法按需选：**

| 方法 | 什么时候用 | 怎么做 |
|---|---|---|
| TCP（4 点，默认方向） | 工具沿法兰 Z 轴、绕 Z 转不影响干活（如圆头记号笔） | 固定点，从 4 个不同方向把 TCP 对准它 |
| TCP + Z 方向 | 工具 Z 轴和法兰 Z 轴不一样、但绕 Z 转不重要 | 4 点定 TCP，再加一点定 Z 方向 |
| TCP + Z 和 X 方向 | 接近姿态必须精确，连绕 Z 的转角都要定 | 4 点定 TCP，再加两点定 Z、X 方向 |

要点：每种方法都要从多个方向对准空间中同一个固定点，点得越准，TCP 越准。

**RobotStudio 里建工具（Create Tool 向导，CMU 10 步）：**

1. Modeling → Import Geometry，导工具模型（.stl 等，建模单位先设成 mm）。
2. Modeling → Create Tool，起名字。
3. Use Existing，选刚导进来的几何。
4. 其他设置不填也行，Next。
5. 起 TCP 名（只有一个 TCP 就默认），填每个 TCP 的位置和姿态，加进 TCP 列表，Done。
6. Layout 里把工具拖到机器人上，弹窗点 No（让它自动摆正位置）。
7. 要改：Home → Paths&Targets → tooldata 文件夹，右键工具 → Modify Tooldata。

**TCP 位置怎么量：**

- 量法兰安装面到 TCP 的距离，填进 TCP 的 Z 值。
- Patino 的例子：吸盘底座到 TCP 量出来是 184 mm——**每把工具自己量，别照抄**。
- 重心：工具重心用 Snap Gravity 取；重量填错会影响负载估算。

### 容易错在哪

- 建模单位不是 mm 就导错尺寸：导之前先确认单位。
- 工具 Z 轴方向搞反：Z 轴从手腕向外指，不是向里。
- 只有一个 TCP 也留默认名，别手改出两个 TCP 互相混。

### 和库里其他内容的关系

- `rapid/05_coordinates.mod` 讲 tooldata 概念；这课补的是“具体怎么点”。
- 真机上标 TCP 的流程见第 5 课，两课合起来，离线和真机都齐了。

## 第 5 课：示教器四点法标 TCP + 验证

**来源视频：** Automation Academy《ABB ROBOT PROGRAMMING TUTORIAL PART 1》第 4 段（视频同第 1 课）
**学法说明：** 同第 1 课，视频内章节时间点**未核实**。

### 这是什么

在示教器上把工具的 TCP（工具中心点，就是工具尖端那个点）标出来，标完验证通过再用。TCP 不准，后面所有点都偏。

**四点法**就是：用四个不同的姿态，把工具尖端碰到同一个固定参考点，每碰一次记一个点，控制器拿这四个点算出 TCP 的位置。

### 怎么做

1. **准备**：工具装好、拧紧；找一个固定参考点（尖点），比如工作台上的尖顶；确认机器人手动模式、速度小档。
2. **四点法**：用四个不同的姿态，把工具尖端碰到同一个参考点，每碰一次记一个点。四个姿态要尽量散开，别都从一个方向来，姿态越分散算得越准。
3. **算 TCP**：四个点记完，控制器算出 TCP 的位置；保存工具数据（tooldata）。
4. **验证**：标完必须验证，不能标完直接用。换几个姿态再碰一次参考点，看 TCP 是不是还对得上参考点；或者点动 TCP 沿直线走，看轨迹直不直。误差大了就重标。
5. **工件坐标系**：TCP 标完再定义工件坐标系（三点法，见第 6 课）；点位挂到工件坐标系下，别挂世界坐标系，换工位只改工件不改程序。

### 容易错在哪

- 四个姿态太接近，算出来的 TCP 不准。
- 标完不验证，直接拿去跑程序，点位全偏。
- 工具没拧紧就标，标完工具一动就全错。
- 点位挂到世界坐标系下，工件一挪全得重教。

### 和库里其他内容的关系

- 第 4 课讲 RobotStudio 里定义工具的三种方法；这课是示教器真机标 TCP 的流程，两课合起来，离线和真机都齐了。
- 例程 05（坐标系）和新手路线 L9 只有概念，这课是能照着做的步骤。

## 第 6 课：三点法定义工件坐标系

**来源视频：** Aleksandar Haber《How to Correctly Define and Create Workobject Frames and Coordinate Systems》（视频 https://www.youtube.com/watch?v=5fdcGGy9IzI ；文字版 https://aleksandarhaber.com/21779-2/ ；时长**未核实**）

### 这是什么

**工件坐标系（wobjdata，工件数据）**是用户自己定的坐标系，通常跟工件的几何对齐。好处：工件一挪位置，只改工件坐标系就行，不用重示教每个点。新手常犯的错就是工件一动就全重示教。

**三点法**就是用三个点定一个坐标系：第 1 个点是原点，第 2 个点定 X 轴方向，第 3 个点定 Y 轴方向，Z 轴按右手定则出来（右手定则：右手四指从 X 轴弯向 Y 轴，拇指指的就是 Z 轴方向）。

### 怎么做

1. **建个盒子练手**：在 RobotStudio 里建模一个盒子（Box），调好尺寸。这一步是练手，也是后面定坐标系的参照物。
2. **开三点法**：建工件坐标系时选三点法（Three-point method）。
3. **取三个点**，按顺序：
   - 第 1 个点：原点（工件坐标系的零点，一般取工件一角）；
   - 第 2 个点：X 轴方向上的点；
   - 第 3 个点：Y 轴方向上的点。
   三个点定了，坐标系就定了。
4. **检查**：看坐标系方向对不对：X、Y 沿着工件边，Z 垂直于工件面。不对就重取，别将就。
5. **用起来**：目标点都挂到这个工件坐标系下写，程序里用 `wobjdata` 引用它。

### 容易错在哪

- 三个点的顺序别搞反（原点、X、Y），反了坐标系就歪了。
- 点别取在工件本身会动的地方，取在固定、可复现的位置。
- 工具 TCP 没标定就定工件坐标系，点位全偏——先标工具（第 4、5 课），再定工件。

### 和库里其他内容的关系

- `rapid/05_coordinates.mod` 讲 tooldata、wobjdata 的概念；这课是三点法的操作步骤，补进去新手路线 L9 就完整了。
- 第 11 课建了 3 个工件坐标系（传送带 + 大小托盘），是三点法的实战应用，两课可以互相印证。

## 第 7 课：多个工件坐标系——一个程序，多处复用

**来源视频：** Mr. Domer《ABB Tutorial - Multiple Work Objects》（30 分钟，时长与简介已核实；视频链接**未核实**，逐字内容未拿到）

### 这是什么

同一段程序（比如取放），换个工位、换个托盘、换条线，不用重示教所有点。做法：点位挂在工件坐标系下，不挂在世界坐标系下；工件一挪，整组点跟着走。

Domer 的讲法：工件的好处不在“多”，在“程序不用改”——位置变了只改工件，不改程序。

### 怎么做

1. **想清楚复用场景**，典型用法：
   - 一台机器人对两个托盘：两个工件（wobjA、wobjB），同一套取放点位挂不同的工件各跑一遍；
   - 传送带 + 两个码垛托盘：3 个工件（第 11 课就是这么做的：传送带一个、大小托盘各一个）；
   - 零件换型：同一种零件换个夹具位置，只重定工件，程序原样跑。
2. **每个工件单独定**：三点法（见第 6 课）：原点、X 方向、Y 方向三个点。每个工件单独定，别共用一个原点凑合。
3. **定完先测**：点动到工件上的已知点，看 TCP 读数跟工件坐标对不对得上。
4. **程序里挂工件**：运动指令挂工件，换工位就换 `\WObj`，点位名可以复用：

```rapid
MoveL pPick, v200, fine, tGripper \WObj:=wobjA;
```

### 容易错在哪

- 忘了写 `\WObj`，点位就默认挂 wobj0（世界坐标系），工件挪了点位不动，机器人走到错的地方。

### 和库里其他内容的关系

- `rapid/05_coordinates.mod`：wobjdata 概念。
- 第 11 课：3 个工件的实战例子。
- 这课补的是“为什么用多个工件”这个讲法，库里原来只讲了 wobjdata 是什么。

## 第 8 课：沿路径走——从记点到 RAPID 程序

**来源视频：** Aleksandar Haber《How to Easy Program ABB Robots to Follow a Path by Using RAPID Programming Language》（视频 https://www.youtube.com/watch?v=zZXk-TW2iCE ；时长**未核实**）
**学法说明：** 视频本身未逐帧看；流程按 Haber 视频讲的顺序，每一步用 CMU Future CNC 官方教程、ITAR《RobotStudio Handbook》、卡尔加里大学 YuMi 指南、plcprogramming.io RAPID 教程交叉核对过；没核实的写“未核实”，不编。

### 这是什么

让机器人沿着一条你定好的路径走：先点动记下路径上的点，再把点连成路径，最后同步成 RAPID 程序跑起来。

**robtarget**（目标点）就是空间里的一个点，带位置和姿态；**路径（Path）**就是一串按顺序排好的目标点；**同步到控制器（Synchronize to VC）**就是把工作站里的路径变成控制器里的 RAPID 程序。

### 怎么做（7 步）

1. **导模型**：Home → Import Geometry，导工件或末端执行器的几何模型（STEP / IGES 等），摆到机器人够得着的位置。
2. **装末端执行器**：Modeling 里把工具模型挂到机器人法兰上，定义 tooldata（TCP）。TCP 没标定就先标——见第 4 课，TCP 不准，后面所有点都偏。
3. **点动记点**：Jog Joint（轴点动）或 Jog Linear（直线点动）把机器人点到要走的位置，Home → Teach Target 记下 robtarget；也可以 Home → Target → Create Target 按数值直接建点。点要挂到工件坐标系下（见第 6 课），别挂到世界坐标系。
4. **建路径**：Home → Path → Empty path 建空路径，把目标点按顺序拖进路径；每一段选运动类型——空中大跨度用 MoveJ，贴工件走直线用 MoveL；沿模型边走可用 Auto path 自动沿边生成目标点。
   - **MoveJ**：关节运动，机器人各关节自己找最快的路，适合空中赶路。
   - **MoveL**：直线运动，TCP 沿直线走，适合贴工件干活（焊接、点胶、装配插入）。
5. **同步到控制器**：右键 T_ROB1 → Synchronize to VC，路径就变成控制器里的 RAPID 程序（一个 Path 过程 + robtarget 声明）。
6. **写 / 读 RAPID**：同步生成的程序长这样（点位是示教值，上真机前必须重示教）：

```rapid
MODULE Module1
    CONST robtarget pStart:=[[500,0,600],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];
    CONST robtarget p10:=[[500,200,300],[1,0,0,0],[0,0,0,0],[9E9,9E9,9E9,9E9,9E9,9E9]];
    PROC main()
        Path_10;
    ENDPROC
    PROC Path_10()
        MoveJ pStart, v1000, z50, tool0\WObj:=wobj0;
        MoveL p10, v500, fine, tool0\WObj:=wobj0;
    ENDPROC
ENDMODULE
```

`MoveJ 目标, 速度, zone, 工具`：速度 v1000 是空中快移，v500 是贴工件慢走；**zone**（转角区）是拐弯时允许多大偏差：z50 是空中过渡点可以拐弯，fine / z1 是贴工件必须走到位。工具和工件用 `\WObj:=` 指明，别漏。

7. **跑仿真**：Simulation → Simulation Setup，把 Path_10 加进主序列，点 Play；或者先不跑程序，右键路径 → Move Along Path，只验证轨迹走得对不对。

### 容易错在哪

- **Move Along Path 报错**：先加 `ConfL Off` 和 `ConfJ Off`（右键路径 → Insert Action Instruction → Instruction Templates 里选），再不行用 Auto Configuration 给所有 Move 指令重算构型。
- **轨迹拐弯 / 够不着**：点太少机器人会抄近路，中间加过渡点（Approach 点）；点在可达范围外就挪工件或机器人位置，别硬改点位数值。
- **MoveJ / MoveL 用反**：贴工件（焊接、点胶、装配插入）必须 MoveL，空中赶路用 MoveJ；用反了轨迹是歪的。
- **zone 用错**：贴工件的点用 fine 或 z1，空中过渡点才用 z50；全用 fine 跑得慢，全用 z50 贴工件会撞。
- **忘了同步**：只在工作站里建了路径、没 Synchronize to VC，控制器里就没有程序，仿真跑的是旧程序。

### 和库里其他内容的关系

- `rapid/01_move_basics.mod`：MoveJ / MoveL 的概念；这课是完整操作链，补进去新手路线 L4、L6 就完整了。
- 第 2 课点动、第 4 课工具坐标系、第 6 课工件坐标系三点法：都是这课的前置步骤，先会点动和坐标系，再学路径。
- 第 11 课：建了 3 个工件坐标系 + 取放轨迹，是“沿路径走”的实战版；两课互相印证。

## 第 9 课：真空夹爪 Smart 组件——信号一来就吸，信号一撤就放

**来源视频：** Maurilio Patino 码垛教程 Part 1（视频 https://youtu.be/y0FjnO8AysQ ，文字版全文已读；时长**未核实**）

### 这是什么

做一个能吸住箱子、松开箱子的真空夹爪，信号一来就吸，信号一撤就放。

**Smart 组件**就是 RobotStudio 里带逻辑的小零件：里面可以挂传感器、挂逻辑、挂信号，拼好了能直接复用。**Line Sensor**（线传感器）就是一条检测线，东西碰到这条线它就亮。**Attacher / Detacher**（吸住器／松开器）是 Smart 组件里的两个动作：Attacher 是把碰到的东西粘到夹爪上，Detacher 是松开。

### 怎么做

1. **导夹爪 CAD**：建空工作站，Modeling → Import Geometry，选 `.SAT` 格式的夹爪文件（GrabCAD 上能找例子）。
2. **摆正工具**：先把工具转到露出底座，用 Place Tool → One Point + Snap Center，把工具放到世界坐标系原点，再转到正确朝向。
3. **定 TCP**：Frame → Create Frame（参考系选世界坐标系）；量出工具底座到 TCP 的距离（Patino 的例子是 184 mm，**用自己的夹爪要自己量**），Set Position 把工具坐标系移到 TCP。
4. **生成工具文件**：Modeling → Create Tool，起名，选 Existing Component；重心用 Snap Gravity 取；TCP 起名、选刚建的工具坐标系。
5. **（可选）存成库**：点工具 → Save as Library，存成 `.rslib`，以后直接复用。
6. **建 Smart 组件**：Modeling → Smart Component，起名如 `SC_VentosaTool`；把自定义工具拖进去做子组件，工具属性用 Set as Role 设为 Role。
7. **加传感器**：在 TCP 处放一个 Line Sensor，定好起点和终点的小圆柱，就是传感器的检测线。
8. **接逻辑**：Design 窗口里新建一个数字输入 DI（如 `DI_Attach`），接线逻辑是——
   - 吸：传感器 SensorOut 为真 → Attacher 执行；
   - 放：DI_Attach 为假 → Detacher 执行（注意：放的逻辑要过一个 LogicGate NOT，就是取反）；
   - Attacher/Detacher 的 Child 都设成 `LineSensor.SensedPart`（也就是传感器碰到的箱子），Parent 设成夹爪工具。
9. **存成库**：Smart 组件 → Save as Library，存成 `.rslib`。

### 容易错在哪

- TCP 距离要自己量，别抄 184 mm，那是 Patino 那个夹爪的数。
- 放的逻辑要取反（DI 为假才放），直接接会吸住不放。
- Attacher 的 Parent 必须是夹爪工具，不然箱子吸到别的地方去。

### 和库里其他内容的关系

- 库里 `rapid/02_pick_place.mod` 的搬运是写死的取放，这个是 Smart 组件版的吸放，信号驱动。
- 库里 `references/smart-components.md` 讲通用搭法，这个是真空夹爪的完整实例，补进去后新手能直接照做。

## 第 10 课：传送带物理仿真——箱子自己掉下来、自己被送走

**来源视频：** Maurilio Patino 码垛教程 Part 2（视频同第 9 课，文字版全文已读）

### 这是什么

做一条会动的传送带：箱子从 Source 里出来、掉到皮带上、被皮带送到头、传感器一碰到箱子皮带就停。

**物理仿真**就是让东西按真实物理走：箱子会受重力往下掉，皮带会带着箱子走。**Source**（发生器）是 Smart 组件里造东西的部件，信号一来就造一个箱子出来。**PhysicsControl**（物理控制）是管皮带启停的部件。**Logic Gate**（逻辑门）是把几个信号按“与／或／非”拼起来的小逻辑块。

### 怎么做

1. **导传送带**：新工作站，Home → Import Library → Equipment，选传送带（Patino 用 950×4000），Set Position 放到中间。
2. **做皮带**：Modeling → Solid → Box，画一个当皮带，起名 Belt，放到传送带顶上。
3. **做箱子**：再画两个 Box，小箱 200×200×100（橙色）、大箱 200×200×200（绿色），放到传送带一头；大箱先隐藏。
4. **移箱子本地原点**：每个箱子用 Set Local Origin + Snap End，把本地坐标系移到箱子顶部。不移的话，开了物理后箱子会穿透皮带（Patino 原话的教训）。
5. **皮带加物理**：Physics → Behavior → Fixed；再用 Surface Velocity，打开速度、方向沿 +X。
6. **建 Smart 组件**：新建 Smart Component，起名如 `SC_Conveyor`，把箱子和传送带都拖进去。再挂这些子组件：
   - 两个 Source：一个造小箱、一个造大箱（开 Transient，箱子到头就删；开 dynamic transition，箱子带物理、会受重力掉下来）；
   - 一个 PhysicsControl：管皮带启停；
   - 两个 Line Sensor：下传感器 X 偏移 −60 mm、Y +50 mm（到小箱中部高度）；上传感器 X 同样 −60 mm、Y +150 mm（只碰大箱）；
   - 一个 Logic Gate：连信号管皮带启停。
7. **接 I/O**：Design 窗口里建数字输入（造小箱、造大箱）和数字输出（上传感器、下传感器）。
8. **接线**：Source 由输入信号触发；传感器输出一亮，皮带经 PhysicsControl 停下。
9. **测试**：先把箱子隐藏，保存仿真初始状态，起名 “Simulation Start”；打开 I/O Simulator，点按钮出箱，点 Play 跑，看箱子掉下来、皮带送、传感器一碰就停；停下后 Reset 回初始状态。
10. **保存工作站**：验证没问题再保存整个站。

### 容易错在哪

- 箱子本地原点不移到顶部，箱子会穿透皮带。
- 上传感器高度要够（+150 mm），不然小箱也会触发它，分拣就乱了。
- 测试前先保存 “Simulation Start” 初始状态，不然每次改完都要重摆。

### 和库里其他内容的关系

- 库里没有传送带物理仿真的内容，`references/smart-components.md` 没讲 Physics，这是新的。学完后那篇可以加一节“物理仿真”。

## 第 11 课：取放 + 叠放偏移 + 传感器分拣

**来源视频：** Maurilio Patino 码垛教程 Part 3（视频同第 9 课，文字版全文已读）

### 这是什么

传送带送来大小两种箱子，机器人按传感器判断：小箱放小托盘、大箱放大托盘，叠起来放，一层一层往上码。

**Offs**（偏移）就是在原来点的基础上加个差值，比如往上抬一个箱子高度，这样不用每个位置都重教点。**motion events**（运动事件）是建系统时开的一个选项，开了后面有些功能才能用。

### 怎么做

1. **摆场景**：导机器人底座放传送带对面；导机器人，控制器起名 “Pick and Place”，建系统时打开 motion events 选项；把机器人放到台座上，调高一点、转个方向；更新任务坐标系，让机器人底座坐标系同步。
2. **加组件**：把前面做好的传送带 Smart 组件和夹爪 Smart 组件拖进来；控制器模型放传送带旁边；两边各放一个托盘，开 workspace volume 可视化确认位置摆对了。
3. **托盘加物理**：两个托盘都加物理属性、设成刚性，箱子才不会掉穿托盘。
4. **放参考箱**：大小托盘上各放一个参考箱对轨迹（大箱那个要设成传感器检测不到，不然干扰）。
5. **建 3 个工件坐标系**：传送带一个（取的轨迹相对它）、小托盘一个、大托盘一个（各绑托盘一角）。三点法定工件见第 6 课。
6. **主程序加循环**：同步配置到控制器，主程序加 `while true` 循环，不然仿真自己停了。
7. **教轨迹**：Home 点；取大箱轨迹（取点起名如 Target Large Box，调好工具朝向）；过渡点（取放之间抬高走，防撞）；小箱轨迹照样做；放大小托盘的轨迹各一套。
8. **同步 + 接信号**：所有指令同步到 RAPID；加数字输入（传感器状态）、数字输出（造箱、真空吸放）。
9. **写程序**：Pick and Place 大箱、Pick and Place 小箱两个程序；再写 Create Box 程序，FOR 循环先造 3 个小箱、再造 3 个大箱，中间加延时模拟间隔。
10. **主逻辑**：开头结尾都回 Home；IF 判断：只有下传感器亮 → 走小箱轨迹；两个传感器都亮 → 走大箱轨迹。
11. **叠放**：路径上加偏移（Offs），每放一层往上抬一个箱子高度，不然箱子叠到同一个点。
12. **收尾**：加 WaitTime 让动作顺滑；再同步一次；把控制器和 Smart 组件的信号连上；跑起来验：箱子自动造、机器人按传感器走、取放都对；最后 Reset、保存。

### 容易错在哪

- 参考箱不设成“传感器检测不到”，分拣逻辑会被它干扰。
- 叠放不加偏移，箱子全叠到同一个点上。
- 建系统时 motion events 没开，后面有些功能用不了，要重建系统。

### 和库里其他内容的关系

- `rapid/02_pick_place.mod`：固定取放；这课是“按传感器分拣 + 叠放”的升级版。
- `rapid/04_loops_conditions.mod`：FOR 循环造箱、IF 判断分拣，都是现成模式的组合。
- `rapid/05_coordinates.mod`：一个场景 3 个工件坐标系，是 wobjdata 的实战例子。

## 第 12 课：PLC 发程序号 + Pounce 点 + 故障处理

**来源视频：** Ryan Bliss《Learn to Code ABB Robots to Perform Pick and Place Tasks using Rapid Programming》（19 分钟，章节表已核实；视频链接**未核实**）
**配套文字材料：** control.com 同主题文字教程《ABB Robot Example Programming Tutorial》（机器人编程系列第 2 篇，2022-03-01，2024-01-08 更新；作者**未核实**——是同主题文字教程，不是视频逐字稿）

### 这是什么

PLC（可编程逻辑控制器，就是工厂里管整条线的大脑）发一个程序号过来，机器人按号执行对应的程序。机器人先回个收到确认，PLC 对上号才让机器人动手。

**组信号**就是把多个离散信号拼成一个整数：比如 `giCommand`（组输入）收程序号，`goCmdEcho`（组输出）把收到的号原样发回去当回执，`diExe`（数字输入）是执行标志，PLC 置 1 才表示“可以动手了”。

**Pounce 点**是离工装足够远、离干活区足够近的中间点，先到它再进活区，省时间。**Offs()** 是偏移函数，在原来点的基础上加个差值。**No Step 模块**是只做计算、不含运动的模块，示教器上不能单步进里面，代码必须先测好再用。

### 怎么做

**1. 视频的完整流程（章节表）：**

定义工件 → 新建工件 → 三点法 → 原点 → 点动 → 改点位 → 再改点位 → 测工件 → 建 Palette B（托盘）→ 定义点 → 工具对象 → 定义点 → 安全点 → 程序编辑器 → 代码走读 → 应用代码 → 调试。

要点：工件、点位、工具、安全点全部先在示教里定好，最后才进程序编辑器写代码、走读、应用、调试。顺序别反。

**2. PLC 发程序号，机器人按号执行：**

- PLC 通过现场总线（Ethernet/IP、PROFINET、EtherCAT，就是工厂里设备之间传信号的工业网线协议）发一个程序号。
- 机器人用组信号收：`giCommand` 收号；回执用 `SetGo goCmdEcho, nCmd` 把收到的号原样发回去，PLC 对上号才把执行标志 `diExe` 置 1。
- 主循环等执行标志：

```rapid
WHILE diExe = 0 DO
  nCmd := giCommand;
  SetGo goCmdEcho, nCmd;
ENDWHILE
```

也可以用 GOTO 写法：`LoopStart:` … `IF NOT(diExe) GOTO LoopStart;`。

**3. 按号分发（TEST/CASE）：**

```rapid
TEST nCmd
CASE 1:
  FuncFirst();
CASE 2:
  FuncSecond();
DEFAULT:
  TPWrite "Invalid Program" \Num:=diExe;
ENDTEST
```

非法程序号要报出来，别静默跳过。库里 `rapid/08_test_case_functions.mod` 有 TEST/CASE 基础，这里补的是“号从 PLC 来”这一层。

**4. Pounce 点 + Offs 接近：**

- Pounce 点：离工装足够远、离干活区足够近的中间点，先到它再进活区，省时间；示教时确认到 Pounce 点和 Home 点的路上没有任何物理阻挡。
- 从 Pounce 点用 `Offs()` 偏移到最终点：先高速到接近点，最后一段用慢速直线（`fine`）下到取件点，停稳再合夹爪，再原路退回 Pounce 点。
- 文字教程的取件片段：先 `CheckGripper\Empty` 查夹爪是空的 → 开夹爪 → 按零件类型 `GetPosition(\Pick)` 取点 → `MoveL Offs(..., -20, 0, 120)` 接近 → `MoveL Offs(..., -20, 0, -5)` 下探 → `MoveL pPallet_Pick, v500, fine` 到位 → `Gripper\Close`。

**5. 故障处理别省：**

- 每次关键动作后查故障位（`dnFltPend1` / `dnFltPend2`），有故障就 `FaultMsg` → `SetCmdDone` → `RETURN`，别继续往下走。
- 取件失败要能恢复：先确认故障、打开夹爪、抬起来退回接近点和 Home 点，再报错。
- 干循环（没料试跑）要单独留开关（`bDryCycle`），别把无料报警和真故障混在一起。

**6. No Step 模块：**

- 只做计算、不含运动的模块可以设成 No Step：示教器上不能单步进里面，代码必须先测好再用。
- 典型放这里的：`FUNC GetPosition(\switch Pick, \switch Place)`——按零件类型（`TEST nPartType`，CASE 1/2/3）返回不同的取件点，非法类型置故障位、发 `TPWrite "Wrong Part type"`。

**7. World Zone 告诉 PLC 机器人在哪（挂 PowerOn 事件）：**

```rapid
PROC WorldZones()
  WZSphDef\Inside, shp wzHome, pHome.trans, 50;
  WZDOSet\Stat, wzHome\Inside, shp wzHome, doAtHome, 1;
  WZBoxDef\Outside, shp wzDial, poswzDialLow, poswzDialHigh;
  WZDOSet\Stat, wzClearDial\Inside, shp wzClearDial, doClearDial, 1;
ENDPROC
```

- 每个 Zone 要两个数据：`wzstationary`（允许的工作范围声明）+ `shapedata`（范围形状大小）。
- 三种形状：球、盒、圆柱；进 Zone 置输出为真，出范围可停机或反转信号。
- 好处：PLC 不用中断程序流就知道机器人在哪，还能用来恢复到已知安全点。
- 详细做法见第 13 课。

**8. 模块分工（文字教程的习惯）：**

- 主模块：PROC + 全局变量；tooldata、夹爪数据放这里；点位不放这里。
- 运动模块：所有运动 PROC；开头先回 Home/维修点、确认夹爪状态。
- 各模块职责分开，别把点位、逻辑、运动全塞一个模块。

### 容易错在哪

- 非法程序号静默跳过：DEFAULT 里一定要报出来，别什么都不干。
- Pounce 点和 Home 点的路上没确认有没有物理阻挡，示教时先确认。
- 关键动作后不查故障位，有故障还继续往下走。
- 干循环（没料试跑）和真故障混在一起：干循环单独留开关。
- No Step 模块里的代码没测好就用：示教器上不能单步进里面，出错不好查。

### 和库里其他内容的关系

- `rapid/02_pick_place.mod`：固定取放；这课补的是 PLC 调度、Pounce 点、故障处理、No Step 这些实战写法。

## 第 13 课：安全——QuickStop + World Zone 禁区

**来源视频：** Maurilio Patino 码垛教程 Part 4（视频同第 9 课，文字版全文已读）；ABB 官方《RobotStudio® Tutorial – Visualize World Zones》（视频 https://www.youtube.com/watch?v=E0bhSQN46Os ，标题已核实、内容待学）
**学法说明：** A2 视频内容待学，本课的 World Zone 写法以 Patino Part 4 为主。

### 这是什么

单元里有人进来机器人要停；机器人不准进的区域，软件上也要拦住，真撞上围栏之前就停机。

**QuickStop**（快速停机信号）就是一个让机器人立刻停下的信号，比正常停快。**World Zone**（禁区）就是在软件里划一块区域，机器人一进这块区域就报警停机，相当于看不见的围栏。**PowerOn 事件**就是控制器一上电就自动跑的程序，把禁区定义挂在这里，重启控制器禁区就生效。**ISO 10218:2011** 是工业机器人安全标准，围栏、光幕、急停这些东西为什么要有，都是它规定的。

### 怎么做

1. **讲标准**：先看 ISO 10218:2011，知道围栏、光幕、急停这些东西为什么要有。
2. **摆安全件**：围栏围住单元；导急停按钮（.SAT）、状态指示塔、Omron 光幕，放到位：急停按钮放墙上、复制一个放站里；光幕放单元入口（叉车进出的口子），两边都装好。
3. **建急停信号**：新建信号 `StopRobotEmergency`（数字输入）+ 一个恢复信号；建用户信号清单，把两个信号加进去。
4. **接系统输入**：System Inputs 里把启动连到 Run 按钮，新建一个 QuickStop 信号；应用后重启控制器。
5. **演练光幕急停**：先关掉自动序列和过渡选项（不然急停时箱子会消失）；跑仿真、造一个小箱；触发急停信号模拟有人进单元，机器人停住；人“出去”后手动恢复。
6. **建 World Zone（禁区）**：先编一条故意撞围栏的轨迹做测试（点如 Point1、Point2）；定义一个四面体禁区，尺寸 1 m × 4 m × 2 m，红色半透明，放单元后部；用底座坐标系量点来定禁区范围。
7. **写 RAPID**：声明一个静止障碍物变量，写 `MyPowerOn` 程序定义禁区，量好的点当输入；把 `MyPowerOn` 挂到机器人的 PowerOn 事件上，重启控制器。
8. **验证**：再跑那条撞围栏的轨迹，TCP 一进禁区就报警、机器人没撞上就停了；最后机器人回初始位置，保存仿真。

### 容易错在哪

- 演练前不关自动序列，急停一触发箱子就消失了，现象看不出来。
- QuickStop 信号建完要重启控制器，不然不生效。
- World Zone 的点要用底座坐标系量，别用错坐标系，禁区会偏。

### 和库里其他内容的关系

- 新手路线 L14 只有安全文字（手动低速、查碰撞、急停围栏），没有 QuickStop 和 World Zone 的做法；这课补的是能照着做的步骤。
- World Zone 的 RAPID 写法（PowerOn 事件 + 禁区定义）是新东西，库里原来没有。
- 可视化做法见第 14 课。

## 第 14 课：World Zone 可视化——三种做法，任选一种

**来源视频：** ABB 官方《RobotStudio® Tutorial – Visualize World Zones》（视频 https://www.youtube.com/watch?v=E0bhSQN46Os ；时长**未核实**）
**学法说明：** 内容靠 ABB 官方发布说明核实；WorldZones Add-in 的做法来自 ABB 社区帖 + GitHub parasuramsarathi/ABB-WorldZones，是社区材料，不是官方教程原文。

### 这是什么

RAPID 里的 World Zone 定义指令（`WZBoxDef` / `WZCylDef` / `WZSphDef`，分别是定义盒形／圆柱形／球形禁区的指令）直接在工作站里画出来：半透明形状。这样不用跑程序就能看见禁区在哪。

工作站和虚拟控制器之间同步；形状能改颜色、能隐藏；用 Instruction 选择级别可以在 3D 图里直接点中指令。

### 两个硬条件

- 定义体积时必须用数字字面量，不能用 `CONST pos` 变量——写成变量就不显示（社区实测：`WZBoxDef\Outside, shp, [-330,-682,10], [1134,682,1060]` 能显示，`CONST pos A := [...]; WZBoxDef\Outside, shp, A, B;` 不显示）。
- 关节坐标系的 Zone（`WZLimJointDef`、`WZHomeJointDef`）还不支持可视化。

### 怎么做：三种可视化做法，任选一种

1. **工作站里直接显示**：定义好的 Zone 在 3D 图里画成半透明形状。
2. **WorldZones Add-in**：Add-ins → Install Packages，装 `WorldZones-2.0.rspak`，重启 RobotStudio；Utilities 下有 Visualize Zones 和 Robot Position Viewer。来源：ABB 社区帖 + GitHub parasuramsarathi/ABB-WorldZones。
3. **手工画**：Modeling 里建一个盒子当 Zone，透明度约 60%，再在 Simulation 里建碰撞集，机器人碰到 Zone 就报警（社区常用土办法）。

Zone 本身的写法（`WZSphDef` / `WZBoxDef` / `WZDOSet`、挂 PowerOn 事件）通用，见第 13 课。World Zone 是 RobotWare 的老选项（608-1），`WZBoxDef` 等指令在 RobotWare 5/6 的手册里就有，不是新功能。

### 容易错在哪

- 定义体积时用 `CONST pos` 变量：写成变量就不显示，必须用数字字面量。
- 关节坐标系的 Zone（`WZLimJointDef`、`WZHomeJointDef`）本来就不支持可视化，别以为是自己装错了。
- Add-in 的做法来自社区帖和 GitHub，不是官方教程原文，装之前先看清来源。

### 和库里其他内容的关系

- 第 13 课：Zone 写法与 QuickStop。
- 这课补的是可视化做法：三种方法任选一种，都能看见 Zone。
